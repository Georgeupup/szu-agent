# 体育学院2025-2026学年度研究生奖学金评选办法

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保2026年研究生奖学金评审工作公开、公平、有序进行，现将体育学院研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
I. 研究生国家奖学金
一、评选对象
体育学院攻读硕士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
二、推荐人数
研究生国家奖学金3人。
三、奖励标准
硕士研究生国家奖学金一人一次性奖励2万元。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习成绩优异，科研能力显著，发展潜力突出。
五、评选细则
详见附件：《深圳大学体育学院研究生国家奖学金量化评分表（2026年）》
注意：
（1）研究生参评国家奖学金，所有课程学业成绩均需在75分以上（含75分）
（2）研究生参评国家奖学金的各类科研成果认定的截止时间为2026年8月31日，可追溯至以当前身份前一次参评研究生奖学金之日，即学术论文、科研项目、个人荣誉等需在2025年9月1日至2026年8月31日内获得或发表。送稿中或评审中的未接收文章不计为科研成果（以见刊为准）。
（3）所有学术成果均需以深圳大学为第一署名单位。
II. 研究生社会奖学金
A.鹏程奖学金
一、评选对象
体育学院攻读硕士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
二、名额及金额
鹏程奖学金1人。一人一次性奖励10000元。
三、评选标准
1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2.刻苦学习、成绩优异，在全班或全年级名列前茅；
3.具有较强的科研能力，有公开发表科研成果。
四、评选细则
详见附件4：《深圳大学体育学院研究生鹏程奖学金量化评分表（2026年）》
注意：
（1）研究生参评社会奖学金，所有课程学业成绩均需在75分以上（含75分）；
（2）研究生参评社会奖学金的各类科研成果认定的截止时间为2026年8月31日，可追溯至以当前身份前一次参评研究生奖学金之日，即学术论文、科研项目、个人荣誉等需在2025年9月1日至2026年8月31日内获得或发表。送稿中或评审中的未接收文章不计为科研成果（以见刊为准）。
（3）所有学术成果均需以深圳大学为第一署名单位。
注：根据学校相关文件和会议精神，同时考虑体育学院人才培养的特殊性，原则上国家奖学金、社会奖学金、学业奖学金不能兼得。特别优秀学生评审委员会专门讨论。
Ⅲ. 优秀研究生干部
一、评选对象
体育学院攻读硕士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
二、推荐人数
优秀研究生干部2人
三、奖励标准
优秀研究生干部奖励标准为一次性奖励2000元，并颁发证书。
四、评选标准
优秀研究生干部主要奖励优秀校、院级研究生干部或学校社团组织负责人以及在社会工作中表现突出的个人。参选人须同时满足下列条件，择优推荐：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
优秀研究生干部综合评分由三部分组成，具体计算方式如下：班级同学打分（满分100分）×40% + 辅导员打分（满分100分）×20% + 科研秘书打分（满分100分）×20% + 班主任打分（满分100分）×20% 评分后报送评审委员会进行评定。
五、评选程序
（一）9月11—16日，各学院（部）成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定本学院（部）的评选细则、开展初步评审等工作。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。院评审委员会名单（附件2）及评选细则需在学校公文通上予以公示。公示无异议，9月16日前将评选细则及评审委员会名单电子版（可编辑Word文件及签字盖章后PDF扫描件）通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（二）9月14—17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4，可下载系统生成的文档）至系统，9月17日17点前将所有纸质版材料线下提交至元平体育馆舒铖老师处。申报各类奖项时，相关佐证材料均需上传至系统附件（过时提交不予认定）。
（三）9月18—30日，各学院（部）组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。公示无异议，9月30日前将以下材料电子版通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交：
（四）10月8—14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（五）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（六）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
