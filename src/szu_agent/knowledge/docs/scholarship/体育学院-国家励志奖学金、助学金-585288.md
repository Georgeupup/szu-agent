# 体育学院2026-2027学年度本科生励志奖学金和助学金评定工作细则

为激励我院家庭经济困难学生勤奋学习、努力进取，在德、智、体、美等方面全面发展，政府在我校设立了助学金。根据《深圳大学本科生助学金评审办法》，结合我院家庭经济困难学生的实际情况，现就开展我院2026-2027学年度本科生国家励志奖学金和助学金评定工作通知如下：
一、国家励志奖学金申请条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校二年级及以上本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度，没有违纪行为；
5.诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，2025-2026学年成绩排名至少在前50%；
7.积极上进，生活简朴。
二、国家励志奖学金评定原则
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。
三、国家励志奖学金名额分配
国家励志奖学金，32人。
四、助学金体系构成
政府助学金：国家助学金一等奖及二等奖。
五、助学金申请条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校本科生；
2.符合各类助学金的申请条件（见附件1）；
3.知晓并承诺履行助学金获助学生义务（见附件2）。
六、助学金评定原则
1.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处；
2.学院将根据学生2025-2026学年成绩和家庭困难情况评定拟获资助等级。
七、助学金名额分配
政府助学金：
国家助学金，一等22人，二等50人。
八、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn）助学金栏目申请。申请国家励志奖学金须上传成绩单。助学金申请系统于10月19日开通，10月22日上午9：00关闭，逾期不予申请。
2.学院在评选过程中应坚持公平、公正、公开的原则，按照学院评选细则，严格审查申请学生资格，确定拟获资助名单，并在学院意见一栏签署详细意见。学院将在规定时间内完成国家励志奖学金和助学金评定网上审核及公示（3个工作日）。
九、有关说明及注意事项
1.超过基本修业年限的学生不再享受国家助学金。
2.国家助学金和国家励志奖学金可以兼得。
体育学院
