# 法学院2025‑2026学年度本科生奖学金及先进班集体评选细则

为落实学校学生部《关于开展2025‑2026学年度本科生奖学金及先进班集体评选活动的通知》要求，现就法学院2025‑2026学年度本科生奖学金及先进班集体评选工作制定本细则。
一、参评基本资格
（一）热爱社会主义中国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守学校的规章制度，品行优良；
（三）我院二年级及以上（含二年级），参评学年度学籍在我院的全日制普通在校本科生，延期毕业的本科生除外；
（四）遵守校规校纪，参评学年度及评选期间没有受到学校行政、党、团处分；
（五）除特殊贡献类奖项外，参评学年度所有课程成绩须全部及格；
（六）原则上参评学年度体测成绩及格及以上；
（七）参评学年度义工时长28小时及以上；
（八）参评学年度思政学时、体测达标；
二、国家奖学金
（一）参评要求
根据《深圳大学本科生国家奖学金评审办法》，需满足以下条件：
1. 上一学年的平均绩点排在本专业本年级前10%，且无挂科记录、无违纪记录；
2. 在专业学科竞赛和学术上获得突出的成绩，取得国家级、省级荣誉；或在专业科研领域发表论文、获得国家发明专利；
3. 在社会实践、体育竞赛、文艺比赛、志愿服务等方面表现优秀。
（二）奖项名额及奖励标准
本科生国家奖学金名额共2个，奖励标准：10000元/人。
（三）申请时间及申请要求
本年度国家奖学金申请时间为9月11日至9月15日。学生凭本人校园卡账号和密码登录网上办事大厅“奖学金”板块在线提交申请表，并按照学院通知要求提交相应材料。
（四）评选流程
1. 奖学金系统开放后，符合申请条件的本科生在线提交奖学金申请，并严格按照学院申请通知要求提交相应材料，学院本科生奖学金评选小组对所有申请材料进行审核。
2. 学院本科生奖学金评选小组推荐学习成绩优异、社会实践、创新能力、学术竞赛等综合素质方面特别突出的候选人。
3. 评选结束后，由学院本科生奖学金评选小组对评定结果进行公示，公示期不少于3天。
4. 公示期结束后，学院提交相关材料至学生部学生资助中心。
三、社会奖学金（鹏程奖学金）
（一）参评要求
根据《深圳大学本科生社会奖学金（鹏程奖学金）评选办法》，需满足：
1. 刻苦学习、成绩优异，参评学年度所有课程及格，学分绩点在全年级10%以内。
2. 在学术竞赛、社会实践、体育竞赛、文艺比赛、志愿服务等方面表现优秀。
（二）评选流程
1. 奖学金系统开放后，符合申请条件的本科生通过网上办事大厅奖学金板块在线提交申请，并严格按照奖学金申请通知要求提交相应材料，学院本科生奖学金评选小组对所有申请材料进行审核。
2. 学院本科生奖学金评选小组遴选学习成绩优异、社会实践、创新能力、学术竞赛等综合素质方面突出的候选人。
3. 评选结束后，由学院本科生奖学金评选工作小组对评定结果进行公示，公示期不少于3天。
4. 公示期结束后，学院提交相关材料至学生部学生资助中心。
（三）奖项名额及奖励标准
本科生鹏程奖学金名额共2个，奖励标准：10000元/人·年。
（四）申请时间及申请要求
本年度鹏程奖学金申请时间为9月15日至9月20日，学生凭本人校园卡账号和密码登录网上办事大厅奖学金板块在线提交申请表，并按照学院通知要求提交相应材料。
四、校级单项先进个人奖学金
（一）学习之星
以参评学年度内所有课程平均学分绩点为依据，按年级排名，平均学分绩点高者优先评选。
1. 一等奖、二等奖和三等奖以年级为单位，按同年级同专业排名。所有参评学生所选课程（含必修课、选修课）按平均绩点高低排序；绩点相同时，按照本学年所选学分多少确定排名先后；所选学分相同时，以一学年必修课成绩高低确定排名。
2. 学习之星获奖人数不超过本院参加评选学生总人数的10%，其中一等奖占1%，二等奖占3%，三等奖占6%。
（二）双创之星
以《深圳大学“双创之星”评选细则》为依据进行评选。
（三）文体之星
以《深圳大学“文体之星”评选细则》为依据进行评选。
（四）公益之星
以《深圳大学“公益之星”评选细则》为依据进行评选。
（五）优秀学生干部
1.评选条件
（1）在评选学年度内担任相关职务满1学年以上；无故离任或被免职者不得参评。
（2）评选对象包括院党促会、团委、学生会、支部委员、班级班委等学生干部。
（3）热心为同学服务，工作积极主动，认真负责，任劳任怨，主动参与策划、组织各类学生活动，工作成绩突出，对班风学风建设做出较大贡献。
2.评选方法
（1）采用个人申请形式，在学校奖学金系统申报。
（2）由学生干部所在组织、班级开展初步评优推荐。
（3）学院奖学金评审工作小组结合各组织、班级推荐人选材料和工作实绩，确定优秀学生干部名单。
3.名额设置
优秀学生干部分一、二、三等奖。获奖人数不超过本院参加评选学生总人数的4%，其中一等奖占0.5%，二等奖占1.5%，三等奖占2%。
（六）校级奖学金申请时间及申请要求
本年度校级单项先进个人奖学金申请时间为9月15日至9月20日，学生凭本人校园卡账号和密码登录网上办事大厅奖学金板块在线提交申请表，并按照学院通知要求提交相应材料。
（七）校级奖学金评选流程
1. 奖学金系统开放后，符合申请条件的本科生在线提交奖学金申请，并严格按照各类校级奖学金申请通知要求提交相应材料。
2. 学院本科生奖学金评选工作小组对所有申请材料进行审核，确定候选名单。
3. 对评审结果进行公示，公示期不少于3天。
4. 公示期结束后，学院本科生奖学金评选工作组提交相关材料至学生部学生资助中心。
（八）校级奖学金奖励标准
一等奖：3000元/人；二等奖：2000元/人；三等奖：1000元/人。
（九）先进班集体
1. 先进班集体以《深圳大学先进班集体评选办法》为依据开展评选。
2. 各班指定1名同学在学校奖学金系统申报并提交材料；学院奖学金评选小组审核申报材料，根据总分排名先后，对照评选名额确定先进班集体名单。
3. 先进班集体名额共6个。
五、评选工作原则及总体要求
1. 本年度国家奖学金、学校奖学金、社会奖学金纳入统一的奖学金评选体系，统筹规划、同步评选；2026年本科毕业生奖学金评选工作同步进行。
2. 申报各类奖学金，均需满足对应奖学金文件规定的评选资格条件。
3. 按照《深圳大学本科生奖学金评定办法（修订）》，如同时获得多项先进个人奖学金，荣誉称号可以兼得，奖学金奖金按最高一项计发；校级单项先进个人奖与团队奖奖金、荣誉可兼得。
4. 国家奖学金与国家励志奖学金不可兼得。
5. 以勤工助学岗位工作身份参与学生工作，不得以学生干部身份参加“优秀学生干部”奖学金评选。
6. 学生申报提交后，一经核查发现不符合评选条件的，取消参评资格，不予评定相关奖项。评选过程中弄虚作假（篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
7. “特殊贡献奖”由学校根据实际情况直接评定，学生无须申请。
