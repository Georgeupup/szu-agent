# 计算机与软件学院2025-2026学年度本科生奖学金及先进班集体评选细则

为鼓励学生刻苦学习、积极创新、全面发展，更好地发挥奖学金的激励和导向作用，切实推动我院学风建设，我院根据《深圳大学本科生国家奖学金评审办法》、《深圳大学本科生奖学金评定办法（修订）》、《深圳大学学生特殊贡献奖认定办法》、《深圳大学先进班集体评选办法》以及各类社会奖学金设置协议，结合我院实际，现就我院2025-2026学年度本科生奖学金及先进班集体评选工作通知如下：
一、评审机构
学院成立2025-2026学年度本科生奖学金评审小组。
组长：杨国洪
副组长：廖江海、杨烜
成员：各系主任、班主任（2022级-2024级）、辅导员、学生权益成员代表
实行参评人员回避制。
二、参评基本资格
申请人参评时应同时满足下列条件：
（一）热爱社会主义中国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守学校的规章制度，品行优良，举止文明，诚实守信；
（三）我院二年级以上（含）且所参评年度内在校学习的全日制普通本科生；
（四）所评选学年度和评选期间没有受到学校行政、党、团处分；
（五）必须符合《深圳大学本科生奖学金评定办法（修订）》的奖学金评选条件；
（六）所评选学年度内所有课程及格（特殊贡献类除外）；
（七）原则上所评选学年度体测成绩及格及以上；
（八）所评选学年度义工时28小时及以上；
（九）所评选学年度思政学时达标。
三、奖学金体系构成
(一) 国家奖学金
全校74人，10000元/人，我院共有4个推荐名额。
(二) 社会奖学金
1.比亚迪奖学金：全校14人，10000元/人，我院共有3个推荐名额。
2.鹏程奖学金：全校71人，10000元/人，我院共有4个推荐名额。
(三) 学校奖学金
1.单项先进个人奖：
（1）学业类：“学习之星”、“双创之星”
（2）特长类：“文体之星”
（3）公共服务类：“公益之星”、“优秀学生干部”
（4）特殊贡献类
*各先进个人奖项对应的奖学金等级及获奖比例如下：
（1）“学习之星”可获一等、二等、三等奖学金。获奖比例：一等1%，二等3%，三等6%。
（2）“双创之星”可获一等、二等、三等奖学金。获奖比例：一二三等奖总获奖比例不超过参评学生总人数的10%。
（3）“公益之星”可获一等、二等、三等奖学金。获奖比例：一等1%，二等2%，三等3%。
（4）“文体之星”可获一等、二等、三等奖学金。获奖比例：一二三等奖总获奖比例不超过参评学生总人数的5%，其中三等奖获奖比例不超过参加评选学生总人数的2%。
（5）“优秀学生干部”可获一等、二等、三等奖学金。获奖比例：一等0.5%，二等1.5%，三等2%。
（全校名额分配见《2025-2026学年度本科生校级奖学金名额分配表》，我院细分名额将发布在各企微年级群。）
*奖学金标准为：
一等奖奖金3000元；二等奖奖金2000元；三等奖奖金1000元。
2.综合先进个人奖
（1）“荔园之星”
（2）“荔园卓越之星”、 “荔园卓越之星”提名奖
*奖学金标准为：
“荔园之星”10000元；
“荔园卓越之星”提名奖30000元；
“荔园卓越之星”50000元。
*奖学金获奖名额：
“荔园之星”获奖名额根据参评人数，结合学校年度预算安排，核定至学院（部）；
“荔园卓越之星”获奖名额不超十名（全校）
“荔园卓越之星”提名奖获奖名额十名（全校）
四、评定工作原则
（一）将本学年度国家奖学金、学校奖学金、社会奖学金纳入统一的奖学金评选体系，统筹规划、同步评选；2026年应届本科毕业生奖学金评选工作也将同步进行。
（二）申报各类奖学金，均需满足相应奖学金文件中规定的评选资格条件。
（三）学校奖学金按照《深圳大学本科生奖学金评定办法（修订）》，荣誉可兼得，奖学金以最高一项计发。
（四）学生参评学校先进个人奖项，不影响参评国家奖学金或校外单位所设的奖项及奖金（设奖单位另有要求除外）。
（五）国家奖学金与国家励志奖学金不可兼得。
（六）原则上，以勤工助学岗位工作身份参与学生工作的不可作为学生干部参加“优秀学生干部”奖学金评选。
（七）学院申报后，一旦发现与条件不符者即刻取消其评选资格，名额自动作废。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
五、各项奖学金评选细则
（一）国家奖学金
另见《计算机与软件学院2025-2026学年本科生国家奖学金评选细则》。
（根据学校通知，自2026年秋季学期起，参评国家奖学金须同时满足以下三个基本参评条件：原则上所评选学年度体测成绩及格及以上；所评选学年度义工时28小时及以上；所评选学年度思政学时达标。）
（二）社会奖学金
1.比亚迪奖学金
（1）名额及金额
全校本科生14人，每人10000元。我院可推荐3名学生参加校评审委员会评审。
（2）评选对象
根据捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二、三、四年级本科生。
（3）评选标准
a.坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。
b.热爱祖国，热爱人民，拥护中国共产党的领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。
c.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
d.具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
e.德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
f.同时满足以下基本参评条件：
①原则上所评选学年度体测成绩及格；
②所评选学年度义工时 28 小时及以上；
③所评选学年度思政学时达标。
g.在符合上述条件前提下，还应至少满足下列条件之一：
①以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文；
②以前两顺位发明人申请国家发明专利；
③在国际/国家级重大的学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
④曾在重大科研项目中担任主要完成人。
（4）评选流程：
a.9月15日9:00至9月20日17:00，学校开放比亚迪奖学金网上申报系统的申请功能，学生凭本人校园卡账号和密码登录网上办事服务大厅（http://ehall.szu.edu.cn/new/index.html），在线提交申请表，附上获奖证明等证明材料，并于9月23日12时前将纸质版申请表（合理调整版面，如有需要则双面打印）、有关证明材料等提交到致腾楼820学生工作办公室。
（注：各类获奖证明材料包括：①各类校级以上获奖证明；②发表论文的期刊封面、版权页、目录及论文正文复印件；③申请材料汇总表；④其他有关证明材料等）上述所有材料均须在9月22日24时前同时提供【电子档】，发至计软学院学工办邮箱csse824@szu.edu.cn。
b.10月14日17:00前，学院将完成院内初评及公示工作，并将初评获奖名单及申请材料报至学生资助中心（海桐斋206），由学校组织专家评审委员会评审最终结果。
2.鹏程奖学金
（1）名额及金额
全校本科生71人，每人10000元。我院可推荐4名学生参加校评审委员会评审。
（2）评选对象
本校二年级以上（含）且所参评年度内在校学习的全日制普通本科生。
（3）评选标准
a.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为，所评选学年度和评选期间没有受到学校行政、党、团处分。
b.刻苦学习、成绩优异，所评选学年度所有课程及格，学分绩点在全年级10%以内。
c.原则上所评选学年度体测成绩及格及以上（2026年要求）。
d.所评选学年度义工时28小时及以上。
e.所评选学年度思政学时达标。
（4）评选流程：
a.9月15日9:00至9月20日17:00，学校开放鹏程奖学金网上申报系统的申请功能，学生凭本人校园卡账号和密码登录网上办事服务大厅（http://ehall.szu.edu.cn/new/index.html），在线提交申请表，附上相关证明材料，并于9月23日12时前将纸质版申请表（合理调整版面，如有需要则双面打印）、有关证明材料等提交到致腾楼820学生工作办公室；上述所有材料均须在9月22日24时前同时提供【电子档】，发至计软学院学工办邮箱csse824@szu.edu.cn。
b.10月14日17:00前，学院将完成院内初评及公示工作，并将鹏程奖学金推荐名单（附件2）及申请材料通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】提交，由学校组织评审委员会评审最终结果。
注：所有本科生社会奖学金的申请者都必须符合《深圳大学本科生奖学金评定办法（修订）》第三条中规定的评选资格条件，热爱祖国，遵纪守法，品行端正，举止文明。
（三）学校奖学金
9月15日-20日，开放校级奖学金网上申报系统的申请功能，期间学生凭本人校园卡账号和密码登录网上办事服务大厅（http://ehall.szu.edu.cn/new/index.html）在线提交申请表及上传相应附件。
1．学业类：“学习之星”
按照年级专业人数比例、经学院本科生奖学金评审小组确定分配名额，以评选学年度内所有课程平均学分绩点为依据进行评选，平均学分绩点高者优先；平均学分绩点根据评选时施行的《深圳大学本科生学籍管理规定》相关规定计算。绩点相同者综合考虑选课学分情况，绩点、学分都相同则综合考虑学生全面发展情况。
2．公共服务类：“优秀学生干部”
学院奖学金评审小组结合本院学生干部工作开展情况进行名额分配。以所担任的学生组织职务工作绩效为依据进行评选，评选条件为：学生在评选学年度内担任相关职务半年以上（无故离任或被免职者不得参评）；任职期间工作绩效鉴定为优秀。
其中党支部、团委学生会、心协、义协等组织，由各组织负责老师按经评审小组确定的分配名额指导学生组织负责人组织初评，其余先进班集体（简称：优班）、优秀学生干部（简称：优干）名额由学生权益成员代表协助评审小组进行现场答辩，优秀班干部申请者所在班级应同时参评先进班集体，参评年度曾获得优秀导生的同学亦可申请参与答辩。所有申请优秀学生干部的申请人，须于9月22日24时前将所有申请材料（电子版，含系统提交页面申请表截屏）发送至学工办邮箱csse824@szu.edu.cn；上述结果报学院本科生奖学金评审小组确定后上报学校。
3．“双创之星”、“文体之星”、“公益之星”、“特殊贡献奖”
（1）申请“双创之星”的同学，如论文是共同一作，请申请“双创之星”（团队）；以学术论文参评“双创之星”可暂不上传图书馆出具的收录证明，由学院统一汇总信息（另见年级禁言群通知收集问卷），学院将在9月23日17:00前上报学生部，由学生部统一报图书馆审核收录情况，如9月18日24:00前未按时成功发送规范论文信息表到学工办邮箱，需申请人自行联系图书馆申请收录证明。
（2）“文体之星”以文体比赛成绩、演出活动的表现为依据，评选基本条件为在校级（含）以上文体活动中评价优秀；学生评选年度积极参加校内外各项文艺体育活动，在校级（含）以上文体活动中获得深圳大学（含）以上单位书面表彰可申请三等奖；同等条件下，根据学院﹝2017﹞10号发文，学生成功策划和组织“朋辈陪伴”等文体活动的，给予倾斜。
（3）“公益之星”以志愿服务工作实绩为依据，评选基本条件为积极参与志愿服务工作。由于名额有限，同等条件下，将综合根据各学年义工时数、参与志愿服务活动的类型、贡献度、不可替代性、参与服务地区等进行评议。其中，申请“公益之星”的同学需提供志愿深圳或i志愿的义工时明细表（另见年级企微禁言群收集问卷），填写问卷时，须同时提供义工时记录的excel版本和系统截图作为附件（须以学年为单位制表），填写截止期限为9月20日24:00。
（4）“特殊贡献奖”由学校根据实际情况直接评定，学生无需申请。
其它评选条件具体参照《关于开展2025-2026学年度本科生奖学金及先进班集体评选活动的通知》中有关深圳大学“双创之星”、“公益之星”、“文体之星”的评选细则评选。
六、先进班集体评定工作
按照《深圳大学先进班集体评选办法》认真开展本学年度先进班集体评选，我院共有优秀班集体名额8个。
9月15-20日17时，学生班集体网上填写先进班集体申请表，附上有关证明材料，并于9月23日12时前提交电子材料（除系统申请表及相关材料外，还有班级高清合照）至学工办邮箱csse824@szu.edu.cn。
参评各班须准备3分钟演讲及PPT、清晰的班级活动合照一张（电子版，要求能体现班级活力），派班委代表上台演讲；演讲内容包括班干架构和分工特点、上年度的工作思路、特色活动和收获。其中申请班级成员在思政学分各模块相关活动的参与度、学优生讲师人数、及对于学习困难学生的帮扶措施等均会列入考虑；由学生权益成员代表负责组织落实初评工作，具体时间和地点待定；高投票数班集体作为参选学校先进班集体候选班级，经学院本科生奖学金评审小组确定后上报学校。
10月11日17时前，学院完成院内初评结果公示，并于10月14日17时前将先进班集体初评获奖名单和材料汇总报送学生资助中心，由学生部在10月30日前进行复核、汇总和公示初评获奖名单（公示期为5个工作日）；公示无异议，学生部将评选结果报送学校审批，通过后公布正式获奖名单。表彰时间另行决定。

（一）所有奖学金均需按照学校通知规定按时在线申报及按要求提交书面及电子材料，如有未能按时在线申报或提交书面及电子材料的同学将无法参与评选。
（二）在奖学金评选期间，学院设立咨询、监督电话：0755-26534380。
（三）学院奖学金评审小组对本细则未尽事宜享有解释权。
