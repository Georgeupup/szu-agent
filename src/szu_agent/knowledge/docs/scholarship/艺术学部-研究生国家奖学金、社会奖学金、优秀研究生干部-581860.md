# 艺术学部2025-2026学年研究生国家奖学金评选细则

根据财政部、教育部《学生资助资金管理办法》《深圳大学研究生国家奖学金评审办法》《深圳大学研究生国家奖学金评选办法》及深圳大学《关于开展深圳大学2025-2026学年研究生奖学金评选工作的通知》有关规定，为促进我部研究生培养机制改革，提高研究生培养质量，确保我部2026年研究生国家奖学金评审工作公开、公平、有序进行，现将评选细则通知如下：
一、评选对象
所有全日制在校研究生（延毕同学不可申请）。
二、推荐人数
艺术学部名额为7名。（详情见附件1）
根据学校名额分配、各专业人数比例以及培养方案，原则上兼顾学科均衡以及鼓励专业成果，现简要分配如下：
专业型学位硕士3人，学术型学位硕士3人，剩余1人由艺术学部评审委员会统筹决定。（学术型硕士中，设计学以及艺术学的美术与书法研究方向、戏剧与影视研究方向、音乐与舞蹈研究方向、艺术学理论研究方向至多评选1人，具体由评审委员会结合专业及实际申请情况综合决定）
三、参评条件
1、热爱社会主义祖国，拥护中国共产党的领导；
2、遵守宪法和法律，遵守高等学校规章制度；
3、诚实守信，道德品质优良；
4、学习成绩优异，科研能力显著，发展潜力突出。
四、评选条件
学业要求：学业成绩的最低要求为学位课或必修课平均成绩达到75分以上（含75分），所修所有课程全部通过（成绩以学籍系统数据为准）；
科研竞赛要求（满足以下一项即可，不同类别不可叠加）：
1、在本专业核心期刊上发表一篇以上（含一篇）学术论文或二件以上（含二件）作品；或在本专业普通期刊上发表两篇以上论文或四件以上（含四件）作品；
2、取得一项发明专利授权；或取得两项以上外观设计专利或者实用新型专利；
3、在《艺术学部研究生高水平学科竞赛目录》（详情见附件2）中的专业赛事获市级（包含市级）以上奖项三项以上（若比赛未在目录中，但奖状盖章单位为市级以上单位也可认定）；
4、若有其他特殊贡献有评审委员会统筹认定。
五 、评选办法
1、9月14日-9月17日：所有符合参评条件并有意愿申请国家奖学金的研究生登陆深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线申请填写并上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（简称汇总表）（附件3，可下载系统生成的文档）至系统，导出并打印《研究生国家奖学金申请审批表》（简称审批表）（样表见附件4）（双面打印在一张A4纸），本人且导师签名后扫描上传至各班通知的问卷中，逾期不予受理。其中申请理由需填写至少半页，否则无效。
个人申请材料请填写至班级通知的问卷中，请严格按照填写规范进行填写。申请材料提交截止时间：9月17日 24：00，逾期无效。
2、9月18日-9月30日：学部评审委员会对各专业点申请国家奖学金的学生进行评审。学部评审委员会（附件5）确定获奖学生名单后，在全校范围内进行不少于5个工作日的公示。公示无异议后，填写《硕士研究生国家奖学金获奖学生汇总表》（附件6），经评委会主任委员签字、学部签章和获奖学生个人申请表一并提交至学生部。
3、10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
4、对评审结果有异议的学生，可在学部公示阶段向学部评审委员会提出申诉，学部评审委员会应及时研究并予以答复。如学生对学部评审委员会做出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
5、经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。
六、奖励金额
研究生国家奖学金由中央财政出资设立，硕士研究生国家奖学金奖励标准为每生每年2万元。
七、资格丧失和取消
凡有下列情形之一的，自动失去获此奖学金资格，评委会有权取消获奖学金学生的获奖资格，有权停发剩余未发放的奖学金：
1、触犯国家法律，或违反校纪校规，不遵守学校和学院各级规章制度者，弄虚作假者，受到刑事处罚或学校范围行政严重警告（含）以上处分者；
2、中途退学、辍学者。
八、评选说明
1、学术论文、科研奖项、个人荣誉等需在2025年9月1日至2026年8月31日内获得或发表（毕业年级提供录用通知书或其他获奖证明文件，评审会员会将酌情予以考虑），方可作为参评的主要依据；不得重复参评；署名单位必须为深圳大学（美术与设计学院、音乐舞蹈学院、戏剧影视学院、文化产业研究院、艺术学部均可）。有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件7，图书馆咨询电话26537002；
2、在科研成果（论文）方面：请提供发表论文期刊封面、目录（画出个人论文）以及论文全文（无需上传整本书）的扫描件。在本专业期刊上发表学术论文或作品, 应已正式刊出并能提供期刊扫描件或检索证明（毕业年级若已出录用通知，评审委员会将酌情予以考虑），发表论文均指第一作者，若为第二作者，第一作者必须是其导师，其他作者无效；
3、在科研成果（竞赛、专利）方面：请提供加盖公章获奖证书扫描件，比赛仅认定奖状证书，截图类的证明均不予以认定（毕业年级若已出正式盖章说明通知，评审委员会将酌情予以考虑）。除了《艺术学部研究生高水平学科竞赛目录》所涵盖的比赛外，其他行业协会主办的比赛需评审委员会综合考量；团队竞赛只认定第一人称，若参评人员为第二人称，导师必须为第一人称；专利需取得专利证书方可，受理通知书不予采纳；
4、评选将从学业成绩、学术论文、专业奖项及公共服务四个维度进行考量。
5、学术期刊参照国家认定的期刊范围及等级分类标准。
6、学院申报后，一旦发现与条件不符者即刻取消其评选资格，名额自动作废。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处；
7、个人不需要提交成绩单原件，由学部统一处理；
8、若本专业或研究方向不存在符合资格候选人或不足，则由其他专业择优递补。
