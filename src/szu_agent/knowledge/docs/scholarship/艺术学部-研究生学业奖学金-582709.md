# 艺术学部2025-2026学年研究生学业奖学金评选细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校有关工作要求，结合我校及我部实际情况，为促进我部研究生培养机制改革，提高研究生培养质量，确保我部2026年研究生学业奖学金评审工作公开、公平、有序进行，特制定本评选细则。现就研究生学业奖学金评审工作有关事宜通知如下：
一、评定原则
要认真贯彻执行党和国家“为社会主义现代化服务、为人民服务、与生产劳动和社会实践相结合，培养德、智、体、美等全面发展的建设者和接班人”的教育方针，以提高综合素质为衡量标准，同时也要遵循“坚持标准、各按步伐、不拘一格育人”的原则，鼓励和提倡研究生积极进取、开拓创新，从而促使各类人才脱颖而出，真正发挥奖学金的激励和导向作用，调动广大研究生的学习和科研积极性，引导研究生在思想品德、课程学习、学术论文、学科竞赛、社会服务等方面都得到提高和发展。
因此，在研究生学业奖学金评定过程中，将综合考虑思想品德、学业成绩、论文发表、学科竞赛、社会服务等综合因素。
二、参评对象
被我校正式录取并注册报到、具有中华人民共和国国籍的全日制在校学习硕士研究生。
三、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践；
（六）研究生出现以下情形之一的，不具备当年研究生学业奖学金参评资格：
1、参评学年违反国家法律法规、校纪校规受到纪律处分者或往年受到纪律处分尚未撤销的；
2、有抄袭剽窃、弄虚作假等学术不端行为经查证属实的；
3、参评学年学籍状态处于休学、保留学籍的。
四、奖励标准及评选人数
（一）硕士研究生学业奖学金实行按年评审，第一年为新生奖学金，第二、三年为学业奖学金。
1、2026级参评新生奖学金：分为特等、一等和二等三个等级。所有推免生、一流大学建设高校（42所名单见附件6）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。扣除上述人数后，获评一等学业奖学金的比例不超过20%，奖励标准为每生每年10000元；获评二等学业奖学金的比例不超过40%，奖励标准为每生每年5000元。学业奖学金只在标准学制年限内享受。
2、2024、2025级参评学业奖学金：分为一等、二等两个等级。获评一等奖学金的比例不超过当年可参评硕士研究生总人数的20%，奖励标准为每生每年10000元；获评二等奖学金的比例不超过当年可参评硕士研究生总人数的40%，奖励标准为每生每年5000元。学业奖学金只在标准学制内享受。
（三）被录取研究生的学业奖学金实行按年评选，动态管理。学部在每学年初对本部研究生学业奖学金进行评选，对因违纪、违规等原因导致不符合参评及获奖条件的研究生取消其获奖资格，并报研究生管理部门备案。
（四）9月16日，学生部下达我部2026级新生的获奖名额分配情况如下：特等学业奖学金学校认定76人（附件2），一等学业奖学金学院选评8人，二等学业奖学金学院选评15人。2026级硕士研究生除学校认定名单外，其他新生根据入学初试和复试总成绩进行排名，按专业统筹评定。
（五）一等奖学金及二等奖学金由院评审委员会根据各专业可参评人数进行名额划分。根据校学生部一等奖学金及二等奖学金评选比例及分配名额（附件3），获评一等学业奖学金的比例不超过20%，获评二等学业奖学金的比例不超过40%，在确保各专业保持均衡的情况下，名额划分如下：
1、2026级新生（除学校认定的特等及一等外）：
一等学业奖学金（共8名）：设计学1名、设计5名、艺术学2名
二等学业奖学金（共17名）：设计学1名、设计9名、艺术学5名
2、2025级：
一等学业奖学金（共21名）：艺术学（音乐与舞蹈学研究方向）2名、艺术学（戏剧与影视学研究方向）1名、艺术学（艺术学理论研究方向）4名、艺术学（美术与书法学研究方向）1名、设计9名、设计学4名
二等学业奖学金（共41名）：艺术学（音乐与舞蹈学研究方向）3名、艺术学（戏剧与影视学研究方向）3名、艺术学（艺术学理论研究方向）8名、艺术学（美术与书法学研究方向）2名、设计18名、设计学7名
3、2024级：
一等学业奖学金（共23名）：艺术学（音乐与舞蹈学研究方向）1名、艺术学（戏剧与影视学研究方向）1名、艺术学（艺术学理论研究方向）3名、艺术学（美术与书法学研究方向）1名、设计13名、设计学4名
二等学业奖学金（共48名）：艺术学（音乐与舞蹈学研究方向）3名、艺术学（戏剧与影视学研究方向）2名、艺术学（艺术学理论研究方向）6名、艺术学（美术与书法学研究方向）2名、设计26名、设计学9名
五、评选流程
（一）9月17日—9月22日：学部成立评审委员会（见附件4），由院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，院评审委员会负责制定本学院评选细则。
（二）9月23日—9月30日：所有符合参评条件的硕士研究生登陆网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写申请表，填好后打印，本人签名后扫描成图片并将个人相关论文、竞赛证明材料上传至班级通知的问卷之中（请务必保证清晰度）。
评优系统开放时间为：9月23日8:00-9月30日23:00，逾期不开放系统；
问卷材料上传截止时间为9月30日上午23点，逾期问卷系统自动关闭。
*请注意，逾期两个任何一项都不予以评定以及补充。
（三）10月8日—10月21日：学部评委会审核个人申报材料、公示推荐名单，确定学院（部）推荐名单后，在全校范围内进行公示（不少于5个工作日），并报送一下材料至学生部：
1.签字盖章版《××学院（部）2026年研究生学业奖学金评选情况总结》（附件5）
2.《硕士学业奖学金推荐名单》（系统审核通过后可导出）（附件6）
（四）10月21日后：学生部审核、公示获奖名单，报校领导审批。
（五）奖金发放时间另行通知，校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
六、有关说明及注意事项：
（一）2026级硕士研究生（包括已认定为特等的研究生）均需网上申报，非直接认定的同学按照入学初试和复试总成绩进行排名认定。
（二）2024级、2025级研究生须自愿申请。所有参评材料署名需为深圳大学（美术与设计学院、音乐舞蹈学院、戏剧影视学院、文化产业研究院、艺术学部均可），时间为2025年9月1日至2026年8月31日。论文、著作需出版，录用通知不计入成果；竞赛成果、专利需出示证书，公示通知、证明等均不计入成果，以上认定2024级可酌情处理，其他年级若因上述情况未认定可计入下一年的奖学金评定。此外，项目不计入成果，项目产出可以以论文、竞赛、专利等形式计入成果。
（三）在科研成果（论文、著作）方面：请提供发表论文期刊封面、目录（画出个人论文）以及论文全文（无需上传整本书）的扫描件；如发表著作，请提供著作封面，作者介绍页以及部分著作内容。在本专业期刊上发表学术论文或作品, 应已正式刊出并能提供期刊扫描件或检索证明（毕业年级若已出录用通知，评审委员会将酌情予以考虑），发表论文均指第一作者，若为第二作者，第一作者必须是其导师，其他作者无效；
（四）在科研成果（竞赛、专利）方面：请提供加盖公章获奖证书扫描件。除了《艺术学部研究生高水平学科竞赛目录》（附件7）所涵盖的比赛外，其他行业协会等主办则需评审委员会综合考量；团队竞赛则平均计入到每一位参赛者（无论团队成员是否为本校学生）；专利需取得专利证书方可，受理通知书不予采纳，且申请单位必须为深圳大学。以上认定如出现特殊情况由评审委员会进行综合考量。
（五）获得研究生国家奖学金、研究生国家助学金及其他研究生奖助学金的同时可以参评学业奖学金。
（六）2024级成绩为过去一年所有课程加权平均成绩（如本学年未修课程则以第一学年分数为准），具体以教务发在年级群内版本为准。2025级成绩为过去一年所有必修课程加权平均成绩，具体以研究生院系统导出数据为准。
（七）所有等级评定以学生申请等级为主要参考依据。若学生申请一等，未获评，可自动降至二等参评；若学生申请二等，参评资料符合一等获评资格，则以学生申请等级为准。
（八）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假的行为。
（九）对认定或评审结果有异议的学生，可在学部公示阶段向学部评审委员会提出申诉，学部评审委员会应及时研究并予以答复。如学生对学部评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
