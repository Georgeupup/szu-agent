# 计算机与软件学院2025-2026学年度本科生国家奖学金评选细则

一、为鼓励学生刻苦学习、积极创新、全面发展，同时更好地发挥奖学金的激励和导向作用，切实推动我院院风、学风建设，具体落实国家奖学金评选相关工作要求，根据《深圳大学本科生国家奖学金评审办法》和《教育部 财政部关于印发〈本专科生国家奖学金评审办法〉的通知》（教财函〔2019〕105号）的要求，结合我院实际情况，制定本办法。
二、全院可推荐名额及奖金：4名，10000元/人。
三、学院成立本科生奖学金评审小组。
组 长：计算机与软件学院党委书记 杨国洪
副组长：计算机与软件学院党委副书记 廖江海
计算机与软件学院副院长 杨 烜
组 员：各系主任、二年级以上（含二年级）班主任、辅导员、学生权益成员代表
四、参评基本条件：
（一）具有中华人民共和国国籍；
（二）热爱社会主义祖国，拥护中国共产党的领导；
（三）遵守宪法和法律，遵守学校规章制度；
（四）诚实守信，道德品质优良；
（五）二年级及以上全日制本科生；
（六）在校期间学习成绩优异，社会实践、创新能力、综合素质等方面特别突出；
（七）在校期间学习成绩优秀，上学年学习成绩为本专业年级前10%，参评课程无不及格科目。对于学习成绩没有进入前10%、但达到前30%的，必须在道德风尚、学术研究、创新发明、社会实践、社会工作、体育竞赛、艺术展演等某一方面表现特别优秀，具体是指：
1. 在社会主义精神文明建设中表现突出，具有见义勇为、助人为乐、奉献爱心、服务社会、自立自强的实际行动，在本校、本地区产生重大影响，在全国产生较大影响，有助于树立良好的社会风尚；
2. 在学术研究上取得显著成绩，以第一作者发表的论文被 SCI、EI、ISTP、SSCI 全文收录（须提供收录证明），以第一、二作者出版学术专著（须通过专家鉴定）；
3. 在学科竞赛方面取得显著成绩，在国际和全国性专业学科竞赛、课外学术科技竞赛、中国“互联网+”大学生创新创业大赛等竞赛中获一等奖（或金奖）及以上奖励（注：一等奖应为竞赛项目最高等级或第二等级奖项）；
4. 在创新发明方面取得显著成绩，科研成果获省、部级以上奖励或获得通过专家鉴定的国家专利（不包括实用新型专利、外观设计专利）；
5. 在体育竞赛中取得显著成绩，为国家争得荣誉。非体育专业学生参加省级以上体育比赛获得个人项目前三名，集体项目前二名；高水平运动员参加国际和全国性体育比赛获得个人项目前三名、集体项目前二名。集体项目应为上场主力队员；
6. 在艺术展演方面取得显著成绩，参加全国大学生艺术展演获得一、二等奖，参加省级艺术展演获一等奖；艺术类专业学生参加国际和全国性比赛获得前三名。集体项目应为主要演员；
7. 获全国十大杰出青年、中国青年五四奖章、中国大学生年度人物等全国性荣誉称号。
上述七方面之外，如在其他方面有同等级别的特别优秀表现，在国家奖学金评审过程中也可作为突出表现提交相关材料。
（八）获得学院推荐名额的候选人，应当配合学校或学院后续的相关工作，在各方面作出模范表率作用。
（九）根据《关于逐步将体测成绩、义工时、思政学时纳入其他本科生校级评审奖学金基本条件的通知》，自2026年秋季学期起，参评本科生国家奖学金需满足三个基本参评条件：原则上所评选学年度体测成绩及格及以上；所评选学年度义工时28小时及以上；所评选学年度思政学时达标。
五、评定流程
1. 9月11-15日，开放国家奖学金网上申报系统申请功能，学生登录网上办事大厅（http://ehall.szu.edu.cn/new/index.html），在线填写申请信息，上传学年成绩单、竞赛证书、专利证书、论文、义工时等完整佐证材料后，提交申请。
①申请人的成果中有涉及论文的，需在9月18日前填妥论文信息申请表，发送到学工办邮箱csse824@szu.edu.cn（见学校评选通知所附附件：校级奖学金--双创之星--附件3，填妥后文件命名需修改为本人姓名+学号）；
②申请表中（尤其是申请理由）的表述应当规范，如尽量不使用“国奖”等缩写，不出现“近几年”等不符合参评年度的用语。
2. 9月22日17:00前，学院评审小组组织评审。
3. 9月29日17:00前，学院完成推荐候选人名单公示（公示期为3个工作日），将推荐候选人推荐理由和院系意见通过【奖学金】模块提交，并将国家奖学金初评推荐候选人汇总名单电子版（可编辑Excel文件及签字盖章后PDF扫描件）通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
4. 10月14日前由学校学生部公示全校国家奖学金推荐获奖名单（公示期为5个工作日）；公示结束后各学院至汇昀楼306领取拟获奖学生国奖审批表纸质版，并由学院领导签字、盖章。
5. 10月24日前，学校将评审结果报上级主管部门。
六、申请与审批
（一）国家奖学金需按照学校通知规定按时在线申报及按学院要求提交材料，如有未能按时在线申报或提交材料的同学将无法参与评选。
（二）在奖学金评选期间，学院设立咨询、监督电话：0755-2653 4654。学院奖学金评选小组对本细则未尽事宜享有解释权。
