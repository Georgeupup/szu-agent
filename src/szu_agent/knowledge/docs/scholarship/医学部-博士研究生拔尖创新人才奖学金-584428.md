# 2026年度深圳大学医学部博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》（深大校发〔2024〕308号）、校长办公会有关精神，以及研究生院《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》，结合医学部实际情况，现就博士研究生拔尖创新人才奖学金评审工作实施方案通知如下：
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生），包括以下专业：
083100 生物医学工程
077700 生物医学工程（理）
107200 生物医学工程（医）
100100 基础医学
071000 生物学（医学部）
085409 生物医学工程（专）
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、一等奖与二等奖三个等级，博士研究生拔尖创新人才奖学金各等级奖励金额为：
（一）特等奖：7.7万元；
（二）一等奖：3.7万元；
（三）二等奖：1.7万元。
三、参评条件
学生申请博士研究生拔尖创新人才奖学金的基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。
（五）未受过任何校级、院级处分。
四、评定标准
按研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》中成果认定标准执行。
五、评选标准
2026年博士研究生拔尖创新人才奖学金实行总额控制，在学校预算总金额内，鼓励争先创优，并引入竞争机制。研究生院按照申请情况测算总额并报学校审批后分别设定各学院的奖学金各等级名额。各等级奖励名额以研究生院下达为准，并根据学生申请成果所属学科领域，结合全学部申报情况统筹考虑。
医学部依据学校要求成立评审委员会（具体名单详见附件1），委员会下设2个评审工作小组：评审工作组1负责基础医学专业和生物学专业拔尖创新人才奖学金评选（具体名单详见附件2），评审工作组2负责医学部其他专业奖学金评选工作（具体名单详见附件3）。
各评审小组对奖学金申请者进行评审，并对申请一等奖的学生进行排序，推优评选出特等奖。学部将对申请人的综合排名及初评结果进行公示。公示期内无异议的，学部将按流程将最终申请材料及初评结果报送至研究生院。
需特别说明：学部公示结果不是最终获奖结果，最终获奖结果以研究生院公示为准。
