# 物理与光电工程学院2025-2026学年研究生鹏程奖学金评选细则（科研成果的备注说明有更新）

根据关于开展2025-2026学年度研究生鹏程奖学金评选工作的通知，现将我院研究生2025-2026学年度研究生鹏程奖学金评选工作有关事宜通知如下：
（一）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（二） 奖励标准
研究生一次性奖励10000元。
（三） 奖励名额
根据《深圳大学2025-2026学年研究生鹏程奖学金名额分配表》（附件1），物理与光电工程学院（含微纳光电子学研究院）研究生鹏程奖学金1个名额。
（四）评选条件
1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为。
2.刻苦学习、成绩优异，在全班或全年级名列前茅。
3.具有较强的科研能力，有公开发表科研成果。
二、评审委员会：
（1）评审委员会主任：刘丽炜
（2）评审委员会副主任：罗景庭、林娜
详见（附件2）
三、评选细则：
具有强烈的学习创新意识，研究能力显著、学术成果突出，并至少具备以下条件之一：
a、在重大学科竞赛中获奖，同等条件下，按竞赛规格，获奖等级排序；
b、在国内外权威学术刊物上发表具有较高学术价值的学术论文。同等条件下按论文数量、刊物等级、影响因子大小从高到低排序；
c、科研课题或创新项目取得突出成绩，能提供相关证明材料；
d、其他学术科研创新成果，能提供相关证明材料。
四、评选程序
（一）9月14日：学校发布评选通知，启动研究生鹏程奖学金评选工作。
（二）9月14日—9月16日,学院成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定学院的评选细则、开展初步评审等工作。评选细则需在学校的总体要求下，按学院的实际情况进一步制定，并在学校公文通上予以公示。公示无异议，9月16日前将评选细则（可编辑Word文件及签字盖章后PDF扫描件）通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（三）9月14日—9月17日,所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，将相关佐证材料上传至系统附件，按照所在学院要求提交材料。
（四）9月18日—9月30日：学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。公示无异议，9月30日前将附件3《鹏程奖学金学院推荐名单汇总表》电子版通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（五）10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
五、关于科研成果的备注说明：
1.评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位（新生除外）；且同一科研成果、奖励等不得重复使用。科研成果以正式刊出或在线优先出版（Online）为准，有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传；专利应已取得专利证书。检索指引见附件4，图书馆咨询电话26537002。
2.“学术论文”，申请人应为独立作者、第一作者；若为第二作者，第一作者必须是其研究生学籍系统导师。以共同第一作者或共同通讯作者发表的论文，按照论文贡献量计算。
3. SCI检索论文的影响因子以JCR最新一期为主要参考；分区以中科院分区（2025年）为主要参考。
6. 科研成果是指申请人入学以来至2026年9月17日23:00期间所取得的成果（若科研成果在此前学院进行初步评审并获奖的国家奖学金、社会奖学金、学业奖学金的评奖中已使用过，则不能再用于参评本次评审。否则，一经发现，取消评奖资格）。根据学校规定，评审会评审时综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素，推荐综合表现突出的参评学生。
7. 对于研究生院所列出的高水平研究生学科竞赛，获奖同学自行商议竞赛贡献量，在证书复印件上写明，并由该证书的所有获奖者以及指导教师签字确认。
六、其他注意事项：
1. 我院研究生国家奖学金的评审工作，坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
2. 本办法未尽事宜，参照《关于开展2025-2026学年度研究生奖学金评选工作的通知》，并由我院研究生国家、社会奖学金评审委员会负责解释。
