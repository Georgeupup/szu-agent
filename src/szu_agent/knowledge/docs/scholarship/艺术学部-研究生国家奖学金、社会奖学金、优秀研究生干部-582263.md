# 艺术学部2025-2026学年研究生社会奖学金评审细则

为鼓励在校研究生刻苦学习、科研创新、全面发展，更好地发挥奖学金的激励和导向作用，切实推动我校校风、学风建设。根据深圳大学相关社会奖学金设置协议，现就我部2025－2026学年研究生社会奖学金评选工作通知如下：
一、 社会奖学金的名额、标准及申请条件
鹏程奖学金
1、名额及金额
研究生1人，一次性奖励10000元。
2、评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
3、评选标准
Ⅰ.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
Ⅱ.刻苦学习、成绩优异，在全班或全年级名列前茅；
Ⅲ.具有较强的科研能力，有公开发表科研成果。
二、评奖时间及流程
（1）9月14日-9月17日：符合参评条件的研究生登陆深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写后下载申请表（需双面打印）（附件1），导师签字后，扫描上传至各班通知的问卷中，逾期不予受理。
个人申请材料请填写至班级通知的问卷中，请严格按照填写规范进行填写。申请材料提交截止时间：9月17日下午23：00。
（系统开放时间为：9月12日—9月17日，逾期不开放）
（3）9月18日-9月30日：学部资格审核，学部评审委员会初评、线上审核通过后校内公示（3个工作日）上报学校（推荐名单汇总表（附件2）与个人申请表）。
（4）10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（5）对评审结果有异议的学生，可在学部公示阶段向学部评审委员会提出申诉，学部评审委员会应及时研究并予以答复。如学生对学部评审委员会做出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
（6）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
三、有关说明
（一）学术论文、科研奖项、个人荣誉等需在2025年9月1日至2026年8月31日内获得或发表（毕业年级提供录用通知书或其他获奖证明文件，评审会员会将酌情予以考虑），方可作为参评的主要依据；不得重复参评；署名单位必须为深圳大学（美术与设计学院、音乐舞蹈学院、戏剧影视学院、文化产业研究院、艺术学部均可）。有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件3，图书馆咨询电话26537002；
（二）在科研成果（论文）方面：请提供发表论文期刊封面、目录（画出个人论文）以及论文全文（无需上传整本书）的扫描件。在本专业期刊上发表学术论文或作品, 应已正式刊出并能提供期刊扫描件或检索证明（毕业年级若已出录用通知，评审委员会将酌情予以考虑），发表论文均指第一作者，若为第二作者，第一作者必须是其导师，其他作者无效；
（三）在科研成果（竞赛、专利）方面：请提供加盖公章获奖证书扫描件，比赛仅认定奖状证书，截图类的证明均不予以认定（毕业年级若已出正式盖章说明通知，评审委员会将酌情予以考虑）。除了《艺术学部研究生高水平学科竞赛目录》（附件4）所涵盖的比赛外，其他行业协会主办的比赛需评审委员会综合考量；团队竞赛只认定第一人称，若参评人员为第二人称，导师必须为第一人称；专利需取得专利证书方可，受理通知书不予采纳；
（四）评选将从学业成绩、学术论文、专业奖项及公共服务四个维度进行考量；
（五）社会奖学金之间不可兼得。若获评2025-2026学年国家奖学金，不可获评本学年社会奖学金；
（六）学部申报后，一旦发现与条件不符者即刻取消其评选资格，名额自动作废。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处；
（七）如对评议结果存在异议，需实名向评审会提出申诉，学部评审委员会应及时研究并予以答复。如学生对学部评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
