# 传播学院2025-2026学年研究生国家奖学金、社会奖学金、优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保2026年研究生奖学金评审工作公开、公平、有序进行，现将传播学院研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、研究生国家奖学金名额、奖励标准、评选对象
（一）学生部下达给我院的获奖名额及奖励金额如下：博士研究生定额1名，一次性奖励30000元；硕士研究生定额8名，一次性奖励20000元。博士研究生和硕士研究生名额均实行定额评审，校级复核确定最终人选。
（二）评选对象：传播学院2024、2025级在校研究生（延期毕业的研究生除外）。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习成绩优异，科研能力显著，发展潜力突出。
三、评选细则
（一）评奖实行计分制，具体计分细则参见《深圳大学传播学院研究生综合类评奖评优评审细则（国家奖学金、社会奖学金、荔研优学、优秀毕业生等）》（附件1）。最终按计分排序决定上报名额。
（二）科研成果是指从2025年9月1日起至2026年8月31日期间取得的并署名我校的成果（2024级毕业班成果计算时限延长至9月14日）。如果在此期间取得的科研成果在学院的评奖中已使用过，此次评奖则不予计入（即不能重复使用）。
（三）论文以正式刊发为准。用稿通知不计入参评条件，但可作为辅助参考。
（四）申请人学位课或必修课各科考核成绩达60分以上（含60分）且平均分达到75分以上（含75分）。
贰·研究生社会奖学金
一、研究生鹏程奖学金
（一）研究生鹏程奖学金名额、奖励标准、评选对象
1.鹏程奖学金名额及奖励金额：学生部下达给我院的获奖名额共1名。一次性奖励10000元，名额实行定额评审，校级复核确定最终人选。
2.评选对象：传播学院2024、2025级在校研究生（延期毕业的硕士研究生除外）。
（二）参评条件
1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2.刻苦学习、成绩优异，在全班或全年级名列前茅；
3.具有较强的科研能力，有公开发表科研成果。
（三）评选细则
1.评奖实行计分制，具体计分细则参见《深圳大学传播学院研究生综合类评奖评优评审细则（国家奖学金、社会奖学金、荔研优学、优秀毕业生等）》（附件1）。最终按计分排序决定上报名额。
2.科研成果是指从2025年9月1日起至2026年8月31日期间取得的并署名我校的成果（2024级毕业班限延长至9月14日）。如果在此期间取得的科研成果在学院的评奖中已使用过，此次评奖则不予计入（即不能重复使用）。
3.论文以正式刊发为准。用稿通知不计入参评条件，但可作为辅助参考。
4.申请人学位课或必修课各科考核成绩达60分以上（含60分）且平均分达到75分以上（含75分）。
叁·优秀研究生干部
一、优秀研究生干部名额、奖励标准、评选对象
（一）学生部下达给我院的获奖名额共8名。优秀研究生干部名额实行定额评审，校级复核确定最终人选。申请人数超出研究生管理部门下达名额的，同等条件下优先推荐成果突出的参评者，符合评奖条件的申请人数达不到研究生管理部门下达名额的，奖项名额自动空缺。
（二）优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
（三）评选对象：传播学院2024、2025级在校研究生（延期毕业的硕士研究生除外）。
二、参评条件
优秀研究生干部主要奖励优秀的学院研究生干部在社会工作中表现突出的个人。参选人须同时满足下列条件：
1.热爱社会主义祖国，拥护中国共产党领导；
2.遵守国家法律法规和校规校纪；
3.践行社会主义核心价值观，道德品质优秀；
4.学习态度端正，所有必修课程全部通过；
5.参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
6.任职期间有突出工作表现，能提供典型材料及例证。

## 附件：深圳大学传播学院研究生奖学金评审细则

深圳大学传播学院研究生综合类评奖评优评审细则

（国家奖学金、社会奖学金、荔研优学、优秀毕业生等）

一、评定原则

为全面衡量研究生综合能力素质，传播学院各类评奖评优采用“先综合考评，再提交学院奖学金评审委员会审议”的评定方式，综合考评系对研究生在评选期内的“学业成绩、学术成果、获奖情况”三个方面分别计分，加总得分即为综合考评成绩，是委员会审议的重要参考条件。学院评委会根据校研究生奖学金评定工作《通知》和《管理办法》进行现场评定并给出相应结论，确保评审程序和结果的公开、公正和公平。

二、参评对象

被我院正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。

三、参评条件

（一）热爱社会主义祖国，拥护中国共产党的领导；

（二）遵守国家法律法规，遵守学校规章制度；

（三）诚实守信，品学兼优；

（四）所修课程全部通过，且学位课程平均成绩达到80分以上（含80分）；

（五）积极参与科学研究和社会实践。

四、评审细则

（一）综合考评计算公式和说明

综合考评的三大项采用百分制计算，公式如下：

研究生综合考评成绩

= 学业成绩综合分×35% + 学术成果综合分×35% + 获奖综合分×30%

1.根据评奖评优的项目时间及性质差异，计算荣誉的时间区间将做合理调整。

2.送稿中或评审中的未接收文章不计为科研成果。

3.所有学术成果均需以深圳大学为第一署名单位。

（二）学业成绩综合分

参评研究生所修课程须全部通过，且学位课程平均分在80分以上（含80分），成绩排名、绩点以研究生院提供的数据为准。
