# 法学院2025-2026学年度研究生国家奖学金、社会奖学金及优秀研究生干部评选细则

根据《关于开展2025-2026学年度研究生奖学金评选工作的通知》的文件要求，为促进我院研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我院2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
壹·研究生国家奖学金一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
三、名额分配
法学院硕士研究生国家奖学金名额为9名，博士研究生1名。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）诚实守信，道德品质优良；
（四）学习成绩优异，科研能力显著，发展潜力突出。
五、评选细则
见附件2
贰·研究生社会奖学金一、鹏程奖学金
（一）名额及金额
法学院研究生奖励名额为1名，一次性奖励10000元。
（二）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（三）评选条件
1、热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2、刻苦学习、成绩优异，在全班或全年级名列前茅；
3、具有较强的科研能力，有公开发表科研成果。
（四）评选细则
见附件2
叁·优秀研究生干部一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
三、奖励名额
校级优秀研究生干部奖励名额为8名。
四、参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任院级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。

## 附件：法学院研究生奖学金评选细则

法学院研究生国家奖学金、社会奖学金评定细则

第一条 目的与依据

为促进我校研究生培养机制改革，提高研究生培养质量，确保我校研究生国家奖学金评审工作公开、公平、有序进行，根据财政部、教育部《学生资助资金管理办法》、深圳市相关规定和《深圳大学研究生国家奖学金评审办法》有关精神及要求，结合我院情况就国家研究生奖学金、社会奖学金评定制定本细则。

第二条 评审原则

国家研究生奖学金、社会奖学金评选应公开、公正和公平。

第三条 评审委员会

法学院成立国家研究生奖学金、社会奖学金评审委员会，由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员。

第四条 参评对象

攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。

硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。

第五条 参评条件

研究生申请奖学金应当符合下列条件：

（一）热爱社会主义祖国，拥护中国共产党的领导；

（二）遵守宪法和法律，遵守高等学校规章制度；

（三）诚实守信，道德品质优良，没有任何违法违纪行为，没有受到过国家和学校的各类处分；

（四）学习成绩优异，科研能力显著，发展潜力突出；

（五）参评学生除了满足以上条件外，还需满足下列条件之一：

1.在SSCI/SCI、CSSCI/SCI、CSSCI扩展版、核心期刊上公开发表一篇及以上学术论文（申请人为第一作者或者通讯作者；若为第二作者，第一作者必须是其导师）；

2.在非核心期刊上公开发表一篇以上学术论文（发表论文署名的作者单位须为深圳大学法学院，申请人为第一作者或者通讯作者；若为第二作者，第一作者必须是其导师）；

3.获得市级以上（含市级）学科竞赛奖励；

4.其它有特殊贡献或者有突出贡献的。

（六）研究生出现以下情形之一的，不具备当年研究生奖学金参评资格：

1.参评学年违反国家法律法规、校纪校规受到纪律处分者或往年受到纪律处分尚未撤销的；

2.有抄袭剽窃、弄虚作假等学术不端行为经查证属实的；

3.参评学年学籍状态处于休学、保留学籍的；

4.出现挂科情况，即有课程成绩低于60分；

5.学位课程平均成绩低于75分。

第六条 奖学金综合成绩评定办法

奖学金评审采用综合考评方式，采取量化评分制度，对研究生在评选期内的“学业成绩、科研成果、获奖情况、社会实践与服务和学风道德表现”五个方面分别评分（分数计算保留小数点后两位），具体计算公式如下：

研究生综合考评成绩=学业成绩得分（申请人所修必修课程平均分×20%）+科研成果得分（申请人科研成果累计得分×60%）+获奖得分（申请人获奖累计得分×15%）+社会服务与实践得分（申请人社会服务与实践的累积得分×5%）-学风道德表现扣分。

第七条 学业成绩

申请人的学业成绩得分=申请人所修必修课平均分×权重

第八条 科研成果

科研成果得分以学术论文、专著、主持参与课题研究的分数为计算依据。科研成果得分=该生科研成果累计得分×权重

（10）提交材料时，需要提交论文和专著的封面、目录以及个人发表部分的复印件，并且在目录和发表部分需要能看到申请人的信息。

（二）研究项目

列入计算的课题分为学生本人主持的科研项目和学生参与的教师研究项目。申请人的信息必须明确地在项目下达批准书/盖章立项书或签订的课题合同的课题组成员中列示和排序才能列入加分项。（成员中无申请人的信息、单位和老师的证明以及结项证明均无效）

学生本人主持的研究项目，该项目计分基数按国家级、省部级、市厅级、校级（校级平级单位）、院级分别记 80分、50分、30分、20分、10分。

（2）学生参与教师研究项目，至多可报 2 项，该项目计分基数按国家级、省部级、市厅级、校级（校级平级单位）分别记 5分、4分、3分、2分。

以比赛实践为目的的项目不能在“项目综合分”模块中算分，例如校团委的社会实践、攀峰等，该类只以获奖后按奖项加分。

第九条 获奖

该生的获奖得分=该生获奖累计得分×权重。

申请者的获奖分为Ⅰ类、Ⅱ类，Ⅰ类获奖计算得分参照下表“奖励级别”和“获奖名次”，Ⅱ类获奖按 I 类获奖得分 50%计算。

Ⅰ类：学术年会获奖、各类学术比赛获奖（如模拟立法大赛、社研杯、法学相关征文等相关、要求必须是以提交论文或调研报告参加的获奖）以及学科各类竞赛（参考《深圳大学研究生参加高水平学科竞赛资助奖励办法》《法学院本科生学科竞赛管理方法》附件8中与专业培养相关的竞赛）。

Ⅱ类获奖：除Ⅰ类的获奖，包括知识竞赛、演讲比赛、文体活动等，最多提交2项。

## 附件：法学院优秀研究生干部评选工作细则

法学院优秀研究生干部评选工作细则

一、参评对象

优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。

直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。

二、奖励标准

为校级优秀研究生干部颁发证书，奖励每生每年2000元；为院级优秀研究生干部颁发证书。

三、奖励名额

（一）校级：8人。

（二）院级：根据具体学生干部数量按照实际工作情况决定。

四、参评条件

优秀研究生干部奖主要奖励优秀的院级研究生干部或学院社团组织负责人以及在社会工作中表现突出的个人，校研究生会等干部由相关管理部门单列评选，不参与学院的评选。参选人须同时满足下列条件：

（一）热爱社会主义祖国，拥护中国共产党领导；

（二）遵守国家法律法规和校规校纪；

（三）践行社会主义核心价值观，道德品质优秀；

（四）学习态度端正，所有必修课程全部通过；

（五）担任院级研究生干部、学生社团组织负责人累计满一年，或在公益组织中服务满一年；

（六）任职期间有突出工作表现，能提供典型材料及例证。

六、申报程序

（一）9月11日—9月16日：学院成立评审委员会（名单见附件），公布评选细则。

（二）9月14日—9月17日：所有符合参评条件并有意愿申请的研究生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写申请表，填好后打印，本人签名，经导师（推荐人）签字后和工作总结表（附件4）于9月17日15:00前交至沈老师处，过期不候。

（三）9月18日—9月30日：学院评委会审核个人申报材料、公示推荐名单，如无问题向学生部报送相关材料。

七、注意事项

（一）学院评审委员会对推荐人选进行资格审核，结合推荐人选的工作表现和书面总结进行综合评审。

（二）研究生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。

（三）未尽事宜，由学院评委会根据学校和学院的相关规定解释。
