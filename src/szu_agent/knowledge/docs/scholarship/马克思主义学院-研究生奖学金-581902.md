# 马克思主义学院2025-2026学年度研究生奖学金评审细则

根据《学生资助资金管理办法》（财教〔2021〕310号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、参评对象
深圳大学马克思主义学院攻读硕士学位的全日制研究生（延期毕业的研究生除外）。
二、奖励标准
研究生国家奖学金由中央财政出资设立，硕士研究生国家奖学金奖励标准为每生每年2万元。
三、奖励名额
全院共2人。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）诚实守信，道德品质优良；
（四）学习成绩优异，科研能力显著，发展潜力突出。
五、评选细则
（一）国家奖学金的评定内容包含学生在思想品德、课业成绩、学术科研、公共服务、社会活动参与等方面的综合表现情况。
（二）评选侧重学生的科研能力，以参评者在CSSCI来源期刊及其扩展版和核心期刊上发表的学术论文的数量为重要依据（CSSCI来源期刊优于扩展版期刊，CSSCI扩展版期刊优于核心期刊，且以南京大学图书馆和北京大学图书馆的最新版本为准）。参评论文均指参评人为第一作者，若为第二作者，则第一作者必须为其导师。
（三）科研成果是指从入学之日起至2026年8月31日期间取得的并署名我院的成果。如果在此期间取得的科研成果在以前学院的评奖中已使用过，此次评奖则不予计入（即不能重复使用）。
（四）论文以正式刊发为准。用稿通知不计入参评条件，但可作为辅助参考。
（五）申请人所修课程须全部通过，所修必修课程加权平均成绩不低于75分。
六、评选流程
（一）9月14日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月14日-9月16日：成立马克思主义学院研究生奖学金评审委员会（以下简称院评审委员会），由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，院评审委员会负责制定本学院评选细则。
（三）9月14日-9月17日：所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件2）至系统，打印申请材料，学生本人签名，附相关成果复印件，经导师（推荐人）签字，送交文科楼2614办公室。个人申报材料包括：
1.《研究生国家奖学金申请审批表》（申请表需双面打印）；
2.课程成绩单复印件（必修课加权平均成绩不低于75分）；
3.导师（推荐人）签字的科研成果材料（承担科研项目及获奖证书复印件、发表论文期刊封面、目录、论文首页复印件，深圳大学图书馆提供并盖章的收录证明）；
4.导师（推荐人）签字的获奖证书复印件及其他可证明本人优异表现的证明材料。
申报材料需由申请人于9月17日17:00前，将上述材料依序装订后送交文科楼马克思主义学院2614室边老师，逾期概不受理。
同时申请人还需在《马克思主义学院2025-2026学年度研究生奖学金申请人信息汇总表》（见附件3）中选择“国家奖学金工作表”按要求填写完成，并将该表格的电子版在9月17日17:00前发送至邮箱：（手机号已省略，见原通知）@163.com。
（四）9月18日-9月30日：学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“奖学金管理”系统中完成线上审核。公示无异议后，学院将初审名单提交学生部，由校评审委员会最终审定。
（五）10月8日-10月14日：学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
贰·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的2024、2025级研究生（延期毕业的硕士研究生除外）。
二、奖励标准
优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
三、奖励名额
优秀研究生干部获奖名额：2名
四、参评条件
优秀研究生干部主要奖励优秀的学院研究生干部在社会工作中表现突出的个人。参选人须同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院研究生干部、学校社团组织负责人累计满一年；
（六）任职期间有突出工作表现，能提供典型材料及例证。
五、评选流程
（一）9月14日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月14日-9月16日：成立马克思主义学院研究生奖学金评审委员会（以下简称院评审委员会），由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，院评审委员会负责制定本学院评选细则。
（三）9月14日-9月17日：所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写《深圳大学优秀研究生干部申请、审批表》（申请表需双面打印），填好后打印申请材料，学生本人签名，附相关成果复印件，经导师（推荐人）签字。申报材料需由申请人于9月17日17:00前，将上述材料依序装订后送交文科楼马克思主义学院2614室边老师，逾期概不受理。
同时申请人还需在《马克思主义学院2025-2026学年度研究生奖学金申请人信息汇总表》（见附件3）中选择“优秀研究生干部工作表”按要求填写完成，并将该表格的电子版在9月17日17:00前发送至邮箱：（手机号已省略，见原通知）@163.com。
（四）9月18日-9月30日：学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“奖学金管理”系统中完成线上审核。公示无异议后，学院将初审名单提交学生部，由校评审委员会最终审定。
（五）10月8日-10月14日：学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
