# 生命与海洋科学学院2026年深圳大学研究生学业奖学金评选细则

根据学生部《关于组织开展深圳大学2026年研究生学业奖学金评审工作的通知》和《深圳大学研究生学业奖学金管理办法（修订）》等文件精神，结合我院实际，特制定本评选细则。
一、参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1．第一学年，所有推免生、一流大学建设高校（42所名单见附件8）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；2026级学业奖学金参评学生根据招生办公室发布的研究生入学综合成绩分专业进行排名，相同排名下优先一流大学建设高校和本校的应届毕业生。
2．第二学年，所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。2025级参评学业奖学金的学生要求所修课程全部通过，无挂科课程。学院根据研究生培养系统提供的研究生平均成绩进行排名，排名相同下，综合考虑思想品德、学业成绩、科研成果和社会实践（包括科技竞赛、文体比赛、参加义工服务、担任学生干部及其他实践活动）等因素展开评定。
3.第三学年，所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。2024级参评学业奖学金的学生要求所修课程全部通过，无挂科课程，根据参评研究生的思想品德、科研成果、学业成绩和社会实践（包括科技竞赛、文体比赛、参加义工服务、担任学生干部及其他实践活动）等因素进行综合评定。
所有科研成果的第一署名单位均需是深圳大学生命与海洋科学学院。研究生学业奖学金参评的各类科研成果均为研究生阶段取得的，认定的截止时间为2026年 9 月1 日（毕业班研究生科研成果认定时限开延迟至2026年9月30日），超出该时间段的成果及获奖不得计入当年学业奖学金评定，且科研成果不得为上次获奖使用过的成果。学业奖学金成果评分按照附件中《生命与海洋科学学院研究生学业奖学金科研成果计分方法（2026年）》进行评定。
3. 名额分配：
1)

一等奖学金：生物学3名、生态学2名、生物技术与工程24名；
二等奖学金：生物学7名、生态学3名、生物技术与工程48名；
2)
2025级研究生：
一等学业奖学金：生物学8名、生态学2名、生物技术与工程25名；
二等学业奖学金：生物学16名、生态学4名、生物技术与工程50名；
3)
2024级研究生：
一等学业奖学金：生物学11名、生态学5名、生物技术与工程17名；
二等学业奖学金：生物学22名、生态学9名、生物技术与工程35名；
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
四、学院评审流程
（一）9月16日：学生部公布研究生学业奖学金评选工作通知，下达获奖名额。其中2026级硕士研究生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定；余下参评的一、二等奖学金由我院根据本细则按名额评定。
（二）9月17日—9月22日：学院评审委员会在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。学院评审委员会名单及评选细则需在学校公文通上予以公布，公示期至9月22日17点，公示无异议，9月22日前将评审委员会名单、评选细则通过“一网通办”平台报送学生部备案。
（三）9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，（每人只需申请一个学业奖学金等级，最终是否获奖以及获奖等级由学业奖学金评审委员会决定）提交后打印，本人签名，按学院要求将所需材料交到本班班长，班长收齐后在10月8日17点前送交学院评审委员会联络人。（学业奖学金申请系统开放时间9月23日8:00—9月30日23:00）
（四））10月8日—10月21日：学院组织评审会，对申请研究生学业奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“学业奖学金管理”系统中完成线上审核。公示无异议后，将学院学业奖学金评审材料通过“一网通办”平台报送学生部。
五、有关说明及注意事项
（一）参评研究生学业奖学金所涉及的科研成果、奖励等认定截止时间为2026年9月1日，针对毕业班研究生，学院可根据实际情况适当放宽，并在学院具体细则中体现。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（三）硕士研究生（包括特等和一等认定的研究生）需网上申报，学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单（新生不需要），其他按需上传，并按学院要求提交个人申报材料。
（四）对认定或评审结果有异议的学生，可在学院公示阶段向所在学院评审委员会提出申诉，学院评审委员会应及时研究并予以答复。如学生对学院评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
（六）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策,以及校内其他研究生奖助政策资助。
（七）本细则未尽事宜，由我院研究生学业奖学金评审委员会负责解释。

## 附件：生命与海洋科学学院研究生学业奖学金科研成果计分方法（2026年）

生命与海洋科学学院研究生学业奖学金科研成果计分方法（2026年）

一、科研成果认定

科研成果包括以下类型：正式发表（含在线发表）的论文、已发表的会议论文、已取得授权专利、已通过结项的科研项目、学科竞赛获奖项目等。凡是涉及有署名的，要求第一署名单位为“深圳大学生命与海洋科学学院”。均要求本人为第一作者。若第一作者为导师，本人为第二作者，在评审时均视为第一作者（注：导师以研究生院备案导师为准）。若为共同第一作者，计分按共同一作人数均分。SCI 检索论文的分区及影响因子以校图书馆所能检索到的中科院分区（CAS分区）最新一期为准，以大类分区为准。科研成果认定时限为入学至2026年9月1日，毕业班研究生科研成果认定时限为入学至2026年9月30日。

二、科研成果分数计算细则

1. SCI论文加分

大类分区基础分：一区：8分；二区：5分；三区：3分；四区：2分。

影响因子附加分（基于最新影响因子区间）：

IF ≥ 15：+5分

10 ≤ IF < 15：+3分

5 ≤ IF < 10：+2分

IF < 5：+1分

总加分 = 分区基础分 + 影响因子附加分。

示例：一区论文，IF=12 → 8（分区）+3（IF附加）= 11分

2. 中文期刊论文加分

中文核心期刊：2分；

中文非核心期刊：1分。

3. 会议论文加分

国际会议2分，全国会议1分；省市级会议0.5分；校级会议0.3分。

4. 专利加分

国际专利：5分；

中国发明专利：4分（PCT申请额外加1分）；

中国实用新型专利：2分；

中国外观设计专利：2分。

5. 学科竞赛加分

| 级别 | 一等奖 | 二等奖 | 三等奖 | 优胜奖 |
| --- | --- | --- | --- | --- |
| 国家级 | 8分 | 7分 | 6分 | 5分 |
| 省级 | 6分 | 5分 | 4分 | 3分 |
| 市级 | 4分 | 3.5分 | 3分 | 2.5分 |
| 校级 | 3分 | 2.5分 | 2分 | 1.5分 |

说明：

分赛区按下一级行政单位标准加分（如国家级分赛区按省级标准）。

6. 科研项目加分

国家级项目：10分；

省级项目：8分；

市级项目：6分；

校级项目：3分。
