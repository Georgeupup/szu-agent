# 生命与海洋科学学院2025-2026学年度研究生奖学金评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号），为促进我院研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我院2026年研究生奖学金评审工作公开、公平、有序进行，现特制定生命与海洋科学学院研究生国家奖学金和优秀研究生干部的评选细则如下：
壹·研究生国家奖学金
一、评选对象
我院攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。硕博连读研究生在注册为博士研究生之前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年3万元；硕士研究生国家奖学金奖励标准为每生每年2万元。
三、名额分配
我院有1个博士国家奖学金名额和11个硕士国家奖学金名额，学院实行定额定项评审，校级复核确定最终人选。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）诚实守信，道德品质优良；
（四）学习成绩优异，科研能力显著，发展潜力突出。所修课程全部通过，无重修记录，学位课程平均成绩达到 75 分以上（含 75 分）；科研要求：公开发表（含在线发表）本专业学术论文或会议论文不少于1篇（学生本人为第一作者，若导师是第一作者的，该论文第二作者必须为学生本人。）或以第一发明人，或者导师为第一发明人，学生本人为第二发明人，获得本专业相关已授权发明专利1项以上专利。所有科研成果，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
参评论文、专利授权及竞赛获奖时限为：当前研究生身份入学日至2026年9月17日。研究生参评国家奖学金的所有成果，必须符合《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》的要求。
五、评选要求
（一）学院研究生国家奖学金评审委员会根据学校参评条件制定本学院评选细则，并在全校范围内公布。
（二）学院制定评选细则时应综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素。
贰·社会奖学金
一、鹏程奖学金
（一）名额及金额
我院研究生1人，一次性奖励10000元。
（二）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（三）评选标准
1、热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2、刻苦学习、成绩优异，在全班或全年级名列前茅；
3、具有较强的科研能力，有公开发表科研成果。成果署名要求和时限要求与我院研究生国家奖学金的要求相同。
叁·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我院正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
三、奖励名额
此次学校下达给我院的优秀研究生干部名额11人。
四、参评条件
优秀研究生干部主要奖励优秀校、院级研究生干部或学校社团组织负责人以及在社会工作中表现突出的个人。参选人须同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的院内评选安排如下：
一、评选程序
（一）9月11日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月11日—9月16日：学院成立研究生奖学金评审委员会（以下简称院评审委员会），由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，同时成立由院研究生会、研究生党支部、研究生班委组成的学生初评小组。院评审委员会负责制定学院评选细则及答辩小组组成。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。院评审委员会名单（附件2）及评选细则需在学校公文通上予以公示，公示期到9月16日17时。公示无异议，9月16日前将评选细则及评审委员会名单电子版通过“一网通办”平台提交到学生部。
（三）9月14-17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4，可下载系统生成的文档）至系统，按照学院要求送交院评审委员会联络人。申报各类奖项时，相关佐证材料均需上传至系统附件（评选时学生无需提交纸质版佐证材料）。
（四）9月18日—9月30日：院评审委员会对本学院申报者进行资格审核，学生初评小组（由院学生会干部、研究生党支部委员、班委等研究生代表组成）对申请人申报材料进行合规审核并进行初评，形成初评名单上报院评审委员会。院评审委员会组织奖学金评选答辩会，确定学院研究生奖学金推荐名单。确定学院推荐名单，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。国家奖学金公示期不少于5个工作日，社会奖学金和优秀研究生干部公示期可由学院酌情安排。公示无异议后，学院评审委员会负责上报评审材料电子版通过“一网通办”平台上报学生部。
（五）对评审结果有异议的学生，可在学院公示阶段向学院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
二、其他事项
（一）社会奖学金之间不可兼得，研究生国家奖学金与社会奖学金不可兼得。科研成果、奖励已用做研究生阶段评奖并获奖的不得重复使用。
（二）论文应已正式刊出，有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传和打印。检索指引见附件3，图书馆咨询电话26537002。
（三）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
（四）研究生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
（五）获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
（六）本评选细则由学院研究生奖学金评审委员会解释。

（五）对评审结果有异议的学生，可在学院公示阶段向学院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
