# 管理学院2026年本科生国家励志奖学金及助学金评选细则

根据学校《关于开展2026年本科生助学金评选工作的通知》和《关于开展2026年国家励志奖学金评选工作的通知》，结合我院家庭经济困难学生的实际情况，现就开展我院2026年国家励志奖学金、助学金评定工作通知如下：
一、体系构成
1. 国家励志奖学金
2. 政府助学金：国家助学金。
3. 社会助学金：中集助学金。
二、国家励志奖学金申请条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党领导；
4.遵守宪法和法律，遵守学校规章制度，无违纪行为；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，上学年成绩排名至少在前50%；
三、助学金获助资格条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱社会主义祖国，拥护中国共产党领导；
4.遵守宪法和法律，遵守学校规章制度；
5.诚实守信，道德品质优良；
6.学习勤奋，生活俭朴，积极向上；
7.符合各类助学金的其他评选要求。
8.知晓并承诺履行助学金获助学生义务。
四、评定原则
1.社会助学金不可兼得。
2.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
3.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。

六、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请。助学金申请系统于10月19日开通，10月22日上午9:00关闭，逾期不予申请。
2.学院成立助学金评定小组，在评选过程中坚持公平、公正、公开的原则，按照学院评选细则，严格审查申请学生资格，确定拟获资助名单。学院于11月3日前完成各项助学金网上审核及公示（3个工作日）。
3.学生部将于11月4日起对学院上报的材料进行审核并对审核后的名单进行公示（公示期为5个工作日）。
七、有关说明及注意事项
1.超过基本修业年限的学生不再享受国家助学金。
2.国家助学金和国家励志奖学金可以兼得。
