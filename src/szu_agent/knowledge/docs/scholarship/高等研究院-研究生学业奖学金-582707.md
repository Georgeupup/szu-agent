# 高等研究院2026年研究生学业奖学金评定细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合我院实际情况，制定深圳大学高等研究院研究生学业奖学金评定细则。
一、参评对象被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、基本参评条件1. 热爱社会主义祖国，拥护中国共产党的领导；
2. 遵守国家法律法规，遵守学校规章制度；
3. 诚实守信，品学兼优；
4. 所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
5. 积极参与科学研究和社会实践。
6. 研究生出现以下情形之一的，不具备当年参评资格：
（1）参评学年违反国家法律法规、校纪校规受到纪律处分者或往年受到纪律处分尚未撤销的；
（2）有抄袭剽窃、弄虚作假等学术不端行为经查证属实的；
（3）参评学年学籍状态处于休学、保留学籍的。
三、奖励标准及要求（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15000元，一等10000元，二等5000元。硕士研究生学业奖学金只在标准学制年限内参评。
1．第一学年，所有推免生、一流大学建设高校（42所名单见附件4）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
2．第二学年及以后，所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。

（四）评定标准：1.第一学年评定：
统考生，综合考虑其统考初试成绩及复试成绩，兼顾其在本科阶段取得的突出成绩展开评定。
2.第二学年及以后，综合考虑思想品德、学术成果、学业成绩和社会实践（包括科技竞赛、文体比赛、参加义工服务、担任学生干部及其他实践活动）等因素展开评定。
四、日程安排（1）9月17日—9月22日：学院成立研究生学业奖学金评审委员会，在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。评审委员会组成人员人数一般为不少于 7 的单数，主任委员由学院主要领导担任，委员由研究生导师、相关管理人员、研究生代表担任，院评审委员会名单(附件3）。本细则公示期至2026年9月22日12:00。
（2）9月23日8:00—9月30日23:00：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，提交后打印申请表、本人签名，按学院要求将所需材料及时送交所在院评审委员会联络人。
（3）10月8日—10月21日：院评委会审核个人申报材料、公示推荐名单，公示无异议后，向学生部报送材料。
（4）10月21日后：学生部审核、公示获奖名单，报校领导审批。
六、有关说明及注意事项（1）申请流程：
①硕士研究生（包括特等和一等认定的研究生）、学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单，其他按需上传。
②所有参评研究生需提交个人纸质申报材料。个人申报材料包括：系统申请后双面打印的《研究生学业奖学金申请审批表》及相关证明材料，申请表需本人签名，导师（推荐人）签字。其中直接认定等级的2026级硕士研究生和各年级博士研究生仅需线上申请并提交纸质申请表。纸质材料提交地点：致知楼208；提交截止时间：2026年9月30日17:00。
③申请学业奖学金一等奖、二等奖的硕士研究生需于2026年9月30日17:30前填写在线问卷汇总个人成果（链接：【腾讯文档】2025-2026学年研究生学业奖学金个人成果汇总
https://docs.qq.com/form/page/DVVZsc1hxU3RQekNr）。
说明：申请学业奖学金一等奖、二等奖的硕士研究生必须同时完成上述①②③的内容。
（2）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。（2026级新生除外）
（3）每人只能申请一个等级的奖学金，必须在规定时间内申请，逾期视为放弃评选资格，最终等级由学院评审委员会确定；
（4）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策，以及校内其他研究生奖助政策资助。
（5）2024级同学科研成果、刊物发表、会议等计算时限为：2025年9月1日至2026年9月30日；2025级同学科研成果、刊物发表、会议等计算时限为：2025年9月1日至2026年8月31日；2026级同学科研成果、刊物发表、会议等计算时限为本科阶段。一般情况下，参评成果必须是已经刊登或授权成果，不包含录用通知，毕业年级研究生科研成果可包含录用通知。
（6）对认定或评审结果有异议的学生，可在学院公示阶段向院评审委员会提出申诉，院评审委员会将及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
