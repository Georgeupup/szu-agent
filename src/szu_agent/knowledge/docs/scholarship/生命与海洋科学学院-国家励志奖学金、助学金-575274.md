# 生命与海洋科学学院2025-2026学年度院内奖学金、助学金评定细则

为鼓励学生刻苦学习、积极创新、全面发展，同时更好地发挥奖助学金的激励和导向作用，切实推动我院院风、学风建设，我院将开展2025-2026学年度院级奖学金评选工作。现就我院2025－2026学年度院级奖助学金评选工作通知如下：
一、院级奖、助学金体系构成
（一）院士奖、助学金
1.奖学金：
硕士研究生，4名(含优秀学生干部1名)，2000元/人。
本科生，本科生8名（含优秀学生干部2名；专业竞赛获省级以上奖励名额单列），1500元/人。
2.助学金：1000元/人。
（二）“豫”见未来奖学金
硕士研究生，3名，2000元/人。
本科生，6名，1500元/人。
（三）南极熊创业奖学金
资助学生项目数量根据每年申请学生情况而定，每年评选创业项目按每项给予2000元-10000元奖励。
二、院级奖、助学金评选要求
（一）院士奖、助学金
（1）本科生评选条件
1. 综合素质评价优良。
2. 全日制二年级以上(含二年级) 在校注册的本科生，原则上评选学年度所有课程必须及格（2025-2026学年）,没有违纪处分记录。学业成绩在同年级同专业排名前20%。
3. 在满足上述条件基础上，符合下列条件按下列条件顺序优先考虑：
① 凡参加各类竞赛（附件二）获省级二等奖及以上奖励的，按竞赛规格、获奖等级顺序排列，团体获奖的，按获奖证书位次排列。
② 发表学术论文等科研成果的（奖学金申请人为唯一第一作者或第二作者（导师为唯一第一作者），若论文存在共同第一作者情况，则该篇论文只计 1/N 篇，其中 N 为共同第一作者数量；论文的第一署名单位必须是深圳大学生命与海洋科学学院），按论文数量、刊物等级从高到低依次排列。
4. 若在某一方面或领域有突出的特质或成果的同学，可以不受上述条件限制。
5. 助学金评选条件：成绩优良，在同年级同专业排名前20%，家庭经济特别困难。
6. 注意事项：
学生干部单列：担任学生干部，参与学校及学院学生工作，表现突出，依据其日常工作表现、所获成绩、所获奖励级别依次排列。
竞赛奖项单列：在省级“挑战杯”竞赛中获一等奖以上，在国家级“挑战杯”竞赛中获二等奖以上团队核心成员（不超过3人），将获得院士奖学金。(国际级专业竞赛参照国家级)
（2）硕士研究生评选条件
1. 全日制二年级以上(含二年级) 在校注册的硕士研究生。
2. 综合素质评价、学位必修课成绩优良，考查课程全部通过, 没有违纪处分记录。
3. 在本专业领域期刊发表学术论文或获得高水平学科竞赛（附件一、二）省级二等奖及以上奖励的。论文成果按论文数量、刊物等级从高到低依次排列。（奖学金申请人为唯一第一作者或第二作者（导师为唯一第一作者），若论文存在共同第一作者情况，则该篇论文只计 1/N 篇，其中 N 为共同第一作者数量，论文的第一署名单位必须是深圳大学生命与海洋科学学院）；竞赛奖励按竞赛规格、获奖等级排序。
4. 在满足上述条件基础上，担任科研课题组成员、助教、学生干部，参与其他社会工作表现突出，依其所获成绩、所获奖励级别从高到低依次排列。
5. 学生干部单列：担任学生干部，参与学校及学院学生工作，表现突出，依据其日常工作表现、所获成绩、所获奖励级别依次排列。
（二）“豫”见未来奖学金
本科生：全日制二年级以上(含二年级) 在校注册的本科生，须满足2025-2026学年度所有课程成绩合格、综合成绩排名同年级同专业前30%、无违纪处分记录。满足上述条件者中，参加高水平学科竞赛（附件二）获省级二等奖及以上奖励者优先考虑（竞赛奖励按竞赛规格、获奖等级排序）。
研究生：全日制二年级以上(含二年级) 在校注册的硕士研究生，须同时满足以下要求：在校期间所修课程全部通过且无重修记录、必修课程平均成绩≥75分、无违纪处分记录，并参加高水平学科竞赛（附件二）获省级二等奖及以上奖励（竞赛奖励按竞赛规格、获奖等级排序）。
（三）南极熊奖学金
热爱祖国、遵纪守法、品行端正、积极实践、勇于创新、成绩突出，没有违法违纪行为。符合下列条件之一者：
（1）所负责的创业项目在深港大学生创新创业基地（深圳大学创业园）等平台内成功立项或运行良好；
（2）所负责的创业项目符合国家产业、技术政策，技术含量较高，创新性较强，已有成熟可行的《创业项目计划书》等；
（3）作为项目的核心队员，参加创业类竞赛，成绩优异，获得省级以上官方或行业（行业普遍认可的）竞赛二等奖及以上者。
（4）特别说明：
1.以团队参赛的，只接受作为团队核心成员的生命与海洋科学学院学生进行申报，如获评奖，则以整个项目团队为单位获颁奖学金，奖金用作团队推进创业项目使用。
2.每个项目团队填一份申请表，不得重复申请。
3.若同一成果获得不同等级奖项，仅以最高奖项参评。
三、评定工作原则
（一）将本学年度院士奖助学金、“豫”见未来奖学金、南极熊奖学金纳入统一的奖学金评选体系，统筹规划、同步评选。
（二）本科生申报各类奖学金，均需满足各类奖学金《深圳大学本科生先进个人评选及奖学金评定办法（修订）》第三条中规定的评选资格条件。
（三）在校期间曾获得同一院级奖学金原则上不再参评，同一评选年度，院内奖学金原则上不能兼得。
（四）院级奖学金仅能选取一项申报。
（五）本细则中所有的成果认定时间为2025年6月1日至2026年5月30日。
四、评选机构
（一）学院成立院级奖助学金评选委员会，由主管学生工作的院领导担任主任，委员由学院领导、学院学生工作委员会成员、教师代表、学生代表组成。
（二）学院学生工作委员会作为院级奖助学金评审的办事机构，负责宣传奖助学金实施细则，并接收申请书和安排评审工作。、
五、评选程序
（一）2026年6月5日17:00前，请符合评选条件的同学提交《深圳大学生命与海洋科学学院2025-2026学年院级奖学金申请表》、《生命与海洋科学学院2025-2026学年院内奖学金个人基本信息表》（见附件）与佐证材料文件（所有佐证材料务必合并在一个PDF文件中，文件命为：姓名+佐证材料）到问卷中（深圳大学生命与海洋科学学院2025-2026学年奖学金申请问卷https://wj.qq.com/s2/26799914/b9bd/）。
（二）2026年6月26日前，学院学生工作委员会根据评选条件对提交的申请材料进行初审，学院评选委员会对通过初审的材料，确定奖学金人选。通过学院网站与学校公文通对评选结果进行公示，公示无异议后报送学院。
（三）学院召开颁奖会，颁发获奖证书与奖金。
六、资格丧失和取消
凡有下列情形之一的，自动失去获此奖学金资格，评委会有权取消获奖学生的获奖资格，学院将追回获奖证书与奖金。
（一）触犯国家法律，或违反校纪校规，受到刑事处罚或学校范围行政严重警告（含）以上处分者。
（二）中途退学、辍学者。
七、学院学生工作委员会享有细则最终解释权。
