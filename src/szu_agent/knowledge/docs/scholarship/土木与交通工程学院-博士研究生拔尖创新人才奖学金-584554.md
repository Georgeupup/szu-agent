# 土木与交通工程学院2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》（深大校发〔2024〕308号）、校长办公会有关精神、研究生院发布的《关于2026年博士研究生拔尖创新人才奖学金有关事宜的说明》（https://www1.szu.edu.cn/board/view.asp?id=568071）与《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》（https://www1.szu.edu.cn/board/view.asp?id=583014）（以下简称“通知”）的相关内容，同时结合我院实际情况，制定我院2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作细则。
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生）。
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、一等奖与二等奖三个等级，各等级奖励金额为：
（一）特等奖：7.7万元；
（二）一等奖：3.7万元；
（三）二等奖：1.7万元。
三、参评条件
学生申请博士研究生拔尖创新人才奖学金的基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。
（五）未受过任何校级、院级处分。
四、评选标准
按第一学年（新生）、其他学年（老生）分类评定，具体评定标准按通知中的相关内容执行。
五、名额分配
各等级奖励名额以研究生院下达为准，并依据新生与老生各等级符合条件的申报数量按比例分配。
六、评选程序
（一）评选原则
1. 分组评选：新生与老生分开进行评选。
2. 新生排名规则。
按照以下优先级原则进行排序：
（1）生源层次：
①本科和硕士均来自世界排名前50院校；
②本科和硕士均来自世界排名前100院校；
③本科和硕士均来自深圳大学、985高校及最新世界排名前200名院校；
④其他。
（2）申请者发表（含录用，下同）Nature、Science、Cell系列期刊论文的数量；
（3）申请者发表自然指数期刊收录论文的数量；
（4）申请者发表通知中相应等级奖学金规定的论文的数量；
（5）申请者发表通知中相应等级奖学金规定的论文的的期刊影响因子和；
（6）通过答辩排序。
3. 老生排名规则
按照以下优先级原则进行排序：
（1）申请者发表Nature、Science、Cell系列期刊论文的数量；
（2）申请者发表自然指数期刊收录论文的数量；
（3）申请者发表通知中相应等级奖学金规定的论文的数量；
（4）申请者发表通知中相应等级奖学金规定的论文的期刊影响因子和；
（5）通过答辩排序。
注：直博生只看本科；论文、高校排名的认定均以通知中的相关内容为准；自然指数期刊以Nature官网数据为准。
（二）评选步骤
1. 材料申报与资格初审​
（1）基础材料申报
所有申请人已于2026年9月29日前通过拔尖创新人才奖学金申请系统完成申报。经学院负责老师整理及审核，形成2026年博士研究生拔尖创新人才奖学金学生申报信息汇总表（以下简称“申报信息汇总表”），见附件1。
​（2）补充材料提交​
若申请人有多篇满足通知规定的相应等级论文但未在系统中完整申报，可提交补充材料。补充材料须填写统一的《补充论文信息表》，并于2026年10月14日12:00前发送至指定邮箱：yafen.qiu@szu.edu.cn。
补充材料仅限在既定截止日期前提交一次，逾期不予受理。学院将对材料进行审核。
​（3）评审结果认定
学院依据申请人提交的材料按照以上评选原则组织评选委员会对申请者进行排序推荐。
学院将会对推荐结果进行公示，公示无异议后，将最终推荐结果报送至研究生院，最终获奖结果以研究生院公布为准。
