# 建筑与城市规划学院2026年度博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》（深大校发〔2024〕308号）、校长办公会有关精神、研究生院《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》要求，结合学院学科实际，制定本学院2026年度博士研究生拔尖创新人才奖学金评选工作细则。
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生）。
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、一等奖与二等奖三个等级，各等级奖励金额：（一）特等奖：7.7万元；（二）一等奖：3.7万元；（三）二等奖：1.7万元。
三、参评基本条件
学生申请博士研究生拔尖创新人才奖学金，须同时满足以下基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。老生还须满足必修课平均分不低于75分，全部培养环节考核通过。
（五）未受过任何校级、院级处分。
四、评定标准
等级申请资格按照研究生院《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》文件规定执行。
论文认定时间：新生论文认定时间为2024年9月1日至2026年8月31日；老生论文认定时间为2025年9月1日至2026年8月31日。超出该时间段论文不计入评定，上次获奖已使用过的论文不得重复使用。
本年度特等奖不设置独立申报入口，具备特等奖申请资格的学生统一填报一等奖进行申报，资格仅代表具备特等奖入围候选项条件，不等于直接获得特等奖，由学院评审委员会结合学校下达名额综合择优推优。
硕博连读新生、其他学年（老生）参评论文须以深圳大学为第一完成单位。
五、评选程序
各等级奖励名额以研究生院下达为准。
学院对所有申请是否符合申请要求进行审核后，组织学院评审委员会进行评审，分别对符合申请特等奖、一等奖的申请者进行排名。学院将会对申请人的排名和申请结果进行公示。公示无异议后，学院将最终申请结果报送至研究生院。学院公示结果不是最终获奖结果，最终获奖结果需关注研究生院的获奖公示。
