# 生命与海洋科学学院2026年本科卓越班奖学金评选细则

为进一步提高创新人才培养质量，引导学生挑战自我，追求卓越，同时激励学生勤思进取、奋发向上，调动学习的积极性和主动性，根据学校《深圳大学本研一体卓越班管理办法》、《关于启动深圳大学2026年卓越班奖学金评选工作的通知》相关要求，结合学院具体实际情况，生命与海洋科学学院将启动本科卓越班奖学金评选工作，特制定本评选细则。
一、学院卓越班奖学金评选工作小组
学院成立卓越班奖学金评选工作小组，工作小组由教授代表、生物科学系主任、各卓越班班主任、学院学生工作办公室代表、本科教务办公室代表等组成。
二、评选对象及资格
1. 深圳大学生命与海洋科学学院生物科学（卓越）班学生；
2. 道德品质良好，遵纪守法，在校期间无考试作弊和学术不端行为记录，无任何违法违纪受处分记录；
3. 所评选学年内所有课程均合格；
4. 所评选学年内有科研训练经历；
5. 评选时已转专业或退班的学生无参评资格；
6. 正处在退班程序的学生无参评资格。
三、奖学金名额及标准
一年级本科生均给予学费奖学金6000元/人。
二年级以上设一、二、三等奖学金。其中一等奖12000元/人，二等奖6000元/人，三等奖3000元/人；获奖比例为各年级参评学生人数的70%，其中一等奖20%，二等奖40%，三等奖10%。（以上比例根据学校当学年评选工作通知要求确定，按四舍五入计算，奖励须遵循《深圳大学本科生先进个人评选及奖学金评定办法（修订）》，荣誉可兼得，奖学金以最高一项计发）

四、评选依据
二年级及以上学生采用百分制综合成绩评定，由学业成绩、科研训练两部分组成，其中学业成绩占80%，科研训练占20%，具体评定办法如下：
（1）学业成绩：以评选学年学业成绩为准，在该奖学金百分制综合成绩评定中占80%。学业成绩计算方法为：评选学年绩点/4.5×100×80%。
（2）科研训练：申请该奖学金学生必须具备科研经历，填写提交《卓越班奖学金申请表》（见附件）时需有实验室指导老师审批意见。符合评奖基本资格的学生需要参与科研答辩，展示包括但不限于在科研实验室所学技能、项目竞赛经历或研究成果等。学院组织卓越班奖学金评选工作小组，根据参评学生在答辩中的表现进行评分。答辩分数将以20%的比例计入该奖学金百分制综合成绩。
五、工作安排
1.2023-2025级申请奖学金的同学于10月21日17：30前提交
纸质材料：《卓越班奖学金申请表》，交至守慧楼405办公室。
电子材料：《卓越班奖学金申请表》、答辩PPT，请发送至邮箱：（个人邮箱已省略，见原通知），逾期未提交视为放弃申请。（文件以“年级+姓名”格式命名，例：2024级张三）
2.10月23日前，卓越班奖学金评选工作小组组织申请学生进行科研答辩。
本细则由学院卓越班奖学金评选工作小组负责解释。
