# 教育学部2025-2026学年度本科生奖学金评选细则（有更新）

各位同学：
学部根据学校各项奖学金评定办法，结合学部实际情况，制定《教育学部2025-2026学年度本科生奖学金评选细则》，现进行公示，具体内容见附件。若有异议，请于9月15日17:00前向学工办提出。
一、评选原则
奖学金评选贯彻公平、公正、公开原则，以学生在参评学年度学业成绩、综合表现为基础，通过民主集中的方式进行评选。
二、基本评选资格
申报各类奖学金及荣誉称号者，必须同时符合以下基本条件：
1.深圳大学教育学部二年级及以上全日制普通本科生；
2.评选学年度内未受党、团、行政处分；
3.评选学年度内所有课程必须及格(特殊贡献类除外)；
4.评选学年度内学生参与交换项目或休学达一个学期以上的不参与奖学金评选；
5.未缴纳学费又未申请国家助学贷款、未办理学费缓交手续的学生不能参评。

四、奖学金体系构成
（一）国家奖学金
教育学部名额：1人，10000元/人
（二）校级奖学金
1.单项先进个人奖
（1）学业类：“学习之星”、“双创之星”
（2）特长类：“文体之星”
（3）公共服务类：“公益之星”、“优秀学生干部”
奖学金金额：一等3000元/人；二等2000元/人；三等1000元/人。
各单项奖学金获奖名额：
“学习之星”一等2人，二等7人，三等15人；
“优秀学生干部”一等1人，二等4人，三等5人；
“公益之星”一等2人，二等5人，三等7人；
“双创之星”一二三等奖总获奖比例不超过本学部参评学生总人数的10%，教育学部“双创之星”一二三等奖学金总计24人。
“文体之星”一二三等奖总获奖比例不超过本学部参评学生总人数的5%，其中三等奖获奖比例不超过本学部参加评选学生总人数的2%，教育学部“文体之星”一二三等奖学金总计12人，其中三等奖5人。
（4）特殊贡献奖
根据审批结果设定，由学校相关部门研究决定，报学校审定批准。
（三）社会奖学金
鹏程奖学金，1人，10000元
2.综合先进个人奖
（1）“荔园之星”
（2）“荔园卓越之星”、“荔园卓越之星”提名奖
奖学金金额：
“荔园之星”10000元/人；
“荔园卓越之星”提名奖30000元/人；
“荔园卓越之星”50000元/人。
奖学金获奖名额：
“荔园之星”获奖名额根据参评人数，结合学校年度预算安排，核定至学部；
“荔园卓越之星”获奖名额不超十名；
“荔园卓越之星”提名奖获奖名额十名。
3.先进班集体
先进班集体名额：2个。
五、评定原则
（一）本学年度国家奖学金、社会奖学金、学校奖学金统一纳入奖学金评选体系，统筹规划、同步评选；2026年应届本科毕业生奖学金评选工作同步开展。
（二）学生申报各类奖学金，均需满足相应奖学金文件中规定的评选资格条件。
（三）学校奖学金按照《深圳大学本科生奖学金评定办法（修订）》，荣誉可兼得，奖学金以最高一项计发。
（四）学生参评学校先进个人奖项，不影响参评国家奖学金或校外单位所设的奖项及奖金（设奖单位另有要求的除外）。
（五）国家奖学金与国家励志奖学金不可兼得。
（六）以勤工助学岗位工作身份参与学生工作者，原则上不可作为学生干部参加“优秀学生干部”奖学金评选。
（七）学部申报提交后，发现申请人不符合评选条件的，立即取消其评选资格，名额自动作废。如有在评选中弄虚作假者（如，篡改成绩单、伪造获奖证明、谎报获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
六、评选程序
（一）学部根据学校相关文件，将各项奖学金名额按比例进行分配。
（二）辅导员、班主任及各班班长及时通知各位同学网上填写相应申请表，各系辅导员审批后打印申请表，由班长收齐排序后统一将申请表及相应材料交至各系辅导员。
（三）学部评奖工作领导小组根据具体评选规则评选出各个奖项的候选人（评选结果须半数通过），公示无异议后报送学生部。
（四）各项校级奖学金评选工作同步进行。
七、学习之星评选办法
（一）各班名额分配方法
1.学部根据学校规定的比例，计算确切名额分配至各专业，计算过程中出现小数差异按小数点后数字高低排序，由高往低增减名额。本学期新转入的学生不算入该班人数，本学期转至外院系的学生仍算入该班人数；
2.学业奖学金名额分配以同年级同专业为单位；
3.根据学校相关规定，于本学期转出其他院系的学生如需参加评选，需回本学部原所在班级评选，奖学金由本学部原所在班级发放。
（二）学业成绩平均绩点计算及排名方法
1.学业成绩平均绩点计算范围为评选学年度学生所修读的全部课程。学业成绩绩点计算方法以学校规定为准；
2.以绩点优先原则，若该学年绩点相同，比较该学年所得学分，所修得学分多者获评，如出现课程成绩平均学分绩点和所修学分相同情况，以并列名次处理，并列名次所造成的名额增减情况由学生工作办公室在本学部范围统筹处理。
八、优秀学生干部评选办法
（一）名额分配与评奖对象
1.优秀学生干部评选由学部统筹，获评人数不超过学校下发的总名额；
2.评选对象包括班委、团支部、学部团委、学生会、党员先锋工作站、宿舍长和社区助理。
（二）评选办法
1、参评条件
（1）满足上述评选范围以及学生参评资格规定的相关条件；
（2）在所评选学年内担任上述职务一学期以上（无故离任或被免职者不得参评）；
2、评选原则
（1）参评人填写申请表格并递交个人详细参评材料；
（2）学部评审小组根据申请审核其参评材料，并根据参评人实际情况作出表决；
（3）评价指标以年度内任职情况和工作绩效鉴定为主，同时参考组织策划各类活动的量和质，获荣誉称号或表彰的情况，以及参评人在学生中的普遍反映以及学业表现等；
九、先进班集体及其它个人奖项评定办法
依据学校有关文件中的评选流程进行材料审核，由学部评选小组进行评定。
十、申诉机制
学部评奖工作领导小组对奖学金评选的全过程进行监督，学生工作办公室同步接受学生在公示期间的据实投诉与申诉。有异议者也可向本班奖学金评选工作小组进行投诉与申诉。
