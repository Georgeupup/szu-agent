# 机电与控制工程学院2026年研究生学业奖学金评选细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和《关于组织开展深圳大学2026年研究生学业奖学金评审工作的通知》有关精神，结合我院实际情况，现就研究生学业奖学金评审工作的有关事宜通知如下：
一、参评对象被我校正式录取并注册报到、具有中华人民共和国国籍的全日制在校学习研究生。
二、参评基本条件（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及参评要求硕士研究生学业奖学金实行按年评审，动态管理。硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。学业奖学金只在标准学制年限内享受。学院在每学年初对本院研究生学业奖学金进行评选，对因违纪、违规等原因导致不符合参评及获奖条件的研究生取消其获奖资格，并报研究生管理部门备案。
（一）第一学年硕士研究生参评学业奖学金第一学年，所有推免生、一流大学建设高校应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
（二）第二学年硕士研究生参评学业奖学金（1）奖励标准：分为一等和二等两个等级。一等奖奖励标准为每生每年10000元，二等奖奖励标准为每生每年5000元。
（2）奖励比例及名额分配：获评一等学业奖学金的比例不超过当年可参评硕士研究生总人数的20%；获评二等学业奖学金的比例不超过当年可参评硕士研究生总人数的40%。各专业名额分配如附件1所示。
（3）评选办法：根据学生个人的思想品德、学业成绩、科研成果、社会实践和培养潜力等综合因素评定。申请人学位课程平均成绩需达到75分以上（含75分），且全部所修课程通过。第一学年必修课（学位课）平均成绩在专业排名前40%可参评一等学业奖学金，第一学年必修课（学位课）平均成绩在专业排名前80%可参评二等学业奖学金。所有符合参评条件的硕士研究生需提交申请表及相关证明材料。学院优先根据学生科研成果进行评定，其次在指标未满的情况下参考学生成绩、社会实践及培养潜力等因素，确定获奖学生名单。提交了一等学业奖学金却未评选上的学生，自动参评二等学业奖学金的评选。
（三）第三学年硕士研究生参评学业奖学金（1）奖励标准：分为一等和二等两个等级。一等奖奖励标准为每生每年10000元，二等奖奖励标准为每生每年5000元。
（2）奖励比例及名额分配：获评一等学业奖学金的比例不超过当年可参评硕士研究生总人数的20%；获评二等学业奖学金的比例不超过当年可参评硕士研究生总人数的40%。各专业名额分配如附件1所示。
（3）评选办法：根据学生个人的科研成果、社会实践、培养潜力和学业成绩等综合因素评定。申请人学位课程平均成绩需达到75分以上（含75分），且全部所修课程通过。学院优先根据学生科研成果进行评定，其次在指标未满的情况下参考学生培养潜力、社会实践及学生成绩等因素，确定获奖学生名单。提交了一等学业奖学金却未评选上的学生，自动参评二等学业奖学金的评选。
（四）博士研究生学业奖学金博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。四、评审日程（一）9月17日—9月22日：各学院成立研究生学业奖学金评审委员会，在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。评审委员会组成人员人数一般为不少于7的单数，主任委员由各学院（部）主要领导担任，委员由研究生导师、相关管理人员、研究生代表担任。院评审委员会名单及评选细则需在学校公文通上予以公布。
（二）9月23日—9月30日：所有符合参评条件并有意愿申请的研究生登陆网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写申请表，填好后双面打印，本人签名，附相关成绩及成果佐证材料，于10月9日上午10:00前送交所在班级班长，班长请于10月9日下午14:00前提交到学院大楼S626黄老师处，逾期不再接收。（学业奖学金申请系统开放时间为：9月23日8:00—9月30日23:00）
（三）10月8日—10月21日：学院评委会审核个人申报材料、公示推荐名单，并于10月21日下午16:00前向学生部报送材料。
（四）10月21日后：学生部审核、公示获奖名单。
五、有关说明及注意事项（一）所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，提交后打印申请表、本人签名，按要求将所需材料及时送交联络人。
（二）延期毕业博士研究生需填写《延期毕业博士研究生学业奖学金发放申请表》（附件3），提交导师及学院审核。
（三）研究生参评奖学金的各类科研成果认定截止时间为2026年9月1日。针对毕业班研究生，截止日期放宽至2026年9月30日。
（四）对认定或评审结果有异议的学生，可在学院公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假的行为。
（六）获得研究生学业奖学金的研究生可以同时参评研究生国家奖学金、研究生国家助学金及其他研究生奖助学金。

## 附件：机电与控制工程学院硕士研究生学业奖学金评审制度

深圳大学机电与控制工程学院硕士研究生学业奖学金评审暂行办法

根据《深圳大学研究生学业奖学金管理暂行办法》（深大【2016】75号）《党委研工部关于各学院成立研究生评审委员会的通知》（深大研院【2017】006号）《党委研工部关于研究生奖学金评定工作的意见》（深大研院【2017】007号）等有关精神，结合学院实际情况，对我院研究生学业奖学金评定工作的基本参评条件、评审程序、申诉程序作出如下补充：

第一条  博士研究生学业奖学金奖励标准为每生每年20000元，在标准学制年限内享受，经申请核准后可适当延长，但最长不超过5年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。

第二条  硕士研究生学业奖学金实行按年评审，第一年为新生奖学金，第二、三年为学业奖学金。

第三条  硕士研究生学业奖学金奖励标准。

（一）第一年新生奖学金分为特等、一等和二等三个等级。特等奖奖励标准为每生每年15000元；一等奖奖励标准为每生每年10000元；二等奖奖励标准为每生每年5000元；

（二）第二、三年学业奖学金分为一等、二等两个等级。一等奖奖励标准为每生每年10000元；二等奖奖励标准为每生每年5000元；

（三）如有变动，以研究生院最新文件为准。

第四条  硕士研究生学业奖学金奖励比例及名额分配。

（一）第一年新生奖学金。特等奖名额及部分一等奖学金名额原则上由党委研工部/学生部根据招生及录取数据统一认定；扣除上述人数后，获评一等奖学金的比例不超过20%；获评二等奖学金的比例不超过40%；

（二）第二、三年学业奖学金。获评一等奖学金的比例不超过当年可参评硕士研究生总人数的20%；获评二等奖学金的比例不超过当年可参评硕士研究生总人数的40%；

（三）研究生院每年9月份根据学院总人数下拨一等、二等学业奖学金名额。学院根据各专业总人数及奖励比例对分配名额，有争议时由学院研究生学业奖学金评审委员会统筹分配。

第四条  硕士研究生学业奖学金奖励参评条件。

（一）满足研究生院制定的基本参评条件。

（二）第一年新生奖学金。分为特等、一等和二等三个等级。扣除学校认定的人数后，参评的一等奖学金和二等奖学金根据学生在全国硕士研究生招生考试中初试与复试的总成绩按比例进行评定；有突出成果的由学院研究生学业奖学金评审委员会根据实际情况认定。

（三）第二年学业奖学金。根据学生个人的思想品德、学业成绩、科研成果、社会实践和培养潜力等综合因素评定。申请人学位课程平均成绩需达到75分以上（含75分），且全部所修课程通过。第一年必修课（学位课）平均成绩在专业排名前40%可参评一等学业奖学金，第一年必修课（学位课）平均成绩在专业排名前80%可参评二等学业奖学金。有意愿申请学业奖学金的需填写《研究生学业奖学金申请审批表》，并附相关证明材料，向学院评审委员会提出申请。学院优先根据学生科研成果进行评定，其次在指标未满的情况下参考学生成绩、社会实践及培养潜力等因素，确定获奖学生名单。提交了一等学业奖学金却未评选上的学生，自动参评二等学业奖学金的评选。

（四）第三年学业奖学金。根据学生个人的科研成果、社会实践、培养潜力和学业成绩等综合因素评定。申请人学位课程平均成绩达到75分以上（含75分），且全部所修课程通过。有意愿申请学业奖学金的需填写《研究生学业奖学金申请审批表》，并附相关证明材料，向学院评审委员会提出申请。学院优先根据学生科研成果进行评定，其次在指标未满的情况下参考培养潜力、社会实践及学生成绩等因素，确定获奖学生名单。提交了一等学业奖学金却未评选上的学生，自动参评二等学业奖学金的评选。

第五条 科研成果认定

（一）研究生参评奖学金的各类科研成果包括：论文、科学著作、专利、高水平学科竞赛、专业作品等。

（二）各类科研成果均需以深圳大学为第一单位。申请人需为该科研成果的第一完成人；或者申请人的导师为第一完成人，申请人为第二完成人。各类科研成果在评选学院奖学金的情况下只能被使用一次，如果第一次使用该成果未能评选上，下次可以再次使用。

（三）科研成果以正式取得为准，其中论文应已在线发表并能提供检索证明,专利应已取得专利证书。SCI检索论文的分区及影响因子以中科院文献情报中心JCR分区最新一期大类分区为准，SSCI检索论文的分区及影响因子以美国科学信息研究所ISI的JCR最新分区为准，核心期刊以最新版的北大中文核心期刊目录为准。

（四）研究生参评奖学金的各类科研成果认定的截止时间为当年8月31日。针对毕业班研究生，放宽至学院公布评审细则当天。

（五）科研成果公示。学院在召开评审会之前，应在全院范围内对学业奖学金的评审材料进行不少于2个工作日的公示，材料包括：学业成绩、科研成果和社会实践。如对学生提交的材料质疑，需在公示日内以书面形式实名制向学院进行投诉，学院应及时研究并进行调查。

第六条 申诉流程。学院将获奖学生名单在全校范围内进行公示，公示期不得少于3个工作日。申请人或导师若对评选结果有异议，可向学院口头提出申诉，学院评审委员会主任或者评审联络人负责解释。若不认可解释的可向学院研究生学业奖学金评审委员会递交书面申诉书，委员会受理申诉后，对评选细则和工作流程等进行讨论并作出最终结论，同时将结果上报研究生院。

第七条 本办法从2019年9月3日起施行，由学院学位评定分委员会负责解释。
