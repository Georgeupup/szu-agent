# 建筑与城市规划学院2025-2026学年研究生国家奖学金、社会奖学金及优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将建筑与城市规划学院2025-2026学年研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
三、名额分配
根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），我院研究生国家奖学金名额共计14人，其中博士研究生1人，硕士研究生13人。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习成绩优异，科研能力显著，发展潜力突出。所修课程全部通过，必修课平均成绩达75分或以上，并至少具备以下条件之一：
1.在国内外权威学术刊物上发表具有较高学术价值的学术论文，可参考高质量科技期刊分级目录总汇（附件3），同等条件下，按刊物等级、影响因子大小以及论文数量等排序；
2.在重大学科竞赛中获奖，同等条件下，按竞赛规格、获奖等级、贡献度以及竞赛数量等排序，团队项目竞赛获奖需提供《团队项目获奖成员贡献度列表》（附件4）；
3.科研课题或创新项目取得突出成绩，能提供相关证明材料；
4.其他学术科研创新成果，能提供相关证明材料。
贰·研究生社会奖学金
鹏程奖学金
一、评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
二、奖励标准
每生每年10000元。
三、名额分配
根据《深圳大学2025-2026学年研究生鹏程奖学金名额分配表》（附件2），我院研究生鹏程奖学金名额1人（不分硕博）。
四、参评条件
（一）热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
（二）刻苦学习、成绩优异，在全班或全年级名列前茅，所修课程全部通过，必修课平均成绩达75分或以上；
（三）具有较强的科研能力，有公开发表科研成果。至少具备以下条件之一：
1.在国内外权威学术刊物上发表具有较高学术价值的学术论文，可参考高质量科技期刊分级目录总汇（附件3），同等条件下，按刊物等级、影响因子大小以及论文数量等排序；
2.在重大学科竞赛中获奖，同等条件下，按竞赛规格、获奖等级、贡献度以及竞赛数量等排序，团队项目竞赛获奖需提供《团队项目获奖成员贡献度列表》（附件4）；
3.科研课题或创新项目取得突出成绩，能提供相关证明材料；
4.其他学术科研创新成果，能提供相关证明材料。
比亚迪奖学金
一、评选对象
根据捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二年级及以上硕士博士研究生，只在标准学制内参评。
二、奖励标准
每生每年20000元。
三、名额分配
根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），我院研究生比亚迪奖学金名额1人（硕士）。
四、评选标准
（一）坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。
（二）热爱祖国，热爱人民，拥护中国共产党领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。
（三）遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
（四）具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
（五）德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
（六）在符合上述条件前提下，还应至少满足下列条件之一：
1.以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文；
2.以前两顺位发明人申请国家发明专利；
3.在国际/国家级重大学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
4.曾在重大科研项目中担任主要完成人。
叁·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
每生每年2000元。
三、奖励名额
优秀研究生干部根据在校生人数、年度预算等因素分配名额，根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），我院优秀研究生干部名额共计13人（不分硕博）。
申请人数超出下达名额的，同等条件下优先推荐成果突出的参评者，符合评奖条件的申请人数达不到下达名额的，奖项名额自动空缺。
四、参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过，必修课平均成绩达75分或以上；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月（如学院研究生会主席团成员或总干事、“童享建筑”学生负责人、学生党支部副书记、支委以及班干部等）；
（六）任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的评选安排如下：
一、评选程序
（一）9月11日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月11日—9月16日：学院成立研究生奖学金评审委员会（以下简称院评审委员会），由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表等任委员，院评审委员会名单（附件5），按学院的实际情况进一步制定本学院评选细则并予以公示。
（三）9月14日—9月17日：所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件，可下载系统生成的文档）至系统。申请表由学生本人签名，导师签字，同时附相关佐证材料，于9月18日11:00前送交至汇意楼A207办公室林老师处，逾期不再受理。
（注：申报各类奖项时，相关佐证材料均需上传至系统附件。同时申请的同学需要在申请截止前登陆【腾讯文档】2026年建规学院研究生奖学金申报材料清单汇总
https://docs.qq.com/sheet/DQmZjUVFTb01pbEds选择相应工作表填报申请材料信息，评审及公示将以此填报信息为准，请认真如实填写,调整好格式，逾期未填写将视为放弃申请。）
（四）9月18日—9月30日：学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示。
（五）10月8日－10月14日：学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
二、其他事项
（一）注意事项：
申请人发表的论文或专利需为第一作者；若为第二作者，第一作者必须是其导师；学生作为通讯作者发表的文章不能作为学生科研成果；参与导师申请的科研项目或获奖不可作为学生科研成果；参与工作坊评比不作为竞赛成果；专利认定原则与论文发表原则一致，专利需经过授权后方可认定为有效参评科研成果，并以授予专利时间为准。研究生参评奖学金的各类科研成果认定的截止时间为2026年9月1日；毕业年级研究生，截止时间放宽至申请截止日。一般情况下，参评成果必须是已经刊登或授权成果，不包含录用通知，毕业年级研究生科研成果可包含录用通知。
个人申报材料包括：
1.《研究生国家奖学金申请审批表》（系统导出后打印，若申请则提交）及《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件）；
2.《深圳大学鹏程奖学金申请表》/《深圳大学比亚迪奖学金申请表》（系统导出后打印，若申请则提交）；
3.《深圳大学优秀研究生干部申请、审批表》（系统导出后打印，若申请则提交）；
4.研究生院出具的研究生学业成绩单（校内自助打印机打印或者“内部网-办事大厅-研究生成绩”下载打印）；
5.科研成果复印件（论文期刊封面、目录、论文首页及分区信息等），学术期刊目录可参考高质量科技期刊分级目录总汇（附件3）。有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索。检索指引（附件6），具体路径参考：内部网-图书馆-资源-数据库-JCR/中国科学院文献情报中心期刊分区表。图书馆咨询电话26537002。
4.竞赛成果复印件（获奖证书、相关图纸、贡献度列表等），如团队竞赛获奖，请填写团队项目获奖成员贡献度列表（附件4），团队成员及指导老师签字确认。杜绝弄虚作假行为，一经发现，取消申请资格，严肃处理。
5.其他成果复印件（专利证书、软著证书等），及其他可以证明本人所申报成果的材料。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（三）已获上一学年国家奖学金或社会奖学金的成果材料不得重复参评。
（四）国家奖学金、社会奖学金不可兼得。
（五）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
（六）研究生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
（七）有关国家奖学金的评选，本通知未尽事宜，详见财政部、教育部《研究生国家奖学金实施细则》及《普通高等学校研究生国家奖学金评审办法》相关规定。
（八）优秀研究生干部评奖细则详见《深圳大学优秀研究生、优秀研究生干部评选办法》。
（九）研究生学业奖学金评选工作将于9月中下旬启动。
（十）获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
（十一）学院奖学金评审委员会对本细则未尽事宜享有解释权。
