# 电子与信息工程学院2026年博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》（深大校发〔2024〕308号）和校长办公会有关精神，以及研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》通知内容，我院制定电子与信息工程学院2026年度博士研究生拔尖创新人才奖学金评选工作细则。
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生）。
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、 一等奖与二等奖三个等级，博士研究生拔尖创新人才奖学金各等级奖励金额为：
（一）特等奖：7.7万元；
（二）一等奖：3.7万元；
（三）二等奖：1.7万元。
三、参评条件
学生申请博士研究生拔尖创新人才奖学金的基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。
（五）未受过任何校级、院级处分。
四、评定标准
具体评定标准按学校研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》第四条评定标准执行。
五、评选程序
（一） 学生线上申报（9月21日-9月29日）
符合条件并有意向申请的学生进入拔尖创新人才奖学金申请系统进行申请（通过电脑版企业微信：工作台 ‐ 学生事务 ‐博士拔尖创新人才奖学金），填写申请审批表，依次完成提交、导师审核、师生电子签名，申请表自动流转至学院，无需提交纸质申请表。不参与本次申请的博士生，须向学院明确报备不申请，学院做好记录留存备查。逾期不再受理申请。
（二） 院内评审（10月23日前）
学院依据申请人提交的材料按照评选规则组织评审，对申请者进行排序推荐。学院将对推荐结果进行公示，公示无异议后，最终推荐结果报送至研究生院。
（三）校级审定与发放
校评审领导小组审定各学院获奖名单，并将校级获奖名单在全校范围内进行公示。最终获奖结果以研究生院公布为准。
六、其他事项
（一）2026年博士研究生拔尖创新人才奖学金实行总额控制，在学校预算总金额内，鼓励争先创优，并引入竞争机制。学院各等级奖励名额以研究生院下达为准。具体评选方法结合研究生院下达的奖励名额及根据学生申请成果所属学科领域，结合全院申报情况统筹考虑后再补充制定。
（二）参评论文等级认定按以下标准执行：
B类为中科院期刊分区大类1区学术论文；
C类为中科院期刊分区大类2区学术论文、CSRankings会议论文或CCF-A类期刊会议论文
（三）本年度参评博士研究生拔尖创新人才奖学金所涉及的论文认定时间：
1.新生论文认定时间为2024年9月1日至2026年8月31日；
2.老生论文认定时间为2025年9月1日至2026年8月31日。
超出该时间段的论文不得计入评定，且上次获奖时使用过的论文不得再次使用。
（四）申请博士研究生拔尖创新人才奖学金的博士研究生须为所发表论文的独立通信作者或独立第一作者（人文社科类导师为第一作者、学生第二作者的，视为学生为第一作者）。学生为共同第一作者，论文级别需按降一级评定（注：共同一作：共一人数2人，等级须降一档； 共一人数3或4人，等级须降两档；共一人数5人及以上，等级须降三档。Nature、cell、scienc e三大顶刊共同一作可以不降档）。
（五）自然科学类论文不设A类等级。Nature、Science、Cell系列期刊不受分区约束，按B类对待，可申请一等奖，评审特等奖时予以重点考量。
（六）参评奖学金的学生所修读课程成绩以学籍系统数据为准。
（七）本通知仅适用于本次奖学金评选。
