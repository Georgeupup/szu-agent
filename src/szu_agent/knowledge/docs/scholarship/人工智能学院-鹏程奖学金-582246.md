# 人工智能学院2025-2026学年度本科生鹏程奖学金评审细则

现开展人工智能学院2025-2026学年度本科生鹏程奖学金评选工作，具体事宜通知如下：
一、基本情况
（一）名额及金额
分配给我院鹏程奖学金获奖名额1人，奖励标准1次性奖励10000元。
（二）评选对象
本校二年级以上(含)且所参评年度内在校学习的全日制普通本科生。
（三）评选标准
1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为，所评选学年度和评选期间没有受到学校行政、党、团处分。
2.刻苦学习、成绩优异，所评选学年度所有课程及格，学分绩点在全年级10%以内。
3.原则上所评选学年度体测成绩及格及以上（2026年要求）。
4.所评选学年度义工时28小时及以上。
5.所评选学年度思政学时达标。
二、评选程序
9月15-20日，开放鹏程奖学金网上申报系统申请功能，学生登录网上办事大厅（http://ehall.szu.edu.cn/new/index.html），在线提交申请表，并附相关证明材料。相关纸质材料提交到致真楼1406-2。
三、具体要求
所有获评奖学金的同学需积极配合学校开展的各类优秀学生宣传活动，发挥模范带头作用。
人工智能学院
