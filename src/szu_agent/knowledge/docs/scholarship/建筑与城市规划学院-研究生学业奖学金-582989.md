# 建筑与城市规划学院2026年研究生学业奖学金评审细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合我院实际情况，现就建筑与城市规划学院研究生学业奖学金评审工作的有关事宜通知如下：
一、参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1.第一学年，所有推免生、一流大学建设高校（42所名单见附件1）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。即2026级硕士研究生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定（附件2）。其余符合参评条件的2026级硕士研究生根据学院细则，综合入学考试成绩等因素，按名额开展评定（附件3）。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。
2.第二学年及以后，综合考虑研究生的思想品德、学业成绩、科研成果、学科竞赛等情况，按照相应名额展开评定（附件3）。其中所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
四、评审日程
（一）9月17日—9月22日：学院成立评审委员会（附件4），在学校参评条件、申请等级及相关规定条件的基础上，结合我院实际情况，制定并公布学院评选细则，各专业评奖小组（附件5）制定本专业具体评选办法及标准，开展初步评审等工作。
（二）9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料。
硕士生提交完成后从系统导出下载申请表，双面打印，本人签名，导师在推荐理由处填写推荐意见并签字，按照各专业评奖小组要求将申请表以及相关佐证材料于9月29日11:00前送交至所在专业评奖小组（各班班委）处。
学制内博士和延毕博士的相关材料仅需提交申请表，其余佐证材料上传至系统即可。申请表以班级为单位于9月29日11:00前送交至汇意楼A207办公室林老师处。
*为给申请奖学金的同学提供便利，学业奖学金系统已接入“深圳大学学术门户”成果数据，请有意申请学业奖学金的同学先登录“深圳大学学术门户”（https://www.lib.szu.edu.cn/ir）进行研究生论文、专利成果认领，详细操作方法请参阅公文通《关于推动研究生论文、专利成果数据认领工作的提醒》（https://www1.szu.edu.cn/board/view.asp?id=557353）。
申请人在学业奖学金系统申请时可直接勾选并引用已通过导师审核的“学术门户”数据，无需额外上传佐证材料；如导师尚未审核或“学术门户”尚未收录相关成果，申请人也可在学业奖学金系统申请时自行添加并上传佐证材料。
同时，学制内博士和延毕博士、2024级和2025级硕士同学需要在申请截止时间（9月29日11：00）前登录【腾讯文档】 https://docs.qq.com/s/CdQyFg9grQyGknWEh5G2Da
选择对应班级表格填报申请材料信息，后续评审将以此填报信息为准，请认真如实填写,调整好格式，逾期文档将关闭编辑。
（三）10月8日—10月21日：各专业评奖小组审核学生申报材料，按照学院各年级各专业名额分配表（附件6）对申请人综合表现进行排序，并在专业内公示拟推荐排序，专业内公示无异议后以班级为单位于10月14日前向学院奖学金评审委员会联络人林老师报送拟推荐名单排序表（附件7）电子版和签字纸质版以及学生个人申请表，其余学生个人申请佐证材料各专业评奖小组留存备查即可。
后续学院组织评审会，对各专业评奖小组专业内公示无异议后的拟推荐名单进行评审。根据实际情况可对推荐名单进行调整，并确定学院最终拟推荐名单，在全校范围内进行公示。
（四）10月21日后：学生部审核、公示获奖名单，报校领导审批。
（五）校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
五、有关说明及注意事项
（一）系统申请提交、共享文档填报以及纸质材料提交三者必须信息一致，同时三者均完成才视为成功申请，否则将视为放弃申请，不纳入评审范围。
（二）参评研究生学业奖学金所涉及的相关成果认定截止时间：
2025级硕士/学制内非毕业年级博士：2025年9月1日至2026年9月1日；
2024级硕士/学制内毕业年级博士/延毕博士：2025年9月1日至2026年9月30日。
一般情况下，参评成果必须是已经刊登或授权成果，不包含录用通知，毕业年级研究生相关成果可包含录用通知。上一学年获研究生学业奖学金的相关成果不可作为本学年的参评材料，如有违反，一经发现，取消申请资格，严肃处理。
（三）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（四）各专业拟推荐名单将参考各专业评选细则进行评定，同时学院奖学金评审委员会将根据参评情况进行最终推荐名额调整。
（五）硕士研究生（包括特等和一等认定的研究生）、学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单（除新生外），其他根据个人实际情况上传，并按学院要求提交个人申报材料。
成绩单下载路径：PC端：办事大厅-研究生自助成绩单-绩点/非绩点成绩单-电子档下载。手机企微端：工作台-学生事务-研究生成绩证明-绩点/非绩点成绩单-电子档下载。
个人申报材料包括：
1.《研究生学业奖学金申请审批表》（需从系统上导出后打印，直接使用附件打印无效）
2.研究生院出具的研究生学业成绩单（校内自助打印机打印或者内部网下载打印）
3.科研成果复印件（论文期刊封面、目录、论文首页及分区信息等），学术期刊目录可参考高质量科技期刊分级目录总汇（附件8）。有关论文证明材料可自行在相关数据库中检索。检索指引（附件9），具体路径参考：内部网-图书馆-资源-数据库-JCR/中国科学院文献情报中心期刊分区表。图书馆咨询电话26537002。
4.竞赛成果复印件（获奖证书、相关图纸、贡献度列表等），如团队竞赛获奖，请填写团队项目获奖成员贡献度列表（附件10），团队成员及指导老师签字确认，杜绝弄虚作假行为。一经发现，取消申请资格，严肃处理。
5.其他成果复印件（专利证书、软著证书等），及其他可以证明本人所申报成果的材料。
相关材料提交请严格参考附件：奖学金佐证材料提交指引
（六）对认定或评审结果有异议的学生，可在各专业公示期间内向相应评奖小组提出申诉，各专业评奖小组应及时研究并予以答复。如有学生对评奖小组作出的答复存在异议，可向学院评审委员会提请复核。如学生对学院评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（七）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
（八）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策以及校内其他研究生奖助政策资助。
（九）学院奖学金评审委员会对本细则未尽事宜享有解释权。

## 附件：奖学金佐证材料提交指引

论文类佐证材料提交指引填写论文的相关信息时，注意清晰完整，日期精确到年月日，其中分区分级等相关信息请根据论文实际发表期刊，进入相应数据库检索期刊名称，截取并打印能够清晰地显示期刊名称、年份、影响因子、分区或分级结果的页面作为证明，同时高亮相应信息，以便核查。
纸质版材料提交，案例示意：
做好标注，圈画或高亮，突出个人信息，如姓名，日期，分级、分区、影响因子等期刊封面 期刊目录 论文首页科协分级 中科院分区 JCR 分级
一、科协 分级证明证明材料可来源于《高质量科技期刊分级目录总汇》（中国科协科学技术创新部，2025 年 12月修订）。请在目录中搜索查找对应期刊，并框选或标注期刊所属学科领域及分级结果。例如，若论文发表在《建筑学报》，需证明该期刊属于建筑科学领域 T1。
二、JCR 分区证明
1. 打开学校内部网，进入图书馆页面。
2. 在数据库导航中搜索 “JCR”，点击进入 JCR 数据库。
3. 页面跳转后，根据提示进入机构登录页面。
4. 搜索并选择 “深圳大学”，完成统一身份认证登录。
5. 登录成功后，在检索框中输入需要查询的期刊名称。
6. 选择对应年份，查看影响因子和 JCR 分区信息。
最终证明截图应清晰显示期刊名称、年份、影响因子和分区结果。
三、中科院 分区证明
1. 同样进入图书馆数据库导航，搜索 “中科院分区”。
2. 登录后，页面通常提供“基础版”和“升级版”两类入口，可根据证明要求选择相应版本。
3. 进入期刊详情页后，截取能够显示期刊名称、分区结果及相关指标的页面作为证明。
四、其他类别 说明如会议论文要清晰呈现收录/宣讲/墙报等情况竞赛类佐证材料提交指引填写竞赛的相关信息时，注意清晰完整，日期精确到年月日，如作品名称、竞赛名称、主办单位、获奖等级、获奖时间、贡献度等相关信息，请根据获奖证书进行填写，A4 彩色打印竞赛图纸、黑白打印获奖证书、贡献度列表作为证明，同时高亮相应信息，以便核查。
纸质版材料提交，案例示意：
做好标注，圈画或高亮，突出个人信息，如姓名，日期，等级，贡献度等其他专利软著、荣誉称号等材料同理，均需做好相应标注，突出个人信息各类佐证材料如不按照通知及相关要求提交将不予受理竞赛图纸获奖证书贡献度证明需所有成员及指导老师签字确认
