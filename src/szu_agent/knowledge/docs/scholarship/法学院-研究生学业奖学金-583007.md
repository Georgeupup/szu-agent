# 法学院2026年研究生学业奖学金评定细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合我院实际情况，现就本院研究生学业奖学金评审工作的有关事宜通知如下：
一、评选对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
详见附件2《法学院研究生学业奖学金评审细则》。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1．第一学年，所有推免生、一流大学建设高校（42所名单见附件2）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
2．第二学年及以后，所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
四、评审日程
（一）9月16日：学生部公布硕士研究生学业奖学金评选工作通知，下达名额。其中硕士一年级研究生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定；余下参评的一、二等奖学金由各学院根据被录取学生的入学考试成绩按名额评定。
（二）9月17日—9月22日：学院成立评审委员会（附件1），评审委员会负责制定评选细则（附件2）。院评审委员会名单及评选细则需在学校公文通上予以公布，公示期为3个工作日，如有异议请于公示期内向学院评审委员会联系人提出。
（三）9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，提交后打印申请表、本人签名，附相关成果复印件，经导师（推荐人）签字，请各班班长收齐本班申请材料，并查验材料是否符合上述要求（不接收单独提交，请务必按时提交给班长，由班长统一送交），在9月30日12点之前送交至明律楼301办公室，过期不候。
（四）10月8日—10月21日：我院评委会审核个人申报材料、公示推荐名单（不少于5个工作日），公示期后向学生部资助工作办公室报送材料。
（五）10月21日后：学生部审核、公示获奖名单，报校领导审批。
（六）校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
五、有关说明及注意事项
（一）参评研究生学业奖学金所涉及的科研成果、奖励等认定截止时间为2026年9月1日，针对毕业班研究生，学院（部）可根据实际情况适当放宽，并在学院（部）具体细则中体现。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（三）硕士研究生（包括特等和一等认定的研究生）、学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单，其他按需上传，并按学院（部）要求提交个人申报材料。
（四）对认定或评审结果有异议的学生，可在各学院（部）公示阶段向所在学院（部）评审委员会提出申诉，学院（部）评审委员会应及时研究并予以答复。如学生对学院（部）评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
（六）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策以及校内其他研究生奖助政策资助。
（七）法学院研究生学业奖学金评审工作联系方式：

## 附件：法学院研究生学业奖学金评审细则

法学院研究生学业奖学金评审细则

一、评定原则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，为提高研究生培养质量，确保我院研究生学业奖学金评审工作公开、公平、有序进行，经学院研究生学业奖学金评审委员会研究制定《法学院研究生学业奖学金评审细则》。法学院学业奖学金评定过程中，为全面衡量研究生综合学习素质，以科研成果为主，参考学业成绩、获奖情况和社会服务与实践方面综合表现，评定过程和结果应公开、公正和公平。

二、评选对象

被我院正式录取并注册报到、具有中华人民共和国国籍的全日制研究生（以在职形式学习的专业学位研究生、周末授课班研究生、延期毕业研究生除外）。

三、参评条件

（一）热爱社会主义祖国，拥护中国共产党的领导；

（二）遵守宪法和法律，遵守高等学校规章制度；

（三）诚实守信，道德品质优良，没有任何违法违纪行为，没有受到过国家和学校的各类处分；

（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）。

（五）积极参与科学研究和社会实践；

（六）研究生出现以下情形之一的，不具备当年研究生学业奖学金参评资格：

1.参评学年违反国家法律法规、校纪校规受到纪律处分者或往年受到纪律处分尚未撤销的；

2.有抄袭剽窃、弄虚作假等学术不端行为经查证属实的；

注：学籍状态处于休学或保留学籍的研究生新生申请参评新生奖学金的，只确定等级，奖学金待复学后按规定另行发放；其他年级休学的研究生按复学后所在年级参评，奖励标准按其当年的招生简章规定执行。

四、评审细则

研究生一年级：新生特等奖学金以学校认定的名单为准，一等、二等奖学金按照考研总成绩进行排名（初试成绩+复试成绩），并以第一志愿报考本校作为优先参评的条件。总成绩相同的，参照初试成绩进行评选。

研究生二年级、三年级研究生学业奖学金评选采用综合考评方式，即：对研究生在评选期内的“学业成绩、科研成果、获奖情况和社会服务实践”四个方面分别评分，加各项总得分，获得的总分即为此次研究生学业奖学金的最终评定成绩（分数保留小数点后三位）。

研究生二年级综合考评成绩=学业成绩得分（必修课程平均分×50%+科研成果得分×40%+获奖得分×5%+社会服务与实践得分×5%。

研究生三年级综合考评成绩=学业成绩得分（必修课程平均分×40%+科研成果得分×50%+获奖得分×5%+社会服务与实践得分×5%。

注意：

1.研究生参评学业奖学金的各类科研成果认定时间为上一学年：即上一年9月1日至当年9月1日。针对毕业班研究生，截止时间放宽到收材料截止时间。

2.学术科研成果、获奖和实践均需以“深圳大学法学院”为第一署名单位。是否属于“深圳大学法学院”为第一署名单位，以申请人的第一署名情况来判断，申请人第一署名为包含“深圳大学”的，视为第一署名单位为“深圳大学法学院”。

3.其中去年已经参评过学业奖学金的材料今年不得重复提交；若重复提交已参评过学业奖学金的材料，取消参评资格。

（二）科研成果得分

该生的获奖得分=该生获奖累计得分×权重。

申请者的获奖分为Ⅰ类、Ⅱ类，Ⅰ类获奖计算得分参照下表“奖励级别”和“获奖名次”，Ⅱ类获奖按 I 类获奖得分 50%计算。

Ⅰ类：学术年会获奖、各类学术比赛获奖（如模拟立法大赛、社研杯、法学相关征文等相关、要求必须是以提交论文或调研报告参加的获奖）以及学科各类竞赛（参考《深圳大学研究生参加高水平学科竞赛资助奖励办法》《法学院本科生学科竞赛管理方法》附件5中与专业培养相关的竞赛）。

Ⅱ类获奖：除Ⅰ类的获奖，包括知识竞赛、演讲比赛、文体活动等，最多提交2项。

（2）若为团队获奖，提交团队成员贡献表（附件5），若无该表则按得分/总人数计算最终得分；其中竞赛获奖中“指导老师”不纳入“总人数”的计数；如果团队竞赛中获得个人表彰，例如“最佳辩手”可以直接获得80%的分数且不占总分数。

（5）如果是学术会议上的科研论文奖项不设等级，则“最佳论文奖”按照上表中对应的项目级别的一等奖计算得分，“最佳论文提名奖”按二等奖计算得分，“优秀论文奖”按三等奖计算得分；不设等级和奖项上台汇报发言的，需提供相关证明。其中学术论文既被收录到论文集（论文集要公开出版，收录到会议材料不加分）又获得学术会议的科研论文奖的，按该论文的最高级别计算，不得重复提交，不得重复计算。

（6）获得研究生国家奖学金、社会奖学金、优秀研究生、优秀研究生干部、优秀志愿者等奖学金奖项都不列入此列中。

（7）“优秀共产党员”奖项视为Ⅱ类三等奖。

（8）比赛设置一、二、三名（等级），则四、五、六名（或者优秀奖）可下调一个级别，第七名以及之后不加分。

（五）社会服务与实践得分

社会服务与实践得分以研究生在学期间担任学生干部、参与社会实践活动的得分为计算依据。计算公式为：该生的社会服务与实践得分=该生社会服务与实践的累积得分×权重。

本项得分根据表3各项累计计算。表3中未尽事项，可由申请人自行提供证明材料，提交评审会议讨论决定是否计分以及确定分值。

表3 社会服务与实践分值表

| 任职 | 分值 |
| --- | --- |
| 省市级学联干部 | 8分 |
| 校（院）研会主席团成员 | 7分 |
| 校（院）研会总干事、党支部（副）书记、团委副书记 | 6分 |
| 班长、团支书 | 5分 |
| 党支部委员 | 3分 |
| 校（院）干事 | 2分 |
| 班干事 | 1分 |
| 社会实践活动 | 分值 |
| 学校组织的三下乡、支教一周以上、暑期实践 | 6分/项（最多可计两项） |
| 各种志愿者活动 | 一次活动算 1分，总分不超过 3 分 |

备注说明：

（1）学生干部任职必须满一年，任职不满一年折半加分，不尽职、表现不好的由学院评委会讨论酌情给分。学生干部任职获得多个计分资格的，按最高计分计算一次，不得累计；

如果获得学生干部相关奖项（奖学金除外），例如五四评优，优秀学生骨干等，校级荣誉在任职得分基础上加2分，院级加1分，而且最多只加一项；

所有的三下乡、支教、暑期实践应由深大组织，以校院团委出具的名单盖章为准；

义工活动以校团委（义工联）、志愿深圳义工时系统认证为准，若在志愿者活动中获得优秀义工加1分，但义工类加分最高为3分。

社会服务实践不包括专业实习、工作实习、夏令营等形式。

任何奖学金、酬劳活动与加分不可兼得。

（六）学风道德表现扣分

扣分主要针对研究生学风道德表现情况，如不按时报到注册、无故缺席重要会议活动、中期考核不合格等，由评委会酌情扣分，一次扣一分，扣满五分即止。违反学校政策被批评处分的一次扣五分，累计两次取消评奖资格。

五、其他

（一）其它特殊贡献、突出贡献的情形由院评委讨论认定。

（二）对符合参评条件的申报人，学院评委会将在评审推荐名额内，根据科研成果的学术水平和本规则其他要求择优确定。

（四）评选时间进度以学校通知为准，参评材料均需提交复印，并配合学院提交线上线下材料，无材料或者材料不全不加分，逾期后果自负。

（五）未尽事宜，由深圳大学法学院学业奖学金评审委员会参照学生部《关于组织开展深圳大学研究生学业奖学金评选工作的通知》等进行解释。
