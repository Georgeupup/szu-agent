# 化学与环境工程学院2025-2026学年研究生国家奖学金、社会奖学金、优秀学生干部奖学金评选细则（更新）

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我院相关社会奖学金设置协议等文件要求，为促进我院研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我院2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
三、名额分配
（一）名额分配方案详见附件1《深圳大学2025-2026学年研究生奖学金名额分配表》。
（二）博士国家奖学金3名，硕士国家奖学金14名，学院实行定额评审，校级复核确定最终人选。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习成绩优异，科研能力显著，发展潜力突出。
五、评选要求
1、学位课程平均成绩达到 75 分以上（含 75 分），所修课程全部通过（成绩排名以所修所有必修课平均成绩为准，以研究生院提供版本为准）；
2、参评学生除了满足以上条件外，还需满足下列条件之一：
（一）发表高水平学术论文。（1）在国内外权威学术刊物上公开发表具有较高学术价值的学术论文，发表论文署名第一单位须为深圳大学，申请人为第一作者。若申请人为第二作者，第一作者必须是其第一导师；同等条件下，学生为第一作者优先。（2）以共同第一作者发表的论文，计算论文时按共同贡献人数平均计算。（3）在中科院大类1区、2区、3区和4区（以升级版中科院分区为准）期刊上发表的论文系数分别为1、1/2、1/3和1/4。学术论文分值计算办法为：论文数×论文系数×论文影响因子。如某同学发表中科院大类1区、2区、3区和4区论文各2篇，影响因子分别为5、4、3和2，则该同学的论文计分为：2×1×5+2×1/2×4+2×1/3×2+2×1/4×2=16.3；对于在Nature Index期刊上发表论文或发表了高被引论文的学生，在积分同等的情况下优先推荐。
（二）获得授权发明专利。1项授权国家发明专利系数为1.0，等同于影响因子为1.0的学术论文；1项PCT授权专利系数为1.0，等同于影响因子为1.5的学术论文。如果同一技术申请了不同类型的专利，按计分最高的来计算，不进行累加。注：发明专利授权需以深圳大学作为第一专利权人，且要求申请人为独立或第一发明人，或导师为第一发明人，申请人为第二发明人;
（三）在重大学科竞赛中获奖。参照《深圳大学本科生学科竞赛清单》（见附件7）I、II和III级分类，其计分规则为：1）I类竞赛，最高等级奖励计 10.0分，第二等级奖励计 7.0分，第三等级奖励计 5.0分，其他等级奖励计3.0分。2）II类竞赛，最高等级奖励计 5.0分，第二等级奖励计 3.5分，第三等级奖励计 2.5分，其他等级奖励计1.5分。3）III类竞赛，最高等级奖励计 2.5分，第二等级奖励计 1.5分，第三等级奖励计 1.0分，其他等级奖励计0.5分。同一题目取得不同层级竞赛奖励时，取计分最高的来计算，不进行累加。同一项获奖仅排名前2的学生可共享该奖励，比值为7:3。
（四）在科研课题或创新创业项目等方面取得突出成绩，能提供相关证明材料。
研究生参评奖学金的各类科研成果认定可追溯至以当前身份前一次参评研究生奖学金之日，参评成果截止时间为9月17日，如此次参评的科研成果在学院2026年（含）之前的研究生评奖中已使用，则不予计入。

硕士研究生1名，每生每年20000元

3.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
4.具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
5.德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
6.在符合上述条件前提下，还应至少满足下列条件之一：

（3）在国际/国家级重大学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
（4）曾在重大科研项目中担任主要完成人。

叁·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
每生每年2000元。
三、奖励名额
优秀研究生干部根据在校生人数、年度预算等因素分配名额，详见附件1。申请人数超出下达名额的，同等条件下优先推荐成果突出的参评者，符合评奖条件的申请人数达不到下达名额的，奖项名额自动空缺。
研究生15人。
四、参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的评选安排如下：
一、评选程序
（一）9月11-16日，学院成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定本学院（部）的评选细则、开展初步评审等工作。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。
（二）9月14-17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4，可下载系统生成的文档）至系统，按照所在学院要求打印申请材料，学生本人签名，附相关成果复印件，经导师签字，提交给班长。申报各类奖项时，相关佐证材料均需上传至系统附件。
（三）9月18-30日，各学院（部）组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，应在全校范围内进行公示。
（四）10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（五）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（六）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
二、其他事项
（一）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励已在前次评奖使用且已获奖则不得重复使用。
（二）有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件3，图书馆咨询电话26537002。
（三）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
（四）研究生学业奖学金评选工作将于9月中下旬启动。
（五）获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
