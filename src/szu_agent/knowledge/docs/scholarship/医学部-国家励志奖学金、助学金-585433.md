# 医学部2026年国家励志奖学金评选细则

根据学校《关于开展2026年国家励志奖学金评选工作的通知》，结合我部实际情况，现就我部2026年国家励志奖学金评选细则公布如下：
一、评审机构
成立医学部2026年国家励志奖学金评审委员会，由学部主要领导、分管本科教学工作的领导、辅导员、教师代表、学生代表组成。
主任委员：殷涛
副主任委员：王子梅
委员：彭斌、许改霞、卢艳红、詹维浠、冯振翀、陈薇薇、钟晨熹
二、申请条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校二年级及以上本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度，没有违纪行为；
5.诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%。
三、评定原则
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.学部申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。
四、名额分配
按照学校分配名额，我部共有113个名额。
五、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，需上传成绩单。申请系统于10月19日开通，10月22日上午9：00关闭，逾期不予申请。
2. 10月21日前，医学部国家励志奖学金评审委员会公示评选细则。
3. 医学部国家励志奖学金评审委员会坚持公平、公正、公开的原则，按照本评选细则，严格审查申请学生资格，如符合评选条件的参评学生多于分配名额，将依据参评学生2025-2026学年学业成绩评定拟获奖名单。参评学生学业成绩相同时，将综合学生家庭经济困难情况等进行评定。
4.本细则适用于医学部2026年国家励志奖学金评选，解释权归医学部国家励志奖学金评审委员会。
5.本细则公示期至2026年10月23日。公示期内，如对本细则存在异议，请于工作时间，以书面形式实名反馈至医学部学生工作办公室，办公地址：丽湖校区守慧楼703。逾期不再受理。
