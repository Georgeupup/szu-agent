# 传播学院2026年研究生学业奖学金评选细则

根据我校学生部《关于组织开展深圳大学2026年研究生学业奖学金评审工作的通知》和《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合我院实际情况，现就传播学院研究生学业奖学金评审工作的有关事宜通知如下：
一、参评对象
被我院正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四） 所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）博士研究生学业奖学金
博士研究生学业奖学金奖励标准为每生每年20000元，在标准学制年限内享受；如有特殊情况，经学生本人申请、学生所在学院（部）及研究生管理部门审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
（二）2026级硕士研究生新生奖学金
1. 2026级参评新生奖学金：分为特等、一等、二等3个等级。特等奖奖励标准为每生每年15000元，所有推免生、一流大学建设高校（42所名单见附件1）应届毕业第一志愿考生及本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等，认定名单详见附件2：《深圳大学2026年硕士新生奖学金认定名单（1882人）》。
2.扣除上述人数后，获评一等学业奖学金的比例不超过剩余人数的20%，奖励标准为每生每年10000元；获评二等学业奖学金的比例不超过40%，奖励标准为每生每年5000元。学业奖学金只在标准学制年限内享受。
3.2026级硕士研究生特等奖学金原则上由党委学生部根据招生及录取数据统一认定；余下参评的一、二等奖学金由学院根据被录取学生的入学考试成绩（初试及复试成绩总和）为主要指标进行评定，如入学考试成绩总成绩相同，则按初试总分、面试总分、初试外国语、初试业务课一、初试业务课二科目顺序从高分到低分评定。
4.学校分配给我院的名额为：一等奖学金9人（学硕3人、专硕6人），二等奖学金18人（学硕5人、专硕13人）。名额分配详见附件3：《各学院（部）硕士研究生学业奖学金名额分配一览表》。
5.被录取研究生的学业奖学金实行按年评选，动态管理。学院在每学年初对本院（部）研究生学业奖学金进行评选，对因违纪、违规等原因导致不符合参评及获奖条件的研究生取消其获奖资格，并报研究生管理部门备案。
（三）2024、2025级硕士研究生学业奖学金
硕士研究生学业奖学金实行按年评审，第一年为新生奖学金，第二、三年为学业奖学金。
2024级、2025级参评学业奖学金，综合考虑思想品德、学业成绩、学术成果和社会实践（包括科技竞赛、文体比赛、参加义工服务、担任学生干部及其他实践活动）等因素展开评定。所有符合参评条件的硕士研究生中不超过20%（四舍五入）获评一等，奖励标准为每生每年10000元；获评二等奖学金的比例不超过当年本专业可参评硕士研究生总人数的40%（四舍五入），奖励标准为每生每年5000元。只在标准学制内享受。名额分配详见附件3：《各学院（部）硕士研究生学业奖学金名额分配一览表》。
2024级共有学硕在校研究生48名，其中一等奖学金名额为10人，二等奖学金名额为19人。
2024级共有专硕在校研究生73名，其中一等奖学金名额为14人，二等奖学金名额为29人。
2025级共有学硕在校研究生57名，其中一等奖学金名额为11人，二等奖学金名额为23人。
2025级共有专硕在校研究生63名，其中一等奖学金名额为13人，二等奖学金名额为25人。
2024级、2025级硕士研究生学业奖学金将由学院评审委员会根据2024级、2025级研究生个人的学业成绩、科研成果和培养潜力等综合因素评定，分为一等、二等两个等级，只在标准学制内享受。评选将从学业成绩、论文项目、获奖情况三个维度进行考量。
2025级硕士研究生所有科研成果、刊物发表、会议等计算时限为：2025年9月1日至2026年8月31日，2024级硕士研究生科研成果、刊物发表、会议等计算时限为：2025年9月1日至2026年9月22日。如果在此期间取得的科研成果在学院的评奖中已使用过，此次评奖则不予计入（即不能重复使用）。

（五）10月21日后：学生部审核、公示获奖名单，报校领导审批。

## 附件：深圳大学传播学院研究生学业奖学金评审细则

深圳大学传播学院研究生学业奖学金评审细则

一、评定原则

为全面衡量研究生综合学习素质，传播学院研究生各类奖学金评选采用“先综合考评，再提交学院奖学金评审委员会审议”的评定方式，综合考评对研究生在评选期内的“学业成绩、学术成果、获奖情况”三个方面分别计分，加总得分为研究生在评选中的综合考评成绩。在涉及到评分标准、分值相等、名额有限等难以计分的情况下则由学院评委会根据校研究生奖学金评定工作《通知》和《管理办法》进行现场评定并给出相应结论。评定过程和结果应公开、公正和公平。

二、参评对象

被我院正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。

三、参评条件

（一）热爱社会主义祖国，拥护中国共产党的领导；

（二）遵守国家法律法规，遵守学校规章制度；

（三）诚实守信，品学兼优；

（四）所修课程全部通过，且学位课程平均成绩达到80分以上（含80分）；

（五）积极参与科学研究和社会实践。

四、评审细则

（一）综合考评计算公式和说明

综合考评的三大项采用百分制计算，公式如下：

研究生综合考评成绩 = 学业成绩综合分×45% + 学术成果综合分×40% + 获奖综合分×15%。

1. 之前评选并已获奖用过的材料不能再用，未参加过评选或参加评选但未获奖的材料不受评奖规定的成果时间限制。

2.送稿中或评审中的未接收文章不计为科研成果。

3.所有学术成果均需以深圳大学为第一署名单位。

（二）学业成绩综合分

参评研究生所修课程须全部通过，且学位课程平均分在80分以上（含80分），成绩排名、绩点以研究生院提供的数据为准。

（三）学术成果综合分

4.科研项目

申请者项目积分计算得分=∑（项目计分基数×项目计分权数），项目需提供立项书（或项目合同）、项目参与人材料须提供立项批文、申请书、结项书、中期检查材料。

（1）学生本人主持的研究项目，该项目计分基数按国家级、省部级、市厅级、校级、院级分别记50分、40分、30分、20分、10分；参与计分权数为1；重大、重点项目可加10分。

（2）学生参与教师研究项目，该项目计分基数按国家级、省部级、市厅级、校级、院级分别记50分、40分、30分、20分、10分。。该项目计分权数，取决于申请者在该项目的所有项目参与人中的排序，参与计分权数分别为1、0.8、0.6、0.4，以此类推，其导师可不参与排序。
