# 2025-2026学年计算机与软件学院卓越班奖学金评选细则

为进一步提高创新人才培养质量，引导学生挑战自我，追求卓越，同时激励学生勤思进取、奋发向上，调动学习的积极性和主动性，根据深圳大学卓越班奖学金评选工作安排，现将我院评选工作细则公布如下：
一、学院成立卓越班奖学金评选小组：
组 长：计算机与软件学院院长 黄 惠
计算机与软件学院党委书记 杨国洪
副组长：计算机与软件学院党委副书记 廖江海
计算机与软件学院副院长 杨 烜
组 员：各系主任、卓越班班主任、辅导员
二、评选对象及资格
1. 深圳大学计算机与软件学院本研一体卓越班（以评选时卓越班学籍名单为准）；
2. 二年级以上学生，上一学年无挂科；
3. 遵纪守法、品行端正、举止文明，没有违反校规校纪行为。
4. 温馨提示：自 2027 年评选起，卓越班奖学金（二年级及以上年级）将同时执行体质健康测试、志愿服务时长、思政学时三项基本条件。本次不做要求。
三、奖学金标准
一年级本科生给予学费奖学金6000元/人。
二年级以上设一、二、三等奖学金。其中一等奖12000元/人，二等奖6000元/人，三等奖3000元/人；获奖比例为各年级参评学生人数的70%，其中一等奖20%，二等奖40%，三等奖10%。（以上奖励须遵循学校奖学金“荣誉可兼得，奖学金以最高一项计发”原则。)
四、评选安排
1.报名表及相关证明材料提交方式另见卓越班群通知（须按时提交自评表方可参评）。
2.除成绩单外的证明材料落款时间需为2025年9月1日-2026年8月31日。
3.由学院卓越班奖学金评选小组对学生申请材料进行初评和公示（公示期为3个工作日）。
4.学院将材料汇总报学生部。公示无异议后，由学生部报学校审批。
