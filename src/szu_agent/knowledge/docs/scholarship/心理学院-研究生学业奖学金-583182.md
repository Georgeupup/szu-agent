# 心理学院2026年研究生学业奖学金评审细则（更新）

根据《深圳大学研究生学业奖学金管理办法（修订）》、《关于组织开展深圳大学2026年研究生学业奖学金评审工作的通知》和学校会议有关精神，结合我院实际情况，现就研究生学业奖学金评审工作的有关事宜通知如下：
一、参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1．第一学年，所有推免生、一流大学建设高校应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
2．第二学年及以后，所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。
3，硕士研究生学业奖学金指标根据各专业可参评人数按比例进行分配（如遇小数点则四舍五入），具体指标如下：

## 附件：2026学年度心理学院学业奖学金综合成绩评定办法（20260924更新）

2026学年度心理学院学业奖学金综合成绩

评定办法

为全面衡量研究生综合学习素质，评选采用综合考评方式，采取量化评分制度，即研究生在评选期内按“学业成绩、科研成果、获奖情况、社会实践与服务”四个方面分别评分，最终得出四项相加的总分，四项的总分即为研究生在此次评选中的综合考评成绩，也即研究生学业奖学金的最终评定标准（分数计算保留小数点后两位）。

一年级硕士研究生学业奖学金依据入学总成绩由高到低排序评定。入学总成绩为初试成绩与复试成绩之和。总成绩相同的，依次以初试成绩、专业课成绩高者优先。

港澳台学生初试、复试满分均为150分，与全国统考满分不一致，须先折算为同一标准后再参与排序。折算公式为：

折算后入学总成绩=（初试成绩÷初试满分）×入读专业全国统考初试满分＋（复试成绩÷复试满分）×入读专业全国统考复试满分。

硕士研究生二年级学生学业奖学金计算比例如下：研究生综合考评成绩=学业成绩得分（40%）+科研成果得分（40%）+获奖得分（10%）+社会服务与实践得分（10%）。

硕士研究生三年级学生学业奖学金计算比例如下：研究生综合考评成绩=学业成绩得分（25%）+科研成果得分（55%）+获奖得分（10%）+社会服务与实践得分（10%）。

注：1.科研成果、获奖、社会服务与实践认定时间：2025年9月1日至2026年8月31日。针对毕业班研究生，认定时间可延长至学校申请系统关闭当日。

2. 所有学术成果和科研项目均需以“深圳大学心理学院”或学校认定的心理学院下属科研单位为第一完成单位。

3.其中去年已经参评过学业奖学金的材料今年不得重复提交；若重复提交已参评过学业奖学金的材料，取消参评资格。

（一）学业成绩得分

研究生学业成绩得分=申请人必修课平均分/所在年级专业必修课平均分最高分×100×权重25%或40%。

权重注释：研二为40%，研三为25%

注：硕士研究生申请一等学业奖学金的申请人必修课平均成绩排名不得低于本年级本专业的前90%

（二）科研成果得分

科研成果得分以学术论文、专著、专利、主持课题研究的分数为计算依据。该生的科研成果得分=P（该生科研成果累计得分）×权重。

权重注释：研二为40%，研三为55%

列入计算的论文、专利、专著和项目等分值P计算方式如下，

F=期刊五年影响因子（发表年份）× 系数（SCI为1，SSCI为1.4，科研项目为1）

G=主持科研项目得分

P =（F+G）/max（F+G）× 100

②期刊论文如未见刊（online 发表且具有doi号视为见刊），录用证明不视为正式发表。
