# 教育学部2026年本科生国家励志奖学金及助学金评定细则

根据学校《关于开展2026年国家励志奖学金评选工作的通知》和《关于开展2026年本科生助学金评选工作的通知》，结合我部家庭经济困难学生的实际情况，现将我部2026年本科生国家励志奖学金及助学金评定细则公布如下：
一、助学金体系构成
1.国家励志奖学金。
2.国家助学金。
二、获助资格条件
1.国家励志奖学金
（1）通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
（2）具有中华人民共和国国籍；
（3）热爱祖国，拥护中国共产党的领导；
（4）遵守宪法和法律，遵守学校规章制度，没有违纪行为；
（5）诚实守信，道德品质优良；
（6）勤奋学习，成绩优秀，成绩排名至少在专业前50%；
（7）积极上进，生活俭朴。
2.本科生助学金
（1）通过2026-2027学年度家庭经济困难认定的全日制在校本科生。
（2）符合各类助学金的申请条件（见附件1）。
（3）知晓并承诺履行助学金获助学生义务（见附件2）。
三、评定原则
1.按国家励志奖学金的评选要求，本学年度已获国家奖学金的学生，不可再申请国家励志奖学金。
2.学部申报后，一旦发现与条件不符者，即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。
四、资助名额分配
国家励志奖学金
国家助学金（一等）
国家助学金（二等）

五、评定流程及工作要求
1.学部助学金评审委员会
主任：吴长贤
委员：曹晓明 刘国艳 倪磊 刘树生 刘芳珍 邓建军 学生代表
2.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请。助学金申请系统于10月19日开通，10月22日上午9:00关闭，逾期不再接受申请。
3.学部在评选过程中坚持公平、公正、公开的原则，按照学部评选细则，严格审查申请学生资格，确定拟获资助名单，并在助学金系统中进行审核。学部将于2026年11月3日前完成各项助学金网上审核及公示（3个工作日）。
六、有关说明及注意事项
1.超过基本修业年限的学生不再享受国家助学金，也不能获得国家励志奖学金。
2.国家助学金和国家励志奖学金可以兼得。
