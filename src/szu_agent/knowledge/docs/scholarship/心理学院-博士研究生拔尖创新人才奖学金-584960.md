# 心理学院2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》和校长办公会有关精神，以及研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》（https://www1.szu.edu.cn/board/view.asp?id=583014）内容（以下简称“通知”），心理学院特制定2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作细则。
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生）。
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、一等奖与二等奖三个等级，博士研究生拔尖创新人才奖学金各等级奖励金额为：
（一）特等奖：7.7万元；
（二）一等奖：3.7万元；
（三）二等奖：1.7万元。
三、参评条件
学生申请博士研究生拔尖创新人才奖学金的基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。
（五）未受过任何校级、院级处分。
四、评选标准
（一）成果等级认定
按通知中对成果等级的认定标准执行。
具体评定标准在符合申请博士研究生拔尖创新人才奖学金基本条件基础上，按第一学年（新生）、其他学年（老生）分类评定，具体评定标准如下：
（一）第一学年（新生）
1.直博生
（1）发表（含录用，下同）B类及以上论文的，可获特等奖申请资格；
（2）来自高水平高校、来自普通高校且发表学术论文的，可获一等奖申请资格，并可纳入学院特等奖推优评选；
（3）来自普通高校的，可获二等奖申请资格。
2.硕博连读生
（1）在读硕士期间发表B类及以上论文的，可获特等奖申请资格；
（2）在读硕士期间发表C类论文的，可获一等奖申请资格，并可纳入学院特等奖推优评选；
（3）其他情况的，可获二等奖申请资格。
3.其他
（1）本科和硕士均来自世界排名前50院校、本科和硕士均来自高水平高校且发表B类及以上论文、来自普通高校且发表A类论文的，可获特等奖申请资格；
（2）本科和硕士均来自世界排名前100院校、本科和硕士均来自高水平高校且发表学术论文、来自普通高校且发表B类论文的，可获一等奖申请资格，并可纳入学院特等奖推优评选；
（3）本科和硕士均来自深圳大学或世界排名前200院校、发表C类论文的，可获二等奖申请资格。
（二）其他学年（老生）
其他学年博士生（老生）的博士研究生拔尖创新人才奖学金评定，应当达到所修读课程全部及格、必修课平均分不低于75分，且所参加的培养环节全部考核通过的基本要求，在此基础上：
1.在读博士期间，发表A类论文的，可获特等奖申请资格；
2.在读博士期间，发表B类论文的，可获一等奖申请资格，并可纳入学院特等奖推优评选；
3.在读博士期间，发表C类论文的，可获二等奖申请资格。
本年度特等奖不设置独立申报入口，取得特等奖申请资格的学生仍须填报一等奖参与申报，资格仅代表具备特等奖候入围条件，不等同于直接获得特等奖，最终由学院结合名额综合择优推优产生。
以上硕博连读新生、其他学年博士生（老生）的论文须以深圳大学为第一完成单位。
论文A类、B类、C类论文质量等级，根据学校科研管理部门制定标准如下：
1.人文社科类学术论文根据《深圳大学人文社会科学顶级、权威学术期刊目录（2023版）》分类：
A类为特级学术期刊和顶级学术期刊；
B类为权威学术期刊；
C类为普通C刊以及SSCI3/4区期刊。
以上期刊不含开源期刊、不含扩展版和集刊。
2.（1）自然科学类(不含计算机学科)学术论文按照中科院期刊分区分类标准（升级版-2023年、2025年）分以下等级：
B类为中科院期刊分区大类1区；
C类为中科院期刊分区大类2区。
具体可以查询网址：
http://www.lib.szu.edu.cn/zh-hans/er/fenqubiao
（中国科学院文献情报中心期刊分区表升级版-2025年，按文章发表年份认定）
以上期刊不含扩展版和集刊。
3.自然科学类论文不设A类等级。Nature、Science、Cell系列期刊不受分区约束，按B类对待，可申请一等奖，评审特等奖时予以重点考量。
4.特殊学科存在成果确有重大创新价值的，可由对应学科统一组织特殊申报，经学校批准后列入特殊名单，方可参与评选。
（二）名额分配
2026年博士研究生拔尖创新人才奖学金实行总额控制，在学校预算总金额内，鼓励争先创优，并引入竞争机制。研究生院按照申请情况测算总额并报学校审批后分别设定各学院的奖学金各等级名额。具体各等级奖励名额以研究生院下达为准。
五、评选程序
（一）评选原则
1. 分组评选：以学院符合特等奖、一等奖、二等奖申报资格的新生、老生申请总数为基数，按比例分别分配新生、老生的特等奖、一等奖、二等奖名额。一等奖名额分配时，应先扣除未获得特等奖的名额，再按比例进行分配。二等奖名额分配时，应先扣除未获得一等奖的名额，再按比例进行分配。若新生/老生分配名额不足1个，进位按1个计算；分配名额大于1个的，按四舍五入计算。若该等级下达的总名额仅有1个或分配时出现单一指标平分情况，则该单一指标不区分新老生，按申报者科研得分高低统一排序竞争。
2. 满足特等奖申报条件者按照申报者提供的代表性论文计算科研成果得分，进行排序，排名在下达名额数额内的申报者获特等奖；若未获得特等奖者，优先获得一等奖。
3.满足一等奖申报条件者按照申报者提供的代表性论文计算科研成果得分，进行排序，排名在下达名额数额内的申报者获一等奖；若未获得一等奖者，优先获得二等奖。
4.满足二等奖申报条件者按照申报者提供的代表性论文计算科研成果得分，进行排序，排名在下达名额数额内的申报者获二等奖。

5. 申请博士研究生拔尖创新人才奖学金的博士研究生须为所发表论文的独立通信作者或独立第一作者（人文社科类导师为第一作者、学生第二作者的，视为学生为第一作者）。学生为共同第一作者（或共同通信作者），论文级别需按降一级评定（注：共同一作：共一人数2人，等级须降一档；共一人数3或4人，等级须降两档；共一人数5人及以上，等级须降三档。Nature、Cell、Science三大顶刊共同一作可以不降档）。
6. 参评奖学金的学生所修读课程成绩以学籍系统数据为准。
7. 高水平高校名单为：深圳大学、985高校及最新世界排名前200名院校（须至少进入“ARWU、QS、THE、USNEWS”四大排行榜中的2个）。
8. 博士研究生拔尖创新人才奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
（二）评选步骤
1. 材料申报与资格初审​
（1）基础材料申报
所有申请人已于2026年9月29日前通过拔尖创新人才奖学金申请系统完成申报。系统将自动导出一份符合基本申报条件的学生名单（以下简称“基础名单”），该名单默认仅统计每位学生的一篇代表性论文，将用于计算学生的科研成果得分。如申报同一等级的申请人科研成果得分相同，则由申请人提供第二篇在成果认定时间段内的科研成果，再次计算科研成果得分。如仍存在得分相同的情况，则学业成绩较高者优先。
对于新生，如前期申报未提供科研成果，则需提供在成果认定时间段内的科研成果，用于计算科研成果得分。
（2）评审结果认定
学院依据申请人提交的材料按照以上评选原则组织心理学院博士生拔尖创新人才奖学金评审委员会负责评审工作。评选委员会对申请者进行排序推荐。
学院将会对推荐结果进行公示，公示无异议后，将最终推荐结果报送至研究生院，最终获奖结果以研究生院公布为准。
