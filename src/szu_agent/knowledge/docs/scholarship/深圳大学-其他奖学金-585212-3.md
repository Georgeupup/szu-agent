# 深圳大学“双创之星”评选细则（2026）

（校级文件，随《人文学院本科卓越班奖学金评选细则（试行）》附发）

深圳大学“双创之星”评选细则（2026）

为鼓励学生积极参与课外学术科技活动，全面提高学生的创新意识与创业能力，努力拓展学生综合素质，培养知识、能力、人格协调发展的优秀科技创新创业人才，根据《深圳大学本科生奖学金评定办法（修订）》（深大〔2024〕290号），结合我校实际情况，现就我校“双创之星”评选细则规定如下：

一、评选条件

评选学年度内，取得标志性的创新创业成果。

二、参评标准

一二三等奖总获奖比例不超过本学院（部）参评学生总人数的10%。

1．满足下列条件之一，可申请一等奖学金：

（1）自然科学类学术论文被SCI Ⅰ区、Ⅱ区、Ⅲ区（论文分区参照JCR、中科院分区等，下同）收录，或人文社科类学术论文被SSCI Ⅰ区、Ⅱ区收录或在《深圳大学人文社会科学顶级、权威学术期刊目录（最新版）》认定的学术期刊上发表；

（2）获《深圳大学“双创之星”参评标准》中学术类或创业类Ⅰ类竞赛第二等级奖项及以上、Ⅱ类竞赛最高等级奖项；

（3）获得国家发明专利（取得授权）。

2．满足下列条件之一，可申请二等奖学金：

（1）自然科学类学术论文被SCI Ⅳ区、EI、ISTP收录，或人文社科类，在除了《深圳大学人文社会科学顶级、权威学术期刊目录（最新版）》认定的学术期刊外的CSSCI期刊（不含扩展版）或者被SSCI收录的Ⅲ区的学术期刊（不含开源期刊和各学科负面清单期刊）发表的学术论文；

（2）获《深圳大学“双创之星”参评标准》中学术类或创业类Ⅰ类竞赛第三等级奖项、Ⅱ类竞赛第二等级奖项、Ⅲ类竞赛最高等级奖项；

（3）获得实用新型专利（取得授权）。

3．满足下列条件之一，可申请三等奖学金：

（1）获《深圳大学“双创之星”参评标准》中学术类或创业类Ⅱ类竞赛第三等级、Ⅲ类竞赛第二等级奖项，或中国国际大学生创新大赛深圳大学校赛金奖，或“荔园挑战”大赛学术赛道特等奖，或“荔园挑战”大赛创业赛道金奖；

（2）论文在一般学术期刊（不含增刊）上发表；

（3）获得外观设计专利（取得授权）。

4．特别说明：

（1）科技专业竞赛：

包括《深圳大学“双创之星”参评标准》中学术类、创业类Ⅰ、Ⅱ、Ⅲ类比赛；

申请者本人须为主要参加人（以获奖证书为准），深圳大学为获奖单位；

若同一成果获得不同等级奖项，仅以最高奖项参评；

团队参赛的，只接受团队贡献排名第一的成员申报，如获评奖，则以整个参赛团队为单位获颁奖学金，所有团队成员（以获奖证书为准，且成员符合奖学金评选基本条件）均可获荣誉证书；项目团队需提交《深圳大学“双创之星”团队奖学金申请表》，每个项目团队填一份申请表。

（2）学术论文：

深圳大学为第一完成单位，申请者为第一作者；

发表在相应级别刊物上的学术会议综述和书评，不能被认定为学术论文；

学术论文需提供论文刊物封面、目录页、正文页。收录证明统一由学生部在图书馆开据。

（3）专利：

申请者本人须作为第一发明人（我校为第一知识产权人）。

（4）在校期间，同一成果仅能申请一次“双创之星”奖，评选等级详见《深圳大学“双创之星”参评标准》。

三、评选程序

1．学生本人在办事大厅奖学金板块申请，并附相关证明材料。

2．各学院（部）学生奖学金评审委员会根据评选细则对学生申请材料进行评审，并将拟获奖学生名单及相关材料汇总上报学生部。

3．学生部对学院（部）上报的拟获奖学生材料进行复核，复核结果公示后报学校学生资助工作领导小组审批。

4．公布正式获奖名单并进行表彰。

本评选细则自发布之日起实施。

深圳大学学生部
