# 艺术学部2026年国家励志奖学金评定细则

根据《学生资助资金管理办法》《深圳大学本科生国家励志奖学金评审办法》，结合艺术学部实际情况，现开展艺术学部2026年国家励志奖学金评定工作，具体通知如下：
一、申请条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活俭朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%。
二、评定原则
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.国家励志奖学金、国家助学金可以同时申请，学部评定小组会根据学生在校表现、家庭困难情况及学校分配名额开展评定工作。
3.学部申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。
三、名额分配
艺术学部共有45个国家励志奖学金名额。
四、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，须上传成绩单。助学金申请系统已于10月19日开通，将于10月22日9：00关闭，逾期不予申请。
2.学部在评选过程中坚持公平、公正、公开的原则，按照本学部评定细则，严格审查申请学生资格，确定拟获资助名单，并在学部意见一栏应签署详细意见。学部将于11月3日前完成各项助学金网上审核及公示（3个工作日）。
