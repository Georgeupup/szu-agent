# 法学院2026年本科生国家励志奖学金及助学金评选细则

根据学校《关于开展2026年国家励志奖学金评选工作的通知》和《关于开展2026年本科生助学金评选工作的通知》，结合我院家庭经济困难学生的实际情况，现就开展我院2026年国家励志奖学金、助学金评定工作通知如下：
一、体系构成
1. 国家励志奖学金
2. 政府助学金：国家助学金。
二、国家励志奖学金申请条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校二年级及以上本科生。
2.具有中华人民共和国国籍；
2.热爱祖国，拥护中国共产党的领导；
3.遵守宪法和法律，遵守学校规章制度，没有违纪行为；
4.诚实守信，道德品质优良；
5.勤奋学习，成绩优秀，上学年成绩排名至少在前50%；
6.积极上进，生活简朴。
三、国家助学金获助资格条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱社会主义祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.诚实守信，道德品质优良；
6.勤奋学习，积极上进，生活简朴；
7.在基本修业年限内。
四、评定原则
1. 国家励志奖学金、国家助学金可以同时申请，学院评定小组会根据学生情况及学校分配名额开展评定工作。
2. 按国家励志奖学金的评选要求，本学年度已获国家奖学金的学生，不可再申请国家励志奖学金。
3. 学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。

六、评定流程及工作要求
1. 学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请。助学金申请系统于10月19日开通，10月22日上午9:00关闭，逾期不予申请。
2. 学院成立助学金评定小组，在评选过程中坚持公平、公正、公开的原则，按照本学院评选细则，严格审查申请学生资格，确定拟获资助名单，并在学院意见一栏签署详细意见。学院于规定时间内完成各项助学金网上审核及公示（3个工作日）。
