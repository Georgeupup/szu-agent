# 集成电路学院2026年国家励志奖学金评定细则

根据《学生资助资金管理办法》《深圳大学本科生国家励志奖学金评审办法》及我校实际情况，现开展2026年国家励志奖学金评定工作，请符合条件的同学按要求及时申报。具体通知如下：
一、申请条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名在前50%以上；
二、评定说明
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.对不符合条件者，一经核实即取消评选资格，名额自动作废；弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等）一律取消当年评选资格，并按学校有关规定严肃处理。
三、名额分配
国家励志奖学金名额：26人。
四、评定流程
1.网上申请：学生本人登录深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，须上传成绩单。申请系统于10月19日开通，10月22日上午9：00关闭，逾期不再受理。
2.学院坚持公平、公正、公开原则，严格审查申请学生资格，确定拟获奖名单，于11月3日前完成国家励志奖学金的网上审核及公示（3个工作日）。
