# 化学与环境工程学院2026年研究生学业奖学金评选细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合我校实际情况，现就研究生学业奖学金评审工作的有关事宜通知如下：
一、参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年（2026级）设特等、一等、二等三个等级，第二学年及以后（2024级、2025级）设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1．2026级研究生：所有推免生、一流大学建设高校（42所名单见附件5）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等（名单见附件2）。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
2． 2024级、2025级研究生：所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。根据参评研究生的学习成绩、科研成果综合评定，分专业进行排名，名额见附件1。
2024级、2025级科研成果积分评定标准：
2024级学生如有科研成果，且该成果经下述标准认定为有效，优先获得奖学金，无科研成果的按照必修课平均成绩排序；2025级学生优先按必修课平均成绩排序，如有科研成果，可予以加分。本次使用过的科研成果，不得在后续学业奖学金评定中重复使用。
学位课程平均成绩达到 75 分以上（含 75 分），所修课程全部通过（成绩排名以所修所有必修课平均成绩为准，以研究生院提供版本为准）；
2024级、2025级学生如有科研成果，积分认定需满足下列条件：
发表高水平学术论文。（1）在国内外权威学术刊物上公开发表具有较高学术价值的学术论文，发表论文署名第一单位须为深圳大学，申请人为第一作者。若申请人为第二作者，第一作者必须是其第一导师；同等条件下，学生为第一作者优先。（2）以共同第一作者发表的论文，计算论文时按共同贡献人数平均计算。（3）在中科院大类1区、2区、3区和4区（以升级版中科院分区为准）期刊上发表的论文系数分别为1、1/2、1/3和1/4。学术论文分值计算办法为：论文数×论文系数×论文影响因子。如某同学发表中科院大类1区、2区、3区和4区论文各2篇，影响因子分别为5、4、3和2，则该同学的论文计分为：2×1×5+2×1/2×4+2×1/3×2+2×1/4×2=16.3；对于在Nature Index期刊上发表论文或发表了高被引论文的学生，在积分同等的情况下优先推荐。
获得授权发明专利。1项授权国家发明专利系数为1.0，等同于影响因子为1.0的学术论文；1项PCT授权专利系数为1.0，等同于影响因子为1.5的学术论文。如果同一技术申请了不同类型的专利，按计分最高的来计算，不进行累加。注：发明专利授权需以深圳大学作为第一专利权人，且要求申请人为独立或第一发明人，或导师为第一发明人，申请人为第二发明人;
在重大学科竞赛中获奖。参照《深圳大学本科生学科竞赛清单》（见附件4）I、II和III级分类，其计分规则为：1）I类竞赛，最高等级奖励计 10.0分，第二等级奖励计 7.0分，第三等级奖励计 5.0分，其他等级奖励计3.0分。2）II类竞赛，最高等级奖励计 5.0分，第二等级奖励计 3.5分，第三等级奖励计 2.5分，其他等级奖励计1.5分。3）III类竞赛，最高等级奖励计 2.5分，第二等级奖励计 1.5分，第三等级奖励计 1.0分，其他等级奖励计0.5分。同一题目取得不同层级竞赛奖励时，取计分最高的来计算，不进行累加。同一项获奖仅排名前2的学生可共享该奖励，比值为7:3。
在科研课题或创新创业项目等方面取得突出成绩，能提供相关证明材料。
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
四、评审日程
（一）9月16日：学生部公布研究生学业奖学金评选工作通知，下达评选名额（附件1）。
（二）9月17日—9月22日：各学院（部）成立研究生学业奖学金评审委员会，评审委员会在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。
（三）9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅（一定要网上申请，不申请视为自动放弃评奖资格！）http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料(成绩单、科研成果)，提交后打印申请表、本人签名，附成绩单、相关成果复印件纸质版，送交给班长。（学业奖学金申请系统开放时间为：9月23日8:00—9月30日23:00）
（四）10月8日—10月21日：各学院（部）组织评审会，对申请研究生学业奖学金的学生进行初步评审。确定学院（部）推荐名单后，在全校范围内进行公示（不少于5个工作日）。
（五）10月21日后：学生部审核、公示获奖名单，报校领导审批。
（六）校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
五、有关说明及注意事项
（一）参评研究生学业奖学金所涉及的科研成果、奖励等认定截止时间为2025年9月1日。针对毕业班研究生，可适当放宽时间。已接收未在线出版、送稿中或评审中的未接收文章不计为科研成果，请勿写入申报表格。如此次参评的科研成果已在学院2025年（含）之前的研究生学业奖学金中使用并获奖，则不予计入。否则，一经发现，取消评奖资格。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（三）硕士研究生（包括特等和一等认定的研究生）、学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单。个人申报材料包括：《研究生学业奖学金申请审批表》、成绩单、论文（需附上全文）等相关证明材料。
（四）对认定或评审结果有异议的学生，可在各学院（部）公示阶段向所在学院（部）评审委员会提出申诉，学院（部）评审委员会应及时研究并予以答复。如学生对学院（部）评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
（六）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策以及校内其他研究生奖助政策资助。
（七）奖学金申报过程中严禁弄虚作假，一经发现，立即取消评奖资格，投诉电话:0755-86938195，王老师。
