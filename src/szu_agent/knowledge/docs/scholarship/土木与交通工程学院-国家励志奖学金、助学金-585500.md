# 土木与交通工程学院2026-2027学年度国家励志奖学金评选细则

根据《学生资助资金管理办法》《深圳大学本科生国家励志奖学金评审办法》，结合我院实际情况，现开展我校2026年国家励志奖学金评定工作，具体通知如下：
一、申请条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度，没有违纪行为
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%；
二、评定原则
1.按国家励志奖学金的评选要求，本学年度已获国家奖学金的学生，不可再申请国家励志奖学金。
2.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。
三、名额
28人
四、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金板块申请，须上传成绩单。助学金申请系统于10月19日开通，10月22日上午9：00关闭，逾期不予申请。
2.10月21日前，学院在学校各项助学金申请条件、评定原则、评定要求的基础上，结合本学院实际情况，制定并公布评选细则及评审委员会名单。公示无异议后，在学校公文通上予以公布，并通过邮件公文发送至学生部。
3.学院在评选过程中应坚持公平、公正、公开的原则，按照本学院评定细则，严格审查申请学生资格，确定拟获资助名单，于规定时间内完成各项助学金网上审核及公示（3个工作日）。
4.若有疑问可联系申老师，办公电话0755-26735711。
