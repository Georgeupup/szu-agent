# 计算机与软件学院2025-2026学年度研究生奖学金评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）、《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）、《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将计算机与软件学院研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜及细则通知如下：
壹·研究生国家奖学金
一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
三、名额分配
（一）根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），我院博士研究生名额4个名额；硕士研究生名额20个名额。
（二）博士、硕士均以学院为单位分配名额，实行定额评审，校级复核确定最终人选。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）践行社会主义核心价值观，道德品质优良；
（四）学习成绩优异，学业成绩的最低要求为学位课程平均成绩达到75分以上（含75分），且全部所修课程通过。
（五）科研能力显著，发展潜力突出，综合考虑参评者发展情况。
科研成果要求：在本专业核心期刊上公开发表学术论文；或获得省级以上奖励；或申请国家发明专利（实质审查）；或其它有特殊贡献或者突出贡献者（需评审委员会讨论认定）。
（六）科研条件：
（1）在国内外知名学术期刊上公开发表具有较高学术价值的期刊论文1篇或以上。发表论文署名的作者第一单位须为深圳大学，申请人为第一作者；若为第二作者，第一作者必须是其导师。参评论文需正式出版或在线出版。同等条件下，学生为第一作者优先，以共同第一作者发表的论文，按共同人数平均计算。
（2）获得1项或以上国家发明专利授权（申请人为第一发明人；若为第二发明人，第一发明人必须是其导师）。
（3）作为负责人在重大学科竞赛中获奖。
（4）作为负责人取得其他突出成绩，能提供相关证明材料。
贰·研究生社会奖学金
一、鹏程奖学金
（一）名额及奖励标准
研究生（不分硕博）1人，每生每年10000元；（附件6）
（二）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（三）评选条件
1.热爱祖国、遵纪守法、品行端正、举止文明、没有违法违纪行为；
2.刻苦学习、成绩优异、在全班或全年级名列前茅；
3.具有较强的科研能力，有公开发表科研成果（具体科研条件可参考国家奖学金）。
二、比亚迪奖学金
（一）名额及奖励标准
硕士生3人，每生每年20000元。（附件1）
（二）评选对象
根据捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二年级及以上硕士博士研究生，只在标准学制内参评。具体学院及名额见附件1。
（三）评选标准
1.坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。
2.热爱祖国，热爱人民，拥护中国共产党的领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。
3.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
4.具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
5.德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
6.在符合上述条件前提下，还应至少满足下列条件之一：
（1）以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文；
（2）以前两顺位发明人申请国家发明专利；
（3）在国际/国家级重大的学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
（4）曾在重大科研项目中担任主要完成人。
叁·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
每生每年2000元。
三、奖励名额
22个名额。（附件1）
四、参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的评选安排如下：
一、评选程序
（一）9月11日—9月16日：计算机与软件学院成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定本学院的评选细则、开展初步评审等工作。院评审委员会名单（附件2）及评选细则需在学校公文通上予以公示。公示无异议，9月16日前将评选细则及评审委员会名单电子版（可编辑Word文件及签字盖章后PDF扫描件）【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（二）9月14日—9月17日：所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，如申请国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4，可下载系统生成的文档）至系统，完成系统申请后由学生本人打印申请表（双面打印在一张A4纸）并签名，附上相关成果复印件，经导师（推荐人）签字，送交计算机与软件学院评审委员会联络人熊老师处。（奖学金申请系统开放时间为：9月14日8:00—9月17日23:00）。国奖申请理由需填写至少半页以上，否则无效。纸质版申请材料提交截止时间为9月18日中午12:00。地点：致腾楼计算机与软件学院820。逾期不予采纳。电子版材料以邮件的形式发送至邮箱（个人邮箱已省略，见原通知）,（邮件命名：姓名+班级+奖项参评材料；附件命名：姓名+班级+佐证材料（PDF格式，按照论文、专利、竞赛获奖、项目、其他等顺序排列））。
（三）9月18日—9月30日：学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院拟推荐名单后，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。公示无异议后，9月30日前将以下材料电子版通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交：
1.XX学院（部）2025-2026学年度研究生奖学金评选情况总结（附件7）的可编辑Word文件及签字盖章后PDF扫描件；
2.学院（部）推荐名单汇总表（附件4、5、6）的可编辑Excel文件及签字盖章后PDF扫描件；
3.国家奖学金推荐学生个人申请审批表的签字盖章后PDF扫描件；
4.比亚迪奖学金推荐学生的成绩前30%盖章证明及符合参评条件的成果证明。（比亚迪奖学金推荐学生的个人申请审批表需提交签字盖章后的纸质文件到汇昀楼305室/丽湖校区综合服务大厅22号窗口。）
（四）10月8日－10月14日：学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（五）对评审结果有异议的学生，可在学院公示阶段向学院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（六）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
二、其他事项
（一）个人申报材料除申请表以外，科研成果复印件（承担科研项目及获奖证书复印件、发表论文期刊封面、目录、论文首页复印件、专利证书复印件）、获奖证书复印件及其他可证明本人优异表现的佐证材料。有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件3，图书馆咨询电话26537002。同时提交《计算机与软件学院研究生奖学金评审表_2026》。
（二）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
（三）研究生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
（四）同一年度国家奖学金、鹏程、比亚迪奖学金不可兼得。不同年度，如果成果不重复，则可以兼得。
（五）研究生学业奖学金评选工作将于9月中下旬启动。
（六）获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
（七）学院奖学金评审委员会对本细则未尽事宜有解释权。
