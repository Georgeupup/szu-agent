# 集成电路学院2026度深圳大学博士研究生拔尖创新人才奖学金评选工作细则

根据《深圳大学博士研究生拔尖创新人才奖学金管理暂行办法（修订）》（深大校发〔2024〕308号）和校长办公会有关精神，以及研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》通知内容，学院制定并公布2026年度深圳大学集成电路学院博士研究生拔尖创新人才奖学金评选细则。
一、评选对象
在标准学制内或经申请核准后延长一年内的深圳大学在籍在读全日制非定向博士研究生（含“少数民族高层次骨干人才计划”、留学博士生）。
二、奖励标准
博士研究生拔尖创新人才奖学金分为特等奖、一等奖与二等奖三个等级，博士研究生拔尖创新人才奖学金各等级奖励金额为：
（一）特等奖：7.7万元；
（二）一等奖：3.7万元；
（三）二等奖：1.7万元。
三、参评条件
学生申请博士研究生拔尖创新人才奖学金的基本条件：
（一）若为中国公民，须热爱祖国、拥护中国共产党的领导、拥护社会主义制度；若为境外个人，须对华友好。
（二）自觉遵守国家法律法规，遵守学校各项规章制度。
（三）诚实守信，品德优良。
（四）积极参与学术研究，所有修读课程不存在不及格情形。
（五）未受过任何校级、院级处分。
四、评定标准
按学校研究生院发布的《关于开展2026年度深圳大学博士研究生拔尖创新人才奖学金评选工作的通知》中成果认定标准执行。
2026年博士研究生拔尖创新人才奖学金实行总额控制，在学校预算总金额内，鼓励争先创优，并引入竞争机制。学院各等级奖励名额以研究生院下达为准。具体评选方法结合研究生院下达的奖励名额及全院申报情况统筹考虑后再补充制定。
五、评选程序
学院对所有申请是否符合要求进行审核后，组织学院评审委员会（见附件1）进行评审。学院将会对推荐结果进行公示，公示无异议后，将最终推荐结果报送至研究生院，最终获奖结果以研究生院公布为准。
六、其他事项
（1）参评奖学金的学生所修读课程成绩以学籍系统数据为准。
（2）本通知仅适用本次奖学金评选。
七、科研成果引导
学院鼓励博士研究生坚持科研成果质量导向，积极在中科院大类1区、2区学术期刊发表高水平论文，同时鼓励在ISSCC、IEDM、VLSI等集成电路领域国际顶级学术会议、CCF-A类学术会议及期刊，以及Nature Index收录期刊、IEEE Transactions系列等具有较高学术影响力的期刊发表代表性科研成果。
请各位博士研究生提前规划，注重成果创新性、学术质量及影响力，合理安排论文投稿。
