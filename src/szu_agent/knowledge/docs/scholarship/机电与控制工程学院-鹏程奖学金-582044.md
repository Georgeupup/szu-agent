# 机电与控制工程学院2025-2026学年度研究生奖学金评选细则（含鹏程奖学金）

根据财政部、教育部《学生资助资金管理办法》、《深圳大学研究生国家奖学金评审办法（修订）》、《深圳大学优秀研究生、优秀研究生干部评选办法》和学校相关社会奖学金设置协议等文件要求，为促进我院研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我院2026年研究生奖学金评审工作公开、公平、有序进行，现将评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、评选对象在我院攻读硕士的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年3万元；硕士研究生国家奖学金奖励标准为每生每年2万元。
三、评选名额评选国家奖学金名额硕士研究生16名，博士研究生1名。
四、参评条件（一）基本条件（1）热爱社会主义祖国，拥护中国共产党的领导；
（2）遵守宪法和法律，遵守高等学校规章制度；
（3）诚实守信，道德品质优良；
（4）学习成绩优异，科研能力显著，发展潜力突出；
（5）所修课程全部通过，学位课或必修课平均成绩达到75分以上（含75分），成绩排名按照所修所有学位课或必修课的平均成绩计算，以学籍系统数据为准。
其他条件请参照学生部发《关于开展2025-2026学年度研究生奖学金评选工作的通知》公文通内容。
（二）科研条件（1）研究生参评奖学金的各类科研成果包括：论文、科学著作、专利、高水平学科竞赛、专业作品等。
（2）研究生参评奖学金的各类科研成果认定的截止时间为2026年8月31日；针对毕业班研究生，截止时间放宽到2026年9月17日。
（3）申请国家奖学金及社会奖学金的所有科研成果只能使用一次，不得重复申报。去年获得国家奖学金及社会奖学金所用过的科研成果此次不能再用，本次获奖学生的科研成果，以后也不得再次使用该成果申请国家奖学金及社会奖学金。
（4）参评学生需满足下列条件之一：
1）在国内外知名学术期刊上公开发表具有较高学术价值的期刊论文1篇或以上。发表论文署名的作者第一单位须为深圳大学，申请人为第一作者；若为第二作者，第一作者必须是其导师。参评论文需正式出版或在线出版。同等条件下，学生为第一作者优先，以共同第一作者发表的论文，按共同人数平均计算。
2）获得1项或以上国家发明专利授权（申请人为第一发明人；若为第二发明人，第一发明人必须是其导师）。
3）作为负责人在重大学科竞赛中获奖。
4）作为负责人取得其他突出成绩，能提供相关证明材料。
贰·研究生社会奖学金
一、比亚迪奖学金
1、评选对象根据捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二年级及以上硕士博士研究生，只在标准学制内参评。
2、奖励标准一次性奖励20000元。
3、评选名额硕士研究生2名。
4、参评条件1.坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。
2.热爱祖国，热爱人民，拥护中国共产党的领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。
3.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
4.具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
5.德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
6.在符合上述条件前提下，还应至少满足下列条件之一：
（1）以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文；
（2）以前两顺位发明人申请国家发明专利；
（3） 在国际/国家级重大的学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
（4）曾在重大科研项目中担任主要完成人。
二、鹏程奖学金
1、名额及奖励标准研究生1名，10000元。
2、评选对象在校全日制研究生（延期毕业的研究生除外，博士研究生延期一年内可申请）。
3、评选标准1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为。
2.刻苦学习、成绩优异，在全班或全年级名列前茅。
3.具有较强的科研能力，有公开发表科研成果。
叁·优秀研究生干部
一、参评对象优秀研究生干部的参评对象为经我院正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
三、奖励名额优秀研究生干部获奖名额：15名。
申请人数超出下达名额的，同等条件下优先推荐成果突出的参评者，符合评奖条件的申请人数达不到下达名额的，奖项名额自动空缺。
四、参评条件优秀研究生干部主要奖励优秀的校、院级研究生干部或学校社团组织负责人以及在社会工作中表现突出的个人。参选人须同时满足下列条件：
1）担任校、院级研究生干部、学校社团组织负责人累计满一年，或在公益组织中服务满一年；
2）任职期间有突出工作表现，能提供典型材料及例证；
3）学习态度端正，所修课程全部通过。
评奖办法及流程：
一、评选办法9月17日23:00前：所有符合参评条件并有意愿申请奖学金的研究生登陆深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在线填写申请表（其中申请理由需填写半页以上），打印申请表后本人签名，附证明材料，经导师（推荐人）签字，于9月18日上午11点前送交沧海校区致信楼S626黄老师处，逾期不再接收。
二、评选程序1）9月16日前，学院成立院评审委员会，由学院主要领导担任主任委员，研究生导师、行政管理人员、学生代表任委员。院评审委员会负责制定学院评选细则，并在学校公文通上予以公布。
2）9月14日-9月17日，个人网上申报，并将相关申报材料上交学院。
3）9月18日-9月30日，院评审委员会对参选学生进行初步评审，并对获奖候选人进行公示。（参评成果截止时间：二年级同学为2026年8月31日，三年级同学为2026年9月14日，所有成果不得重复申报。学院评审委员会经审核个人申报材料后，将组织参选学生现场答辩（需自行准备PPT），并由评审委员会的各位评委依据材料及学生现场陈述进行投票，评选出国家奖学金、社会奖学金及优秀研究生干部。）
4）对评审结果有异议的学生，可在学院公示阶段向院评审委员会提出申诉，院评审委员会及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向校评审领导小组提请裁决。
三、其他1）论文说明：所有论文被SCI/SSCI（理工/文科）、EI（理工）、ISTP/ISSHP（理工/文科）、CSCD/CSSCI（《中国科学引文数据库》/《中文社会科学引文索引》，理工/文科）等收录的，无需校图书馆开具的检索证明，但必须在相关数据库中检索出来，打印全文上交；对于SCI、SSCI论文最新的期刊分区及影响因子检索出来，截图打印上交。检索指引咨询图书馆电话26537002。特别提醒：在线出版的需提供在线出版网址并提交网上截图，并由导师签字确认，证明成果属实。
2）参评研究生成绩排名根据所修所有学位课或必修课的平均成绩进行计算，以学校系统数据为准。
3）研究生社会奖学金的评审及申报过程严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消评奖资格；对于已获得者，追回证书奖金，并按学校相关规定处理。
4）同年度研究生国家奖学金、社会奖学金二者不可兼得。
5）机电与控制工程学院评审工作联系方式：
联络人：黄老师、卓老师 办公电话：26609137、22673861 办公地点：致信楼S626
6）本办法未尽事宜，由我院研究生评审委员会负责解释。
