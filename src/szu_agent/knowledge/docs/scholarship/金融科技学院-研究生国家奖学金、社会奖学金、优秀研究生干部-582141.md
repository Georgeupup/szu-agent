# 金融科技学院2025-2026年度研究生国家奖学金、社会奖学金及优秀研究生干部评选细则

根据财政部、教育部《学生资助资金管理办法》《深圳大学研究生国家奖学金评审办法（修订）》《深圳大学优秀研究生、优秀研究生干部评选办法》和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年3万元；硕士研究生国家奖学金奖励标准为每生每年2万元。
三、名额分配
金融科技学院国家奖学金硕士研究生获奖名额为2名。
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守高等学校规章制度；
（三）诚实守信，道德品质优良；
（四）学习成绩优异，科研能力显著，发展潜力突出；
（五）积极参与学术与科研活动。
贰·研究生社会奖学金
一、鹏程奖学金
（一）名额及金额
硕士生1人，一次性奖励10000元。
（二）评选对象
在校全日制2024、2025级研究生（延期毕业的硕士研究生除外）。
（三）参评条件
1、热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2、刻苦学习、成绩优异，在全班或全年级名列前茅；
3、具有较强的科研能力，有公开发表科研成果。
叁·优秀研究生干部
一、评选对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
二、奖励标准
优秀研究生干部奖励标准为每生每年2000元，并颁发证书。
三、奖励名额
金融科技学院优秀研究生干部为2名。
四、参评条件
优秀研究生干部主要奖励优秀校、院级研究生干部或学校社团组织负责人以及在社会工作中表现突出的个人。参选人须同时满足下列条件：
优秀研究生干部主要奖励优秀校、院级研究生干部或学校社团组织负责人以及在社会工作中表现突出的个人。参选人须同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的评选安排如下：
一、评选程序
（一）9月11-16日，学院成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定本学院（部）的评选细则、开展初步评审等工作。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。
（二）9月14-17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件3，可下载系统生成的文档）至系统，打印申请材料，学生本人签名，附相关成果复印件，经导师签字，于9月19日前送交学院评审委员会联络人李卡老师（汇元楼356）。申报各类奖项时，相关佐证材料均需上传至系统附件。
（三）9月18-30日，学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核并公示。
（四）10月8-14日，学生部复核各学院推荐名单，并将校级推荐名单在全校范围内进行公示。
（五）对评审结果有异议的学生，可在学院公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（六）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
二、其他事项
（一）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励已在前次评奖使用且已获奖则不得重复使用。
（二）有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件2，图书馆咨询电话26537002。
（三）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
（四）研究生学业奖学金评选工作将于9月中下旬启动。
（五）获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
（六）国家奖学金、社会奖学金（以及不同类社会奖之间）不可兼得。
注意事项：
1、申请人发表的论文需为第一作者；若为第二作者，第一作者必须是其导师。研二同学参评成果必须是已经刊登的成果，不包含录用通知，计算时限为：2025年9月1日至2026年8月31日，毕业年级研究生科研成果，计算时限为：2025年9月1日至2026年9月18日。
2、同等条件下，学院评审委员会应根据参评者科研成果的学术水平、刊物等级等因素综合评定。
3、奖学金申报过程中严禁弄虚作假，一经发现，立即取消评奖资格，投诉电话：0755-26530775 李老师，办公地址：深圳大学汇元楼356室。
