# 心理学院2025-2026年度研究生国家奖学金、社会奖学金及优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部的评选工作有关事宜通知如下：
壹·研究生国家奖学金
一、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
二、奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
三、奖励名额
心理学博士：1人
心理学硕士：3人
应用心理专业硕士：3人
四、参评条件
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习成绩优异，科研能力显著，发展潜力突出。
五、评选要求
综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素，详情请见附件2《2026学年度心理学院国家、社会奖学金综合成绩评定办法》。
贰·研究生社会奖学金
一、鹏程奖学金
（一）名额及金额
学院推荐名额1名，一次性奖励10000元（单列指标，不分硕博）。
（二）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（三）评选标准
1、热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为；
2、刻苦学习、成绩优异，在全班或全年级名列前茅；
3、具有较强的科研能力，有公开发表科研成果；
4、详情请见附件2《2026学年度心理学院国家、社会奖学金综合成绩评定办法》。
叁·优秀研究生干部
一、参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
二、奖励标准
每生每年2000元。
三、奖励名额
我院推荐名额6人（不分硕博）。申请人数超出研究生管理部门下达名额的，同等条件下优先推荐表现突出的参评者，符合评奖条件的申请人数达不到研究生管理部门下达名额的，奖项名额自动空缺。
四、参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
（七）参评人需参加心理学院评优评先委员会组织的答辩，由委员会通过投票表决的方式得出最终推荐人员。

## 附件：2026学年度心理学院国家、社会奖学金综合成绩评定办法

2026学年度心理学院国家、社会奖学金综合成绩评定办法

为全面衡量研究生综合学习素质，评选采用综合考评方式，采取量化评分制度，即研究生在评选期内按“学业成绩、科研成果、获奖情况、社会实践与服务”四个方面分别评分，最终得出四项相加的总分，四项的总分即为研究生在此次评选中的综合考评成绩，也即研究生国家、社会奖学金的最终评定标准（分数计算保留小数点后两位）。

研究生综合考评成绩=学业成绩得分（25%）+科研成果得分（55%）+获奖得分（10%）+社会服务与实践得分（10%）。

注：1.科研成果、获奖、社会服务与实践认定时间：2025年9月1日至2026年8月31日。针对毕业班研究生，认定时间可延长至学校申请系统关闭当日。

2.所有学术成果和科研项目均需以“深圳大学心理学院”或学校认定的心理学院下属科研单位为第一署名单位。

3.其中去年已经参评过国家奖学金、社会奖学金的成果今年不得重复提交；若重复提交已参评过国家、社会奖学金的成果，取消参评资格。

（一）学业成绩得分

研究生学业成绩得分=申请人必修课平均分/所在年级专业必修课平均分最高分×100×25%。

注：硕士研究生申请国家奖学金、社会奖学金的申请人必修课平均成绩排名不得低于本年级本专业的前90%

（二）科研成果得分

科研成果得分以学术论文、专著、专利、主持课题研究的分数为计算依据。该生的科研成果得分=P（该生科研成果累计得分）×55%。

列入计算的论文、专利和专著等分值P计算方式如下，

F=期刊五年影响因子（发表年份）× 系数（SCI为1，SSCI为1.4，科研项目为1）

G=主持科研项目得分

P =（F+G）/max（F+G）× 100

②期刊论文如未见刊（online 发表且具有doi号视为见刊），录用证明不视为正式发表。

③期刊五年影响因子为论文见刊（或在线发表）当年的五年影响因子，若发表当年的影响因子尚未公布，应以最新可查到的数据为准

④严禁一稿多发（参评成果有60%以上相似视为一稿多发），一经发现，取消参评人当学年参评资格。

（2）列入计算的课题分为学生本人主持的科研项目课题须在2025年9月1日至2026年8月31日之间立项（毕业生可延长至学校申请后系统关闭当日），申请人作为项目主持人的信息必须明确呈现在项目下达的批准书/立项书/公示/课题合同中（单位和老师的证明均无效），方能列入加分项。
