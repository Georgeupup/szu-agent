# 受助学生义务

（校级文件，随《高等研究院2026年本科生助学金（含国家励志奖学金）评选细则》附发）

此文档含“各项助学金受助学生基本义务”及《深圳市中集慈善基金会“中集助学金”受助学生承诺书》

各项助学金受助学生基本义务

热爱社会主义祖国，拥护中国共产党的领导；

遵守宪法和法律，遵守学校规章制度；

诚实守信，品行端正；

努力学习，积极向上，积极参加志愿服务和公益活动；

生活俭朴，不挥霍浪费；

按设助单位要求，按时提交成绩单等材料及参与相关颁发

仪式、座谈见面会及该资助项目所要求的其他活动（如有）。

深圳大学孙熙涛助学金受助学生义务

有意向申请的学生应在申请时在系统中上传《大学规划及未来展望》（见附件7）,不少于600字。

按照资助方的要求，汇报思想、学习情况，参与相关颁发仪式、座谈见面会及本资助项目所要求的其他活动（如有），并接受资助方的考评（如有）。

深圳大学“中集助学金”受助学生义务

1. 知晓并同意签署《深圳市中集慈善基金会“中集助学金”受助学生承诺书》，并履约践诺。《承诺书》见下文。

2. 中集助学金分两学期发放，资助特别困难学生4年全额学费及住宿费，资助一般困难学生4年全额学费。学生应按要求按时提交学费收据等材料。如成绩出现不及格的情况，下一学年起不再继续享有本助学金。

3. 按照中集慈善基金会的要求，汇报思想、学习情况，提交录取通知书、每学期成绩单、学期评价表等，参与相关颁发仪式、座谈见面会及本资助项目所要求的其他活动（如有），并接受资助方的考评（如有）。

4. 积极参加资助方提供的实习实践等活动，把握机会，提升自我。

5. 按时按通知按要求提交上述材料。
