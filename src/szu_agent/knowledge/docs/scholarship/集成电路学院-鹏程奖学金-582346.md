# 集成电路学院2025-2026学年研究生国家奖学金、比亚迪奖学金、鹏程奖学金及优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部评选工作有关事宜通知如下：
一、研究生国家奖学金（一）评选对象攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生，延期毕业的研究生除外。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
（二）奖励标准博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
（三）参评条件申请研究生国家奖学金的学生应当符合学校规定的基本参评条件：
热爱社会主义祖国，拥护中国共产党领导；
遵守国家法律法规，遵守学校规章制度；
践行社会主义核心价值观，道德品质优秀；
学习成绩优异，科研能力显著，发展潜力突出。
同时，参评学生须符合学校关于研究生国家奖学金评选的其他相关要求。
（四）评选原则学院研究生国家奖学金评审工作坚持公开、公平、公正、择优的原则，由学院研究生奖学金评审委员会综合考虑参评学生的科研能力、科研成果、学业成绩、综合素质及其他突出贡献等情况进行评议。
学院不另行设置量化评分标准，不以单一科研成果、成绩排名或获奖数量作为确定推荐人选的唯一依据，由学院评审委员会根据学生提交的完整材料进行综合评议，并通过无记名投票方式确定学院拟推荐人选。
参评学生提交的科研成果、奖励等材料须符合学校相关认定要求。同一科研成果、奖励等不得重复使用；已用于往年国家奖学金评审的成果，不得再次用于国家奖学金申报。
有关学术论文、科研成果等须按照学校要求进行认定，深圳大学须为第一完成单位（新生除外）。
二、研究生社会奖学金——比亚迪奖学金（一）名额及奖励标准学院比亚迪奖学金名额：
· 硕士研究生：1人。
奖励标准为每生每年20000元。
具体名额以学校最终下达的名额分配方案为准。
（二）评选对象根据相关捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二年级及以上硕士、博士研究生。
申请人须在标准学制内，延期毕业研究生不参加评选。
（三）参评条件申请比亚迪奖学金的学生须符合学校规定的相关条件：
坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想；
热爱祖国，热爱人民，拥护中国共产党领导，积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神；
遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为；
具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动；
德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀，成绩排名须位于前30%；
在符合上述条件的基础上，还须至少满足以下条件之一： （1）以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文； （2）以前两顺位发明人申请国家发明专利； （3）在国际/国家级重大学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉； （4）曾在重大科研项目中担任主要完成人。
（四）评选办法学院严格按照学校规定的参评条件开展比亚迪奖学金评选，不另行设置量化评分标准。
在符合学校规定的参评资格和条件的基础上，由学院研究生奖学金评审委员会综合考虑学生的学业表现、科研能力、科研成果、综合素质及其他突出表现等情况进行评议，并通过无记名投票方式确定学院拟推荐人选。
三、研究生社会奖学金-鹏程奖学金（一）名额及奖励标准研究生（不分硕博）1人，每生每年10000元。
（二）评选对象在校全日制研究生（延期毕业的硕士研究生除外）。

2.刻苦学习、成绩优异，在全班或全年级名列前茅；
3.具有较强的科研能力，有公开发表科研成果，具体科研条件参考国家奖学金。

（二）奖励标准及名额优秀研究生干部奖励标准为每生每年2000元，并颁发相应荣誉证书。

具体名额以学校下达的名额分配方案为准。

热爱社会主义祖国，拥护中国共产党领导；
遵守国家法律法规和校规校纪；
践行社会主义核心价值观，道德品质优秀；
学习态度端正，所有必修课程全部通过；
参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
任职期间有突出工作表现，能够提供典型材料及例证。
（四）评选办法优秀研究生干部评选重点考察参评学生的履职情况、工作成效、服务意识、组织协调能力、示范带动作用及综合表现。
学院将组织符合条件的参评学生进行现场答辩。参评学生可提前准备答辩PPT，具体答辩时间、地点及相关要求由学院另行通知。

六、申报及评选程序（一）个人申报9月14日—9月17日，所有符合参评条件并有意愿申请相关奖项的研究生，登录深圳大学网上办事服务大厅，进入“奖学金申请”模块，按照要求在线填写相关奖学金申请审批表。
国家奖学金申请人还需按照学校要求填写并上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》。
申报各类奖项时，相关佐证材料须按照学校及学院要求上传至系统，并按学院要求提交相关纸质材料或其他申报材料。
（二）学院资格审查及材料审核9月18日—9月30日，学院对学生申报材料进行资格审查和材料审核。
学院将重点审核：
学生是否符合学校规定的参评对象及基本条件；
学生课程学习情况是否符合要求；
学术论文、专利、竞赛、科研项目等成果材料是否真实、有效；
科研成果及奖励是否符合学校认定要求；
同一成果、奖励是否存在重复使用情况；
申报材料是否完整、规范。
对于不符合参评条件或材料不完整、无法提供有效证明材料的申请，学院将按照有关规定处理。
（三）学院评审国家奖学金、比亚迪奖学金由学院研究生奖学金评审委员会根据学生申报材料，综合考虑科研能力、科研成果、学业成绩、综合素质及其他突出贡献等情况进行评议，并通过无记名投票方式确定学院拟推荐人选。
学院不另行设置量化评分标准，不以单项成果或单一指标直接确定最终推荐结果。
优秀研究生干部在材料审核基础上组织现场答辩，由参评学生介绍任职情况、工作成绩、典型事例及个人表现等，学院评审委员会结合申报材料及现场答辩情况进行综合评议，并通过无记名投票方式确定拟推荐人选。
（四）学院公示学院确定拟推荐名单后，按照学校要求进行公示，公示期不少于规定时间。
公示期间，对评审结果有异议的学生，可向学院研究生奖学金评审委员会提出申诉。学院将按照有关规定及时研究并予以答复。
（五）学校复核学院完成初步评审、公示及相关材料提交后，由学校学生部对各学院推荐名单进行复核，并按照学校统一安排进行校级公示。

## 附件：集成电路学院优秀学生干部评选办法

集成电路学院优秀学生干部

评选办法（征求意见稿）

第一条  为充分发挥优秀学生干部的模范、带头、桥梁和纽带作用，激发我院学生干部的工作积极性和主动性，根据《深圳大学优秀研究生、优秀研究生干部评选办法》的有关要求，结合学院工作实际，制定本细则。

第二条  评选对象及名额

我院优秀学生干部评选对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。包括校、院级研究生会干部、学校社团组织负责人、学生党支部干部、班级班委会干部等。评选名额参考当年学校下发的校级优秀学生干部名额。

直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。

第三条  参评条件

（一）热爱祖国，拥护四项基本原则，坚持正确的政治方向，思想积极上进；

（二）自觉遵守国家法律、法规和校纪校规，遵守大学生行为准则，品行端正，在校期间无任何违纪处分；

（三）任职期间有突出工作表现，能提供典型材料及例证；

（四）积极参加校、院级志愿服务活动；

（五）担任学生干部累计满一年，或在公益组织中服务满一年及以上；

（六）工作认真负责，成绩显著，在学生中有较高的威信，起模范带头作用；

（七）学习态度端正，所修课程需全部通过；

第四条  评选方法

个人申报及资格审核

以本人在公文通学院通知的规定时间内自愿申报为准，不申

报者视为自动放弃评奖资格。

评选环节

学院优秀研究生干部评选以百分制计分，按分数高低进行名次排序确定获奖人选，对得分相同的情况，按照民主评议中得分高低决定排名先后，具体评分标准如下：

民主评议打分（30分）

参选同学需提交学生干部分管学生名单（如研会干事需提交2024-2025年度全体研会成员名单，党支部干部需提交2024-2025年度所属党支部党员名单）。经学院审核确认名单后，统一制作无记名投票工具进行民主评议打分，以优秀、良好、合格、不合格档次确定成绩。90分以上为优秀，89至80分为良好，79至70分为合格，不满70分为不合格。参与打分的同学超过2/3核准为有效分数，民主评议打分不合格则无法参与后续优秀学生干部现场述职环节。此部分得分将统一加权归一化至最终分数折合最高30分计。

综合素质打分（70分）

学院评审委员会经审核个人申报材料后，将组织参选学生现场答辩（需自行准备PPT），并由评审委员会的各位老师现场依据学生干部的政治素质、履职能力、工作成效及现场表现四部分综合打分。此部分得分将统一加权归一化至最终分数折合最高70分计。

最终以民主评议分数与综合素质打分合计分数排名，按分数高低进行名次排序确定获奖人选。

评审结果经学院公示三天，如无异议，奖评审结果报送党委学生工作部审核后报学校审定。

第五条  奖励办法

优秀研究生干部奖励标准为每生每年4000元，并颁发证书。

第六条  本评选办法自公示期后起执行。由学院研究生奖学金评审委员会负责解释。
