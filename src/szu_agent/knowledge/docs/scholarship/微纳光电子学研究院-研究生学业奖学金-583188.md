# 微纳光电子学研究院2026年研究生学业奖学金评审细则（更新）

根据《研究生学业奖学金管理暂行办法（修订）》和学校会议有关精神，结合我院实际情况，特制定微纳光电子学研究院2026年研究生学业奖学金评审细则。
一、研究生学业奖学金评审工作安排
（一）参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
（二）参评条件
1.热爱社会主义祖国，拥护中国共产党的领导；
2.遵守国家法律法规，遵守学校学院规章制度；
3.诚实守信，品学兼优；
4.所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
5.积极参与科学研究和社会实践。
（三）研究生学业奖学金总体标准及比例
1.硕士研究生学业奖学金实行按年评审，第一年为新生奖学金，第二、三年为学业奖学金。
（1）2026级参评新生奖学金：分为特等、一等和二等三个等级。特等奖奖励标准为每生每年15000元，所有推免生、一流大学建设高校（附件1）应届毕业第一志愿考生及本科期间专业排名前20%的本校应届毕业生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生及本科期间专业排名前20%的本校应届调剂毕业生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生不超过20%获评一等，不超过40%获评二等。
（2）2025级、2024级参评学业奖学金：分为一等、二等两个等级。综合考虑思想品德、学业成绩、学术成果和社会实践等因素展开评定。获评一等奖学金的比例不超过当年可参评硕士研究生总人数的20%，奖励标准为每生每年10000元；获评二等奖学金的比例不超过当年可参评硕士研究生总人数的40%，奖励标准为每生每年5000元。只在标准学制内享受。
经过与学生部指标核算，我院本年度一等、二等奖学金名额如下：
老生：
一等奖名额34人，二等奖名额67人
新生：
一等奖名额15人，新生二等奖名额29人
2.博士研究生学业奖学金奖励标准为每生每年20000元，在标准学制年限内享受；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
3.其他
（1）对于新生奖学金，除被认定为特等奖和一等奖硕士研究生外，其他新生学院原则上依据《深圳大学研究生学业奖学金管理暂行办法（修订）》进行评选。
（2）对于2025级学业奖学金，将根据学生个人的学业成绩，科研成果综合计算得分认定。学业成绩中要求所修课程全部通过，以学位课（必修课）平均成绩为准，科研成果根据具体情况给予加分，并完成相应的实践要求。（详见附件2）
（3）对于2024级学业奖学金，根据研究生的科研成果、培养潜力、学习成绩综合评定，并完成相应的实践要求。
（4）关于科研成果的备注说明：
1）科研成果以正式取得为准，其中论文应已正式刊（24级硕士研究生放宽至论文接收状态）出并能提供检索证明，有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见（附件3），图书馆咨询电话26537700转808,专利应已取得专利证书。大赛需要提供获奖证书，获奖同学自行商议竞赛贡献量，在证书复印件上写明，且后一排名作者的贡献理论上不高于前一排名作者，并由该证书的所有获奖者以及指导教师签字确认。
2）“学术论文”的申请人应为独立作者、第一作者或通讯作者，通讯作者应在论文中明确标识。若为第二作者，第一作者必须是其学籍系统导师。以共同第一作者或共同通讯作者发表的论文，按照共同贡献人数平均计算。
3)全国中文核心期刊目录参考北京大学图书馆最新版《中文核心期刊目录》。SCI检索论文的分区及影响因子以中科院分区（2025年）及JCR最新一期为主要参考。
4)科研成果是指申请人入学以来至2026年9月1日期间所取得的成果.如此次参评的科研成果在以往学院组织评选的国家奖学金、社会奖学金、学业奖学金评奖中已使用过，则不予计入。否则，一经发现，取消评奖资格。根据学校规定，评审会评审时综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素，优先推荐科研表现突出的参评学生。
5）毕业班研究生，学院可根据实际情况适当放宽。以研究生办事大厅网上申请学业奖学金的截止日期9月30日23：00为科研成果认定时间的截止日期，如果是论文，则以收到正式录用通知（需系统导师签字确认真实有效）为准。
（四）评审日程
1.9月16日：学生部公布研究生学业奖学金评选工作通知，下达获奖名额（附件4）。其中2026级硕士研究生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定（附件5）；余下参评的一、二等奖学金由各学院根据学院细则按名额评定。
2．9月17日—9月22日：各学院成立研究生学业奖学金评审委员会，在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。学院（部）评审委员会名单（附件6）及评选细则需在学校公文通上予以公布，设置明确的公示期，公示无异议，9月22日前将评审委员会名单、评选细则可编辑的电子版及经签字盖章后的PDF扫描版通过“一网通办”平台报送学生部备案，文件以“XX学院（部）学业奖学金评选细则”命名。
3.9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.webvpn.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表，提交后打印，本人签名，按学院要求将所需材料及时送交所在院评审委员会联络人。（学业奖学金申请系统开放时间为：9月23日8:00—9月30日23:00）
为给申请奖学金的同学提供便利，学业奖学金系统已接入“深圳大学学术门户”成果数据，请有意申请学业奖学金的同学先登录“深圳大学学术门户”（https://www.lib.szu.edu.cn/ir）进行研究生论文、专利成果认领，详细操作方法请参阅公文通《关于推动研究生论文、专利成果数据认领工作的提醒》（https://www1.szu.edu.cn/board/view.asp?id=557353）。
申请人在学业奖学金系统申请时可直接勾选并引用已通过导师审核的“学术门户”数据，无需额外提供佐证材料；如导师尚未审核或“学术门户”尚未收录相关成果，申请人也可在学业奖学金系统申请时自行添加并上传佐证材料。
4.10月8日—10月21日：各院（部）组织评审会，对申请研究生学业奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“学业奖学金管理”系统中完成线上审核。公示无异议后，将以下材料可编辑的电子版和经学院和党委领导签字盖章后的PDF扫描版通过“一网通办”平台报送学生部，文件以“XX学院（部）学业奖学金推荐名单”命名：
1)《XX学院（部）2026年研究生学业奖学金评选情况总结》（附件7）
2)《学业奖学金推荐名单》（系统审核通过后可导出）（附件8）
备注：推荐名单请按2026级特等、一等、二等，2025级一等、二等，2024级一等、二等的顺序填写，每个年级等级请单独排序。
5.10月21日后：学生部审核、公示获奖名单。
6.校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
二、有关说明及注意事项
（一）参评研究生学业奖学金所涉及的科研成果、奖励等认定截止时间为2026年9月1日，针对毕业班研究生，我院适当放宽。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。学科竞赛目录详见附件9。
（三）硕士研究生（包括特等和一等认定的研究生）学制内博士及延毕博士均需网上申报，并提交个人申报材料。个人申报材料包括：《研究生学业奖学金申请审批表》、成绩单以及相关证明材料。
（四）对认定或评审结果有异议的学生，可在我院公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假的行为。
（六）获得学业奖学金奖励的研究生,可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策以及校内其他研究生奖助政策资助，但是科研成果不可重复使用。
三、其他
1.研究生对学业奖学金评定结果持有异议，请于公示期内，以书面方式（面谈提交或邮件提交均可）向学院评审委员会（沧海校区致腾楼918室）反映。反映情况时要签署真实姓名，要有具体事实；不签署真实姓名或不提供具体事实情况的，一律不予受理。

## 附件：微纳光电子学研究院研究生学业奖学金补充细则

微纳光电子学研究院2026年研究生学业奖学金补充细则

-仅适用2025级硕士研究生（研二）科研成果加分

为表示对于在研究生第一年学年阶段即取得科研成果的研究生的鼓励，特拟定此科研成果加分原则，以作为微纳光电子学研究院研究生2026年学业奖学金的补充细则。

加分标准：发表文章（以第一作者）：SCI：40分；EI：30分；中文核心期刊：20分；其他期刊和会议学术论文：10分；

专利（以第一作者）：发明授权：30分，实用新型：10分；

大赛奖：国家级一等：30分，二等：20分，三等：15分；

省部级一等：15分，二等：10分，三等：6分。

注：1、美国大学生数学建模大赛按国家二等奖；

2、大学生创新创业训练项目国家级按国家三等奖；

3、各类奖项中入围奖、优秀奖、优胜奖、竞赛奖等均不计入；

4、所符合参评奖大赛项见附件12.

5、所获奖项需本人和团队成员写清楚贡献量说明，并需团队成员和指导教师签字，模板自拟。

说明：2025级研究生学业奖学金最终将根据学生个人的学业成绩、科研成果综合计算得分认定，计算时的比例为7:3，实行统一加分原则。加分按照贡献量百分比换算。

本细则由微纳光电子学研究院研究生学业奖学金评审委员会负责解释。
