# 金融科技学院2025-2026学年度本科生奖学金及先进班集体评选细则

为鼓励学生刻苦学习、积极创新、全面发展，同时更好地发挥奖学金的激励和导向作用，切实推动我院院风、学风建设，具体落实学校奖学金评选相关工作要求，我院将开展2025-2026学年度本科生奖学金和先进班集体评选工作。根据《深圳大学本科生国家奖学金评审办法》《深圳大学本科生奖学金评定办法（修订）》《深圳大学学生特殊贡献奖认定办法》《深圳大学先进班集体评选办法》以及各类社会奖学金设置协议，现就我院2025－2026学年度本科生奖学金及先进班集体评选工作通知如下：
一、奖学金基本情况
（一） 国家奖学金：全院3人，10000元/人
国家励志奖学金评选通知将于困难认定工作结束后另行发布。
（二） 社会奖学金（鹏程奖学金）：全院3人，10000元/人
（三） 学校奖学金
1. 单项先进个人奖
（1）学业类：“学习之星”、“双创之星”；
（2）特长类：“文体之星”；
（3）公共服务类：“公益之星”、“优秀学生干部”；
奖学金金额：一等3000元/人；二等2000元/人；三等1000元/人。
学院奖学金获奖名额：
“学习之星”：一等9人，二等27人，三等54人。
“优秀学生干部”获奖比例：一等5人，二等14人，三等18人。
“公益之星”：一等9人，二等18人，三等27人。
“文体之星”：一二等共计27人，三等18人。
“双创之星”：一二三等共计91人。
（4）特殊贡献奖。
2. 综合先进个人奖
（1）“荔园之星”；
（2）“荔园卓越之星”、 “荔园卓越之星”提名奖。
奖学金金额：“荔园之星” 10000元/人，“荔园卓越之星”提名奖30000元/人，“荔园卓越之星”50000元/人。
奖学金获奖名额：“荔园之星”获奖名额根据参评人数，结合学校年度预算安排，具体通知将另行发布；“荔园卓越之星”获奖名额全校不超十名，“荔园卓越之星”提名奖获奖名额全校不超十名（“荔园之星”及“荔园卓越之星”的评选时间另行通知）。
（四） 先进班集体：全院5个，由学校发给奖状并按每人30元的标准发给活动经费。
二、评定工作原则
（一）将本学年度国家奖学金、学校奖学金、社会奖学金纳入统一的奖学金评选体系，统筹规划、同步评选；2026年应届本科毕业生奖学金评选工作也将同步进行。
（二）申报各类奖学金，均需满足相应奖学金文件中规定的评选资格条件。
（三）学校奖学金按照《深圳大学本科生奖学金评定办法（修订）》，荣誉可兼得，奖学金以最高一项计发。
（四）学生参评学校先进个人奖项，不影响参评国家奖学金或校外单位所设的奖项及奖金（设奖单位另有要求除外）。
（五）国家奖学金与国家励志奖学金不可兼得。
（六）以勤工助学岗位工作身份参与学生工作的原则上不可作为学生干部参加“优秀学生干部”奖学金评选。
（七）学院申报提交后，一旦发现评选条件不符者即取消其资格，名额自动作废。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
三、奖学金申请条件的义工时认定
（一）请学生于9月13日23：59前在网上办事大厅（http://ehall.szu.edu.cn/new/index.html）【奖学金】模块的【评选条件申请】处查看义工时数据，系统已匹配“志愿深圳”义工时长。若时长不足28小时，可在系统补充填报“i志愿”义工时，请及时完成。请注意必须填报2025年9月1日-2026年8月31日期间的义工时，且务必剔除数据来源为“志愿深圳”的部分，避免重复计算。请提供截图或导出的PDF文件作为证明，并秉持诚信原则，确保信息真实有效。如有弄虚作假者，一律取消当年奖学金评选资格，并按学校有关规定严肃处理。
（二）9月14日前，学院辅导员在网上办事大厅（http://ehall.szu.edu.cn/new/index.html）【奖学金】模块的【评选条件审核】处审核完成学生填报的i志愿义工时。
四、国家奖学金评定工作安排
（一）9月11日-15日，开放国家奖学金网上申报系统申请功能，学生登录网上办事大厅（http://ehall.szu.edu.cn/new/index.html），在线填写申请信息，上传学年成绩单、竞赛证书、专利证书、论文、义工时等完整佐证材料后，提交申请。于9月15日17：00前提交电子版至邮箱zhengyq@szu.edu.cn，并提交纸质材料至汇星楼一楼学工办郑老师处。
（二）9月22日17:00前，学院完成初评。
（三）9月29日17:00前，学院完成推荐候选人名单公示（公示期为3个工作日）。
五、社会奖学金评定工作
（一）9月15日-20日，开放社会奖学金（鹏程奖学金）网上申报系统申请功能，学生登录网上办事大厅：http://ehall.szu.edu.cn/new/index.html，在线提交申请表，并附相关证明材料。
（二）10月14日17:00前，学院完成社会奖学金初评及公示工作。
六、学校奖学金评定工作安排
（一） 9月15日-20日，开放校级奖学金网上申报系统申请功能，学生登录网上办事大厅（http://ehall.szu.edu.cn/new/index.html），在线提交申请表。
（二）10月9日17:00前，学院辅导员进入系统完成审批工作。
（三）10月14日前，学院公示初评获奖名单（含独立指标“优秀学生干部”）（公示期为3个工作日），并完成系统审核。
附加说明：
（一）请申请“双创之星”的同学注意，如论文是共同一作，请申请“双创之星”（团体）。
（二）以学术论文参评“双创之星”可不上传图书馆出具的收录证明，参评学生需在9月18日前将《学术论文信息汇总表》（表格见附件）发至（个人邮箱已省略，见原通知），由学院统一汇总信息后再由图书馆统一审核收录情况（逾期未交请自行前往图书馆检索）。
七、先进班集体评定工作
（一）9月15日-20日，学生班集体网上填写先进班集体申请表，并附有关证明材料，纸质版提交至汇星楼一楼学工办郑老师处。
（二）10月14日17:00前，学院完成先进班集体初评结果公示（公示期为3个工作日）。
八、评选标准
（一）国家奖学金
国家奖学金采用申请答辩制（答辩时间另行通知），评选依据学校国家奖学金评定办法执行。
（二）社会奖学金
社会奖学金采用申请答辩制（答辩时间另行通知），评选依据学校社会奖学金评定办法执行。目前暂缓。
（三）学习之星
1. 学习之星奖学金的评选以参评学生评选学年度学业成绩为依据进行，评选一、二、三等奖学金。
2. 名额分配：学院以专业为单位进行分配，综合考虑班级人数比例与违纪处分情况分配名额。
（四）优秀学生干部
学院优秀学生干部奖学金参评对象包含学院本科生团委、学生会、学院党建办等学生组织任职干部，以及学院本科班级班委。
（五）先进班集体
1. 先进班集体评选依据学校相关规定执行。
2. 学院奖学金评选小组组织先进班集体风采展示评选活动，综合评审确定先进班集体名单。
九、注意事项
（一）本细则公示期自2026年9月14日至2026年9月16日。公示期内如对本细则存在异议，可实名反馈给学工办郑老师，办公电话：0755-26531424，办公邮箱：zhengyq@szu.edu.cn，办公地址：汇星楼一楼学工办，逾期学院将不受理。
（二）为保证公平、公正、公开原则，请同学们依照相关时间及要求提交申请和材料，逾期学院将不受理。
（三）本细则未尽事宜，由金融科技学院奖学金评选小组另行适时通知和解释。
