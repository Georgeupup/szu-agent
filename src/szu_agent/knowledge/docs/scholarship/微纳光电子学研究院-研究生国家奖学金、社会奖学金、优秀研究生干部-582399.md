# 微纳光电子学研究院2025-2026学年研究生国家奖学金、社会奖学金、优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我院2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金和社会奖学金的评选工作有关事宜通知如下：
一、奖学金类型：
壹·研究生国家奖学金
（一）评选对象：
深圳大学微纳光电子学研究院攻读硕士、博士学位的具有中华人民共和国国籍全日制研究生。（延期毕业的研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
（二）奖励标准：
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年3万元；硕士研究生国家奖学金奖励标准为每生每年2万元。
（三）名额分配：
根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1）进行名额分配。博士、硕士均以学院为单位分配名额，物理与光电工程学院（含微纳光电子学研究院）实行定额评审，具体名额如下：
博士研究生：7人
硕士研究生：31人
（四）参评条件：
（1）热爱社会主义祖国，拥护中国共产党的领导；
（2）遵守宪法和法律，遵守学校规章制度；
（3）践行社会主义核心价值观，道德品质优秀；
（4）学习成绩优异，科研能力显著，发展潜力突出；
贰·研究生社会奖学金
比亚迪奖学金
（一）评选对象
根据捐赠协议，奖励在特定学院全日制在读的德智体美劳全面发展、品学兼优的二年级及以上硕士博士研究生，只在标准学制内参评。
（二）奖励标准
每生每年20000元。
（三）奖励名额
根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），物理与光电工程学院（含微纳光电子学研究院）博士研究生比亚迪奖学金1个名额、硕士研究生比亚迪奖学金3个名额。
（四）评选标准
1.坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。
2.热爱祖国，热爱人民，拥护中国共产党的领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。
3.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。
4.具有乐观向上的人生态度，尊敬师长，热爱集体，积极参加校园文化活动。
5.德智体美劳全面发展，能够激励和带动身边同学敦品励学，综合素质突出，学业成绩优秀（成绩排名前30%）。
6.在符合上述条件前提下，还应至少满足下列条件之一：
（1）以第一作者（或导师第一、本人第二）在本学科（或本领域）有较大影响的学术期刊上发表论文；
（2）以前两顺位发明人申请国家发明专利；
（3）在国际/国家级重大的学术科研、创新实践等竞赛性活动中取得二等奖及以上荣誉；
（4）曾在重大科研项目中担任主要完成人。
鹏程奖学金
（一）评选对象
在校全日制研究生（延期毕业的硕士研究生除外）。
（二）奖励标准
研究生一次性奖励10000元。
（三）奖励名额
根据《深圳大学2025-2026学年研究生鹏程奖学金名额分配表》（附件2），物理与光电工程学院（含微纳光电子学研究院）研究生鹏程奖学金1个名额。
（四）评选条件
1.热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为。
2.刻苦学习、成绩优异，在全班或全年级名列前茅。
3.具有较强的科研能力，有公开发表科研成果。
叁·优秀研究生干部
（一）参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
直博生和招生简章中注明不授予中间学位的本硕博、硕博连读学生，根据其学籍注册阶段确定身份参与优秀研究生干部的评定。在硕士研究生学籍注册阶段按照硕士研究生身份参与评定，在博士研究生学籍注册阶段按照博士研究生身份参与评定。
（二）奖励标准
每生每年2000元。
（三）奖励名额
2026年优秀研究生干部不分硕博，根据在校老生人数、年度预算等因素分配名额，以学生学籍所在学院为单位组织评审，物理与光电工程学院（含微纳光电子学研究院）共32名。详见附件1《深圳大学2025-2026学年研究生奖学金名额分配表》。
（四）参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。
二、评选细则：
1.国家奖学金评选细则：
硕士研究生：
（1）申请人须在校学习满一年，在校期间无处分记录；学业成绩优异、科研成果突出，积极参加专业实习和社会实践活动，并完成我院相应的实践要求。
（2）国奖奖学金申请人所修课程须全部通过，必修课（学位课）平均成绩为80分以上，以研究生院系统学位课（必修课）成绩为准。
（3）学术型研究生申请人须以第一作者或第二作者（导师为第一作者）在本专业期刊上公开发表学术论文至少1篇，已接收未公开发表的不计入。
（4）专业型研究生申请人需参加实践类课题，并取得一定成果，须以第一发明人或第二发明人（导师为第一发明人）取得授权发明专利至少1项，或者以第一作者或第二作者（导师为第一作者）在本专业期刊上公开发表学术论文至少1篇。
（5）申请人有其他突出表现，如获得国家级奖项等，可在满足以上条件的情况下优先考虑。
博士研究生：
（1）申请人应为我院全日制注册在读博士研究生，品行端正，具有扎实的基础理论和专业知识，严谨的治学态度，良好的科学道德和创新精神，科研能力突出。
（2）申请人需已在高水平学术刊物上发表创新性研究成果。要求博士生已在SCI收录刊物上以第一作者（如本人为第二作者，第一作者需为其导师）发表论文。
（3）申请人有其他突出表现，如获得国家级奖项等，可在满足以上条件的情况下优先考虑。
2.社会奖学金评选细则：
具有强烈的学习创新意识，研究能力显著、学术成果突出，并至少具备以下条件之一：
a、在重大学科竞赛中获奖，同等条件下，按竞赛规格，获奖等级排序；
b、在国内外权威学术刊物上发表具有较高学术价值的学术论文。同等条件下按论文数量、刊物等级、影响因子大小从高到低排序；
c、科研课题或创新项目取得突出成绩，能提供相关证明材料；
d、其他学术科研创新成果，能提供相关证明材料。
三、评选程序
（一）9月11日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月11日—9月16日：研究院成立研究生奖学金评审委员会（以下简称院评审委员会），由研究院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，院评审委员会负责制定本院评选细则。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。院评审委员会名单（附件3）及评选细则需在学校公文通上予以公示。公示无异议，9月16日前将评选细则及评审委员会名单电子版（可编辑Word文件及签字盖章后PDF扫描件）通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（三）9月14日—9月17日：所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4）至系统，打印申请材料，学生本人签名，附相关成果复印件，经导师（推荐人）签字，送交所在院评审委员会联络人。申报各类奖项时，相关佐证材料均需上传至系统附件。
（四）9月18日—9月30日：研究院组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。
公示无异议，9月30日前将以下材料电子版通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交：
1.学院（部）2025-2026学年度研究生奖学金评选情况总结（附件6）的可编辑Word文件及签字盖章后PDF扫描件；
2.学院推荐名单汇总表（附件4、5）的可编辑Excel文件及签字盖章后PDF扫描件；
3.国家奖学金推荐学生个人申请审批表的签字盖章后PDF扫描件；
4.比亚迪奖学金推荐学生的成绩前30%盖章证明及符合参评条件的成果证明。（比亚迪奖学金推荐学生的个人申请审批表需提交签字盖章后的纸质文件到汇昀楼305室/丽湖校区综合服务大厅22号窗口。）
（五）10月8日－10月14日：学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在学院公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
四、关于科研成果的备注说明：
1.科研成果以正式取得为准，其中论文应已正式刊出并能提供检索证明，有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传；专利应已取得专利证书。检索指引见附件7，图书馆咨询电话26537002。
2.“学术论文”，申请人应为独立作者、第一作者；若为第二作者，第一作者必须是其研究生学籍系统导师。以共同第一作者或共同通讯作者发表的论文，按照论文贡献量计算。
3.SCI检索论文的影响因子以JCR最新一期为主要参考；分区以中科院分区（2025年）为主要参考。
4.科研成果是指申请人入学以来至2026年9月17日23:00期间所取得的成果（若科研成果在此前学院进行初步评审并获奖的国家奖学金、社会奖学金、学业奖学金的评奖中已使用过，则不能再用于参评本次评审。否则，一经发现，取消评奖资格）。根据学校规定，评审会评审时综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素，推荐综合表现突出的参评学生。
5.对于研究生院所列出的高水平研究生学科竞赛，获奖同学自行商议竞赛贡献量，在证书复印件上写明，且后一排名作者的贡献理论上不高于前一排名作者，并由该证书的所有获奖者以及指导教师签字确认。
五、其他注意事项：
1.我院研究生国家奖学金的评审工作，坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。
2.本办法未尽事宜，参照《关于开展2025-2026学年度研究生奖学金评选工作的通知》，并由我院奖学金评审委员会负责解释。
