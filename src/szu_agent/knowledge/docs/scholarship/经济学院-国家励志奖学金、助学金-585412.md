# 经济学院2026年本科生国家励志奖学金评选细则

根据《学生资助资金管理办法》《深圳大学本科生国家励志奖学金评审办法》，结合我院实际情况，现开展院校2026年国家励志奖学金评定工作，具体通知如下：
一、经济学院2026-2027学年度本科生国家励志奖学金评审委员会名单
组 长：张颖、张建华
组 员：高志威、毛成、李沛燊、罗胡阳、侯泽琦、王自强、王哲涵、蔡莹莹、曾蓓蕾、林仪等学生代表大会常务委员会成员
二、申请条件
1.通过2026-2027学年度家庭经济困难认定的全日制在校二年级及以上本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在年级前50%（以2025-2026学年成绩单为准）。
三、评定原则
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年奖、助评选资格，并按学校有关规定进行严肃查处。
四、名额分配
按照学校分配名额，我院本学年共有43个名额。
五、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请。助学金申请系统于10月19日开通，10月22日上午9:00关闭，逾期不予申请。
2.10月21日前，学院国家励志奖学金评审委员会公示本学院国家励志奖学金评选细则。
3.学院在评选过程中应坚持公平、公正、公开的原则，按照本学院评定细则，严格审查申请学生资格，确定拟获奖名单。学院于11月3日前完成国家励志奖学金的网上审核及公示（3个工作日）。
4.学生部将于11月4日起对学院上报的材料进行审核并对审核后的名单进行公示（公示期为5个工作日）。
