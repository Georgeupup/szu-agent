# 电子与信息工程学院2026年本科生国家励志奖学金评选细则

根据《学生资助资金管理办法》《深圳大学本科生国家励志奖学金评审办法》，结合我院实际情况，现开展我院2026年国家励志奖学金评定工作，具体通知如下：
一、申请条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%；
二、评定原则
1.同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。
三、名额分配
按照学校分配名额，我院共有64个名额。
四、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，须上传成绩单。助学金申请系统于10月19日开通，10月22日上午9:00关闭，逾期不予申请。
2.学院在评选过程中将坚持公平、公正、公开的原则，按照学院评定细则，严格审查申请学生资格，确定拟获奖名单，并于规定时间内完成国家励志奖学金的网上审核及公示。
