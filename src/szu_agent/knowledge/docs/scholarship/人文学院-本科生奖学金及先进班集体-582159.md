# 人文学院2025-2026学年度本科生奖学金及先进班集体评选细则

为落实学校学生部《关于开展2025-2026学年度本科生奖学金及先进班集体评选活动的通知》要求，现就人文学院2025-2026学年度本科生奖学金及先进班集体评选工作通知如下：
一、参评基本资格
（一）热爱社会主义中国，拥护中国共产党的领导；
（二）遵守宪法和法律，遵守学校的规章制度，品行优良；
（三）我院二年级以上（含）且所参评年度内学籍在我院的在校学习全日制普通本科生（延期毕业的本科生除外）；
（四）遵守校规校纪，所评选学年度和评选期间没有受到学校行政、党、团处分；
（五）各类奖学金都要求所评选学年度内所有课程及格（特殊贡献类除外）；
（六）原则上所评选学年度体测成绩及格及以上；
（七）所评选学年度义工时28小时及以上；
（八）所评选学年度思政学时达标。
二、奖学金构成
（一）国家奖学金
人文学院名额4人，10000元/人。
国家励志奖学金评选通知将于困难认定工作结束后另行发布。
（二）社会奖学金
鹏程奖学金：人文学院名额4人，10000元/人。
（三）学校奖学金
1.单项先进个人奖
（1）学业类：“学习之星”“双创之星”；
（2）特长类：“文体之星”；
（3）公共服务类：“公益之星”“优秀学生干部”。
奖学金金额：一等3000元/人；二等2000元/人；三等1000元/人。
获奖比例：
“学习之星”获奖比例：一等1%，二等3%，三等6%。
“优秀学生干部”获奖比例：一等0.5%，二等1.5%，三等2%。
“公益之星”获奖比例：一等1%，二等2%，三等3%。
“双创之星”一二三等奖总获奖比例不超过本学院（部）参评学生总人数的10%。
“文体之星”一二三等奖总获奖比例不超过本学院（部）参评学生总人数的5%，其中三等奖获奖比例不超过本学院（部）参加评选学生总人数的2%。
（4）特殊贡献奖（学生无需申请，学校直接认定）。
2.综合先进个人奖
（1）“荔园之星”：10000元/人；
（2）“荔园卓越之星”提名奖：30000元/人；
（3）“荔园卓越之星”：50000元/人。
奖学金获奖名额：
“荔园之星”获奖名额根据参评人数，结合学校年度预算安排，核定至学院；
“荔园卓越之星”获奖名额不超十名；
“荔园卓越之星”提名奖获奖名额十名。
（四）先进班集体
班级名额：9个；
奖学金金额：班级全体成员30元/人。
三、评定工作原则
（一）将本学年度国家奖学金、学校奖学金、社会奖学金纳入统一的奖学金评选体系，统筹规划、同步评选；2026年应届本科毕业生奖学金评选工作也将同步进行。
（二）申报各类奖学金，均需满足相应奖学金文件中规定的评选资格条件。
（三）学校奖学金按照《深圳大学本科生先进个人评选及奖学金评定办法（修订）》，荣誉可兼得，奖学金以最高一项计发。
（四）学生参评学校先进个人奖项，不影响参评国家奖学金或校外单位所设的奖项及奖金（设奖单位另有要求除外）。
（五）国家奖学金与国家励志奖学金不可兼得。
（六）以勤工助学岗位工作身份参与学生工作的不可作为学生干部参加“优秀学生干部”奖学金评选。
（七）学院申报后，一旦发现与条件不符者即刻取消其评选资格，名额自动作废。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
四、国家奖学金工作安排
根据学校学生部《关于开展2025-2026学年度本科生奖学金及先进班集体评选活动的通知》文件精神，今年我院国家奖学金名额4个。为保证国家奖学金评定工作的顺利进行，安排如下：
（一）评定要求
为进一步规范国家奖学金评审和材料填报工作，各学院须严格执行《教育部 财政部关于印发〈本专科生国家奖学金评审办法〉的通知》（教财函〔2019〕105号）和《深圳大学本科生国家奖学金评审办法》的要求，按照学校下达的推荐候选人名额（见附件1），推荐学习成绩优异，社会实践、创新能力、综合素质等方面特别突出的候选人。
（二）评定流程
1.9月11日至15日，学校开放国家奖学金网上申报系统申请功能，学生登录网上办事大厅奖学金板块，在线提交申请表；
2.9月15日17:00前，请申请同学将所有在奖学金申请系统提交申请材料的纸质版提交至汇文楼办公区1116杨老师处，届时组织申请同学进群核对材料。
3.9月28日17:00前，学院完成初评及推荐候选人名单公示工作。
（三）材料要求
1.系统打印奖学金申请表；
2.25-26学年成绩单；
3.比赛获奖证书（政府部门或校内举办相关比赛）；
4.社会实践经历证明材料（志愿服务或其他相关证明材料）；
5.学生干部证明材料；
6.学术经历证明材料；
7.文体经历证明材料；
8.人文学院团体类奖申请情况说明（如有）；
9.所有参评材料均须提供证明材料，否则不列入参评。
五、鹏程奖学金工作安排
根据学校相关文件精神，今年我院鹏程奖学金名额4个。为保证鹏程奖学金评定工作的顺利进行，安排如下：
（一）评定流程
1. 9月15日至20日，学校开放鹏程奖学金网上申报系统申请功能，学生登录网上办事大厅奖学金板块，在线提交申请表；
2. 9月20日17:00前，请申请同学将所有在奖学金申请系统提交申请材料的纸质版提交至汇文楼办公区1116杨老师处，届时组织申请同学进群核对材料；
3.10月14日17:00前，学院完成鹏程奖学金初评及公示工作。
（二）材料要求
1.《深圳大学鹏程奖学金申请表》（见附件：2-社会奖学金相关文件）；
2.其余材料参照国家奖学金材料要求进行申请；
3.所有参评材料均须提供证明材料，否则不列入参评。
（三）证书及奖金发放
社会奖证书及奖金发放时间以教育发展基金会联系结果为准。
（四）注意事项
国家奖学金与鹏程奖学金不可兼得。
六、学校奖学金工作安排
为保证学校奖学金评定工作顺利有序进行，本学年度学校奖学金申请仍采用网上申报的方式进行。学院将严格执行《深圳大学本科生先进个人评选及奖学金评定办法（修订）》中的规定，按照奖项设置、获奖比例，开展我院学生校级奖学金评定工作，具体评定工作流程如下（综合先进个人奖评定时间另行通知）：
（一）评定流程
1.学院学委会将组织各班选出班级奖学金评审工作小组，并组织各班组长召开奖学金工作会议；
2.9月15日至20日，学校开放校级奖学金网上申报系统申请功能，学生登录网上办事大厅奖学金板块，在线提交申请表；
3.9月24日17:00前，各班级奖学金评审工作小组完成班级初评工作，在班级内完成初评结果公示，并且将整理好的各项单项奖学金纸质版材料提交至汇文楼办公区1116杨老师处；
4.10月14日前，学院完成公示初评获奖名单。
（二）附加说明
1.请申请“双创之星”的同学注意，如论文是共同一作，请申请“双创之星”（团队）。
2.以学术论文参评“双创之星”可不上传图书馆出具的收录证明，学院统一汇总信息至学生部，后再由图书馆统一审核收录情况。
3.学院将严格按照各类奖项评定条件考核选评，避免学校复核时因材料不足被取消获奖资格。
4.所有获评奖学金的同学需积极配合学校学院开展的各类优秀学生宣传活动，发挥模范带头作用。
七、先进班集体
按照《深圳大学先进班集体评选办法》认真开展本学年度先进班集体评选，我院共有先进班集体名额9个。
1.9月15日9月20日，学生班集体网上填写先进班集体申请表，附上有关证明材料。
2.9月20日17:00前，请申请先进班集体的的班级在系统提交的申请材料的纸质版提交至汇文楼办公区1116杨老师处，届时组织申请先进班集体的班级负责人同学进群核对材料；
3.若先进班集体申请班级数少于等于学院名额，则奖学金评选工作小组仅审核申请班级是否符合申请条件，满足申请条件的班级即可获评；若先进班集体申请班级数多于学院名额，则奖学金评选工作小组将根据班级在思想政治教育、校风建设、学风建设、社会实践和文体活动5个指标择优推荐；
4.10月14日前，学院完成审批、初评。
八、其他
（一）本科生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格；
（二）有关国家奖学金的评选，本通知未尽事宜，详见《教育部财政部关于印发<本专科生国家奖学金评审办法>的通知》（教财函〔2019〕105号）《深圳大学本科生国家奖学金实施细则》相关规定；
（三）优秀学生干部评奖细则详见《人文学院优秀学生干部评选办法（试行）》相关要求；
