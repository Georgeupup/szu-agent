深圳大学传播学院国家励志奖学金评选细则 （2026年修订版）
传播学院 2026/10/20 12:19:00
根据《深圳大学本科生国家励志奖学金评审办法》（深大学部[2025]3号）文件精神，结合我院实际情况，特制定本评选细则：
‌一、评选对象‌
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在册本科生（超过基本修业年限的学生无法获评）；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%。
‌二、评选原则
1.本科生国家励志奖学金每年评审一次，坚持公开、公平、公正、择优的原则。
2.同一学年内，申请国家励志奖学金的学生可以同时申请国家助学金，但不能同时获得国家奖学金。
3.学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。
‌三、评选程序‌
1.宣传动员阶段：启动国家励志奖学金评定工作，学院奖学金评审委员会根据学校公布的评审办法结合我院实际制定评选细则和流程。
2.申请受理阶段：即日起至10月22日9：00，学生本人到网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，须上传成绩单及相关佐证资料，并填写在线文档https://v.wjx.cn/vm/hjAAG6R.aspx（如未在规定时间内填写视为无相关成绩提交）。助学金申请系统10月22日上午9：00关闭，逾期不予申请。
3.评审推荐阶段：10月29日前，学工办严格审查申请学生资格，确定拟获奖学生名单，报学院本科生助学金评审委员会审核后公示。
4.公示3个工作日
无异议后，报送学生部。
5.学生部将于11月4日起对学院上报的材料进行审核并对审核后的名单进行公示（公示期为5个工作日）。
‌四、量化评分标准‌
我院2026年本科生国家励志奖学金名额有29个，按照以下量化标准综合评估：
A.学业成绩占60%；
B.学科竞赛及学术特长表现占30%；
C.公益服务表现占10%。
计分公式为：总分T=A×60%+B×30%+C×10%；总分高者优先。
