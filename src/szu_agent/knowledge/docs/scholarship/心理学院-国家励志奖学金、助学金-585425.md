# 心理学院2026年国家励志奖学金评选细则

根据《深圳大学本科生国家励志奖学金评审办法》及我校《关于开展2026年国家励志奖学金评选工作的通知》，现制定我院2026年国家励志奖学金评选细则。
一、评选条件
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%。
7. 承诺履行受助学生基本义务（热爱社会主义祖国，拥护中国共产党的领导；遵守宪法和法律，遵守学校规章制度；诚实守信，品行端正；努力学习，积极向上，积极参加志愿服务和公益活动；生活俭朴，不挥霍浪费）。
二、评选标准：
国家励志奖学金名额：18
三、评选程序
1. 成立心理学院2026年本科生奖学金评审委员会，公示我院2026年国家励志奖学金评选细则。
2.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn/）助学金栏目申请，须上传成绩单。申请系统于10月19日开通，10月22日上午9：00关闭，逾期不予申请。
3.10月21日前，公示我院国家励志奖学金评选细则。
4.11月3日前完成国家励志奖学金的网上审核及公示（3个工作日）。
四、工作要求
1.同一学年内，申请国家励志奖学金的学生可同时申请并获得本科生国家助学金，但不能同时获得本科生国家奖学金。
2.学生申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。
3. 学院本科生奖学金评审委员会应坚持公平、公正、公开的原则，按照学院评选细则，严格审查申请学生资格，结合学生在校期间学习成绩和家庭经济困难学生认定情况提出拟获奖名单，并公示不少于3个工作日。
