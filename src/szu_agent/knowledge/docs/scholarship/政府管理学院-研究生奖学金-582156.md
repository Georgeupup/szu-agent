# 政府管理学院2025-2026年度研究生奖学金评选办法

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我校研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我校2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金、社会奖学金和优秀研究生干部评选工作有关事宜通知如下：
一、评定原则
激励研究生在德、智、体、美、劳等方面全面发展，真正发挥奖学金的激励和导向作用，引导研究生提高思想品德、业务学习、科研实践等方面素质。研究生国家奖学金及社会奖学金评定以科研成果为主，并参考学业成绩、获奖情况、项目参与以及社会服务实践内容，评定过程和结果公开、公正、公平。
二、评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（以在职形式学习的专业学位研究生、周末授课班研究生、延期毕业研究生除外）。
硕博连读研究生在注册为博士研究生之前，或通过攻读博士学位资格考试前，按照硕士研究生身份申请国家奖学金；注册为博士研究生后，或已经通过攻读博士学位资格考试后，按照博士研究生身份申请国家奖学金。
三、奖励标准及要求
硕士研究生国家奖学金奖励标准为每生每年2万元；
博士研究生国家奖学金奖励标准为每生每年3万元；
鹏程奖学金奖励标准为每生每年1万元；
优秀研究生干部奖励标准为每生每年2000元。
四、奖励名额
硕士研究生国家奖学金5名；
博士研究生国家奖学金1名；
鹏程奖学金1名；
优秀研究生干部5名。
五、研究生国家奖学金与社会奖学金参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，道德品质优良，没有任何违法违纪行为，没有受过国家和学校的各类处分；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践；
（六）研究生出现以下情形之一的，不具备当年研究生学业奖学金参评资格：
1.参评学年违反国家法律法规、校纪校规受到纪律处分者或往年受到纪律处分尚未撤销的；
2.有抄袭剽窃、弄虚作假等学术不端行为经查证属实的；
3.参评学年学籍状态处于休学、保留学籍的。
六、优秀研究生干部参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
（一）热爱社会主义祖国，拥护中国共产党领导；
（二）遵守国家法律法规和校规校纪；
（三）践行社会主义核心价值观，道德品质优秀；
（四）学习态度端正，所有必修课程全部通过；
（五）参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
（六）任职期间有突出工作表现，能提供典型材料及例证。

一、评选程序
（一）9月11日：学校发布评选通知，启动研究生奖学金评选工作。
（二）9月11-16日，政府管理学院成立研究生奖学金评审委员会（以下简称院评审委员会），由学院主要领导任主任委员，研究生导师、行政管理人员、学生代表任委员，院评审委员会负责制定本学院（部）评选细则。院评审委员会名单（附件3）及评选细则需在学校公文通上予以公布。
（三）9月14-17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件5，可下载系统生成的文档）至系统，打印申请材料，学生本人签名，附相关成果复印件，经导师（推荐人）签字。此外，所有奖项申请人还需填写《政府管理学院研究生奖学金评审表》（附件7）完毕后打印连同其他证明材料一起送交学院评审委员会联络人。
注：所有证明材料除纸质复印件外，均需打包上传至系统附件，且与系统提交证明材料一致，否则视为无效。9月18日下午17：00前，将材料依序整理好后交至守正楼B209。
（四）9月18-24日，政府管理学院组织评审会，对申请研究生奖学金的学生进行初步评审。确定推荐名单后，在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。国家奖学金公示期不少于5个工作日，优秀研究生干部公示期为5个工作日。
（五）10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（六）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（七）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。
二、其他事项
（一）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位（新生除外）；且同一科研成果、奖励等不得重复使用。
（二）有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件3，图书馆咨询电话26537002。
（三）研究生奖学金的评审工作，应坚持公开、公平、公正、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假，一经发现，立即取消申请资格。获奖学生须积极参加学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
（四）有关国家奖学金的评选，本通知未尽事宜，详见财政部、教育部《研究生国家奖学金实施细则》及《普通高等学校研究生国家奖学金评审办法》相关规定。
（五）优秀研究生干部评奖细则详见《深圳大学优秀研究生、优秀研究生干部评选办法》。
（六）参评研究生奖学金的学生需所修课程全部通过，成绩排名以学籍系统数据为准。
