# 体育学院2026年研究生学业奖学金评审细则

根据《深圳大学研究生学业奖学金管理办法（修订）》和学校会议有关精神，结合体育学院实际情况，现就体育学院硕士研究生学业奖学金评审工作事宜通知如下：
一、参评对象

二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
(一）第一学年，所有推免生、一流大学建设高校（42所名单见附件）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；
（二）所有符合参评条件的硕士研究生中：
2024级共有学硕在校研究生22名，其中一等奖学金名额为5人，二等奖学金名额为10人。
2025级共有学硕在校研究生16名，其中一等奖学金名额为3人，二等奖学金名额为6人。
2025级共有专硕在校研究生46名，其中一等奖学金名额为9人，二等奖学金名额为18人。
2026级共有学硕在校研究生14名，其中学校认定特等奖11名。需参评：一等奖学金名额为1人，二等1人。
2026级共有专硕在校研究生39名，其中学校认定特等奖24名。需参评：一等奖学金名额为3人，二等奖学金名额为6人。
（三）相关说明
（1）2026级硕士研究生学业奖学金以学校出具研究生统一考试成绩为参考标准（初试+复试）；2024级，2025级硕士研究生学业成绩以学校出具的学位课成绩为准。（参评学生需要提交具有公章的成绩证明+排名证明）学院评审委员会复核查验；所有学业成绩平均分均在75分以上（含75分）才可进入奖学金评审。其中：每一门学位课程学业成绩均在75分以上（含75分），可以申请一等、二等奖学金两个等级；未达到每一门学位课程学业成绩均在75分以上（含75分），可以申请二等奖学金一个等级。
（2）2024级，2025级研究生参评2026年学业奖学金的各类科研成果认定的截止时间为2026年8月31日，可追溯至以当前身份前一次参评研究生奖学金之日，即学术论文、科研项目、个人荣誉等需在2025年8月31日至2026年8月31日内获得或发表，论文以见刊时间为准。（包含2025年8月31日、2026年8月31日当天）。学院评审委员会根据参评人提供的真实有效的，经过核实的相关材料进行综合考量评定。
（3）评分细则详见：深圳大学体育学院研究生学业奖学金量化评分表（2026年）
四、评审日程
（一）9月16日：学生部公布研究生学业奖学金评选工作通知，下达评选名额。其中2026级硕士研究生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定
（二）9月17日—9月22日：各学院（部）成立研究生学业奖学金评审委员会，评审委员会在学校参评条件、申请等级及相关规定条件的基础上，结合本单位的实际情况，制定并公布评选细则，开展初步评审等工作。学院（部）评审委员会名单（附件3）及评选细则需在学校公文通上予以公布，设置明确的公示期，公示无异议，9月22日前将评审委员会名单、评选细则可编辑的电子版及经签字盖章后的PDF扫描版通过“一网通办”平台报送学生部备案，文件以“XX学院（部）学业奖学金评选细则”命名。
（三）9月23日—9月30日：所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的硕士生，学制内博士和延毕博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，提交后打印申请表、本人签名，按学院（部）要求将所需材料及时送交所在院（部）评审委员会联络人。学生个人申请表请各学院（部）留存备查。（学业奖学金申请系统开放时间为：9月23日8:00—9月30日23:00）
（四）10月8日—10月21日：各学院（部）组织评审会，对申请研究生学业奖学金的学生进行初步评审。确定学院（部）推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“学业奖学金管理”系统中完成线上审核。
五、说明及注意事项
（一）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用
（二）硕士研究生（包括特等和一等认定的研究生）需网上申报，并按学院（部）要求提交个人申报材料。
（三）对认定或评审结果有异议的学生，可在各学院（部）公示阶段向所在学院（部）评审委员会提出申诉，学院（部）评审委员会应及时研究并予以答复。如学生对学院（部）评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（四）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
注：根据学校相关文件和会议精神，同时考虑体育学院人才培养的特殊性，原则上国家奖学金、社会奖学金、学业奖学金不能兼得。特别优秀学生评审委员会专门讨论。
