# 生命与海洋科学学院2026年本科生助学金及国家励志奖学金评定细则

根据学校《关于开展2026年本科生助学金评选工作的通知》和《关于开展2026年国家励志奖学金评选工作的通知》结合我院家庭经济困难学生的实际情况，现将我院2026年本科生助学金及国家励志奖学金评定细则公布如下：
一、资助体系构成
1．国家励志奖学金
2．国家助学金
二、获助资格条件
（1）国家励志奖学金
1.通过2026-2027学年度家庭经济困难认定的二年级及以上全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.生活简朴、诚实守信，道德品质优良；
6.勤奋学习，成绩优秀，成绩排名至少在前50%。
（2）本科生助学金
1.通过2026-2027学年度家庭经济困难认定的全日制在校本科生；
2.具有中华人民共和国国籍；
3.热爱社会主义祖国，拥护中国共产党的领导；
4.遵守宪法和法律，遵守学校规章制度；
5.诚实守信，道德品质优良；
6.学习勤奋，生活简朴，积极向上；
7.符合各类助学金的其他评选要求（见附件1）;
8.知晓并承诺履行助学金获助学生义务（见附件2）；
9.超过基本修业年限的学生不再享受国家助学金。
三、评定原则
1．同一年内，学生不得同时获得国家奖学金和国家励志奖学金。
2．学院申报后，一旦发现与条件不符者即刻取消评选资格，名额自动作废。如有在评选中弄虚作假者（如伪造贫困材料、不如实填写家庭经济情况等），一律取消当年评选资格，并按学校有关规定进行严肃查处。

五、评定流程及工作要求
1.学生本人到深圳大学网上办事服务大厅（网址：http://ehall.szu.edu.cn）助学金板块申请。国家励志奖学金须上传成绩单。申请系统于10月19日开通，10月22日上午9：00关闭，逾期不予申请。
2．学院在评选过程中坚持公平、公正、公开的原则，按照本学院评选细则，严格审查申请学生资格，确定拟获资助名单，于规定时间内完成各项助学金网上审核及公示（3个工作日）。
