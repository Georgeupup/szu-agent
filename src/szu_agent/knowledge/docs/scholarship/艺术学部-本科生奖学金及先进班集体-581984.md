# 艺术学部2025-2026学年度本科生奖学金及先进班集体评选细则

为鼓励学生刻苦学习、积极创新、全面发展，同时更好地发挥奖学金的激励和导向作用，根据《深圳大学本科生国家奖学金评审办法》、《深圳大学本科生奖学金评定办法（修订）》、《深圳大学学生特殊贡献奖认定办法》、《深圳大学先进班集体评选办法》以及各类社会奖学金设置协议，结合艺术学部实际，制定本细则。
一、奖学金申请基本条件
有意愿申请当学年奖学金的在校本科生，均需符合以下全部基本条件：
1. 热爱祖国，拥护中国共产党的领导；
2. 遵守宪法和法律，遵守学校的规章制度，品行优良；
3. 评选学年度成绩无挂科记录、无违规违纪行为；
4. 原则上所评选学年度体测成绩及格及以上（2026年要求）；
5. 评选学年度志愿服务时长不低于28小时；
6. 评选学年度思政学时达标。
二、国家奖学金
1. 奖项名额及奖励标准：
本年度艺术学部共有6个本科生国家奖学金名额，奖励标准每生每年10000元/人。
2. 申请时间及申请要求：
本年度国家奖学金申请时间为9月11日至9月15日，学生凭本人校园卡账号和密码登录网上办事大厅“奖学金”板块在线提交申请表，并按照班级通知要求提交相应材料。
3. 参评要求：
根据《深圳大学本科生国家奖学金实施细则》，参评国家奖学金需满足以下几个方面的要求：
（1）上一学年的平均绩点需排在本专业本年级前10%，且无挂科记录、无违纪记录；
（2）在专业学科竞赛上获得突出的成绩，如国家级、省级荣誉；或在专业科研领域发表论文、获得国家发明专利；
（3）个人其他方面表现优秀，如：社会实践、体育竞赛、文艺比赛、志愿服务等；
（4）如绩点不在本专业本年级前10%、但在前30%的其他情况，需严格按照《深圳大学本科生国家奖学金评审办法》（深大学部〔2025〕4号）的具体标准参与评选。
4. 评选流程：
（1）奖学金系统开放后，由符合申请条件的本科生在线提交奖学金申请，并严格按照奖学金申请通知要求提交相应材料，由艺术学部本科生奖学金评选工作组对所有申请材料进行复核；
（2）由艺术学部本科生奖学金评选委员会基于当学年申请情况，开展国家奖学金评选工作；
（3）评选结束后，由艺术学部本科生奖学金评选工作组对评定结果进行公示，公示期不少于3天。如公示期内有异议，由艺术学部本科生奖学金评选工作组对相关异议进行受理；
（4）公示期结束后，由艺术学部本科生奖学金评选工作组提交相关材料至学生部学生资助中心。
二、社会奖学金（鹏程奖学金）
1. 奖项名额及奖励标准：
本年度艺术学部共有6个本科生鹏程奖学金名额，奖励标准每生每年10000元/人。
2. 申请时间及申请要求：
本年度鹏程奖学金申请时间为9月15日至9月20日，学生凭本人校园卡账号和密码登录网上办事大厅“奖学金”板块在线提交申请表，并按照班级通知要求提交相应材料。
3. 参评要求：
根据深圳大学本科生社会奖学金（鹏程奖学金）评选办法，申请人员需同时满足以下申请条件：
（1）刻苦学习、成绩优异，所评选学年度所有课程及格，学分绩点在全年级10%以内；
（2）热爱祖国、遵纪守法、品行端正、举止文明，没有违法违纪行为，所评选学年度和评选期间没有受到学校行政、党、团处分，综合表现优秀。
3、评选流程：
（1）奖学金系统开放后，由符合申请条件的本科生在线提交奖学金申请，并严格按照奖学金申请通知要求提交相应材料，由艺术学部本科生奖学金评选工作组对所有申请材料进行复核；
（2）由艺术学部本科生奖学金评选委员会基于当学年申请情况，开展鹏程奖学金评选工作；
（3）评选结束后，由艺术学部本科生奖学金评选工作组对评定结果进行公示，公示期不少于3天。如公示期内有异议，由艺术学部本科生奖学金评选工作组对相关异议进行受理；
（4）公示期结束后，由艺术学部本科生奖学金评选工作组提交相关材料至学生部学生资助中心。
三、校级单项先进个人奖学金
1. 奖项构成及奖励标准：
（1）学业类：“学习之星”“双创之星”
（2）特长类：“文体之星”
（3）公共服务类：“公益之星”“优秀学生干部”
（4）特殊贡献奖
奖学金金额：
一等奖3000元/人；二等奖2000元/人；三等奖1000元/人。
（注：综合先进个人奖的评选细则将在学校启动综合先进个人奖评定工作后另行公布。）
校级单项个人奖学金名额详见附件1。
2. 申请时间及申请要求：
本年度校级单项先进个人奖学金申请时间为9月15日至9月20日，学生凭本人校园卡账号和密码登录网上办事大厅“奖学金”板块在线提交申请表，并按照班级通知要求提交相应材料。
3. 评选流程
（1）奖学金系统开放后，由符合申请条件的本科生在线提交奖学金申请，并严格按照各类校级奖学金申请通知要求提交相应材料，由艺术学部本科生奖学金评选工作组对所有申请材料进行复核；
（2）由艺术学部本科生奖学金评选委员会基于当学年申请情况，开展校级单项先进个人奖学金评选工作；
（3）评选结束后，由艺术学部本科生奖学金评选工作组对评定结果进行公示，公示期不少于3天。如公示期内有异议，由艺术学部本科生奖学金评选工作组对相关异议进行受理；
（4）公示期结束后，由艺术学部本科生奖学金评选工作组提交相关材料至学生部学生资助中心。
四、先进班集体
1. 奖项名额及奖励标准：
本年度艺术学部共有15个本科生先进班集体奖学金名额，奖励标准为班级总人数*30元。
2. 申请时间及申请要求：
本年度先进班集体奖学金申请时间为9月15日至9月20日。班级选定一名学生代表，凭本人校园卡账号和密码登录网上办事大厅“奖学金”板块在线提交申请表，并按通知要求上传提交相应材料。
3. 参评要求：
根据《深圳大学先进班集体评选办法》，申请奖项的班级需为我校全日制本科大二及以上年级班级，并在思想政治教育、校风建设、学风建设、社会实践、文体活动方面表现优良。
4. 评选流程
（1）奖学金系统开放后，由符合申请条件的班级选定一名代表在线提交奖学金申请，并严格按照各类校级奖学金申请通知要求提交相应材料，由艺术学部本科生奖学金评选工作组对所有申请材料进行复核；
（2）由艺术学部本科生奖学金评选委员会基于当学年申请情况，开展先进班集体奖学金评选工作；
（3）评选结束后，由艺术学部本科生奖学金评选工作组对评定结果进行公示，公示期不少于3天。如公示期内有异议，由艺术学部本科生奖学金评选工作组对相关异议进行受理；
（4）公示期结束后，由艺术学部本科生奖学金评选工作组提交相关材料至学生部学生资助中心。
五、评选工作原则及总体要求
1. 本年度国家奖学金、学校奖学金、社会奖学金纳入统一的奖学金评选体系，统筹规划、同步评选；2026年本科毕业生奖学金评选工作也将同步进行。
2. 申报各类奖学金，均需满足相应奖学金文件中所对应的评选资格条件。
3. 按照《深圳大学本科生奖学金评定办法（修订）》，如同时获得多项先进个人奖学金，其荣誉可兼得，奖学金以最高一项计发；校级单项先进个人奖与团队奖奖金、荣誉可兼得。
4. 国家奖学金与国家励志奖学金不可兼得。
5. 以勤工助学岗位工作身份参与学生工作，不可作为学生干部参加“优秀学生干部”奖学金评选。
6. 学生申报提交后，一旦发现评选条件不符者即取消其资格，不予以评定相关奖项。如有在评选中弄虚作假者（如篡改成绩单、伪造获奖证明、不如实填写获奖等级等），一律取消当年奖学金评选资格，并按学校有关规定严肃查处。
7. “特殊贡献奖”由学校根据实际情况直接评定，学生无须申请。
