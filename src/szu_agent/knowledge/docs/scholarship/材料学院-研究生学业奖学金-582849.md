# 材料学院2026年研究生学业奖学金评定细则

根据《深圳大学研究生学业奖学金管理办法（修订）》、《关于组织开展深圳大学2026年研究生学业奖学金评审工作的通知》等文件通知的有关精神，结合材料学院特点，现制定学业奖学金评定细则如下：
一、参评对象
被学校正式录取并注册报到、具有中华人民共和国国籍的全日制在校研究生。
二、参评条件
（一）热爱社会主义祖国，拥护中国共产党的领导；
（二）遵守国家法律法规，遵守学校规章制度；
（三）诚实守信，品学兼优；
（四）所修课程全部通过，且学位课程平均成绩达到75分以上（含75分）；
（五）积极参与科学研究和社会实践。
三、奖励标准及要求
（一）硕士研究生学业奖学金第一学年设特等、一等、二等三个等级，第二学年及以后设一等、二等两个等级。各等级每生每年奖励标准为：特等15,000 元，一等10,000 元，二等5,000 元。硕士研究生学业奖学金只在标准学制年限内参评。
1．第一学年，所有推免生、一流大学建设高校（42所名单见附件6）应届毕业第一志愿考生、本科成绩专业排名前20%的本校应届毕业第一志愿考生（不包括联合培养的本科学生）直接认定为特等。一流大学建设高校应届毕业调剂考生、本科成绩专业排名前20%的本校应届毕业调剂考生（不包括联合培养的本科学生）直接认定为一等。其余符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等；其中，第一志愿的一流学科建设高校应届毕业生和第一志愿的本校应届毕业生总成绩排名在获奖人数比例范围内的条件下优先参评一等奖。认定名单见附件1，名额分配见附件2。
2.第二学年及以后，综合考虑思想品德、学业成绩、学术成果和社会实践（包括科技竞赛、文体比赛、参加义工服务、担任学生干部及其他实践活动）等因素展开评定。所有符合参评条件的硕士研究生中不超过20%获评一等，不超过40%获评二等。名额分配见附件2。
（二）博士研究生学业奖学金奖励标准为每生每年20,000 元，在标准学制年限内参评；如有特殊情况，经学生本人申请、学生所在培养单位及学校审核批准后可适当延长参评年限，但最长不超过五年。凡符合基本参评条件的博士研究生，均可获得学业奖学金。
四、评定细则
（一）研一新生
新生特等奖学金及部分一等奖学金原则上由学生部根据招生及录取数据统一认定，其他参评同学的一、二等奖学金由学院根据考研总成绩（初试成绩+复试成绩）进行排名，分数相同时看复试成绩进行排序，依次按名额进行评定。调剂生根据考研总成绩进行排名，与第一志愿学生总成绩分开计算。
（二）研二、研三老生
由学业成绩、科研成果得分和综合素质测评成绩构成参评总成绩，制定参评总成绩计分方式为：
研二：参评总成绩 ＝ 学业成绩（百分制总评成绩）×40％+科研成果得分+综合素质成绩得分×10％。
研三：参评总成绩 ＝ 学业成绩（百分制总评成绩）×10％+科研成果得分+综合素质成绩得分×10％。
1.学业成绩
由学院根据成绩系统统一认定。
2.科研成果
（1）有效成果认定：所有成果均需符合《深圳大学材料学院研究生科研成果认定办法（修订）》（附件4、附件5）。
（2）科研成果分数计算
a.SCI论文加分
A+影响因子（以深圳大学图书馆能查询到的最新影响因子为准）
备注：A为文章大类分区加分（一区8分；二区5分；三区3分；四区2分）。
b.中文期刊论文加分
中文核心期刊论文2分；
中文非核心期刊论文1分。
c.会议论文：1分；
优秀论文、优秀墙报在会议论文基础上加0.5分；
d.专利加分
国际专利5分；
中国发明专利4分（PCT则另加1分）；
实用新型专利2分；
外观设计专利2分。
以上加分均要求取得授权，如进入实质审查阶段，则分值×50%。
e.学科竞赛加分
国家级：一等奖8分；二等奖7分；三等奖6分；优胜奖5分；
省级：一等奖6分；二等奖5分；三等奖4分；优胜奖3分；
市级：一等奖4分；二等奖3.5分；三等奖3分；优胜奖2.5分；
校级：一等奖3分；二等奖2.5分；三等奖2分；优胜奖1.5分；
院级：一等奖2分；二等奖1.5分；三等奖1分；优胜奖0.5分；
此项中竞赛加分均为总决赛，分赛区原则上采取降级处理，具体加分视赛事情况而定。
f.科研项目：
国家级、省级8分；
市级6分；
校级3分。
例：某同学有一篇影响因子6的一区SCI论文，科研成果加分方法如下：
8（文章大类分区加分）+6（文章影响因子）=14分
3.综合素质成绩
综合素质测评成绩依据该研究生上一学年的综合表现，主要包括社会工作和学院评价两方面。
（1）社会工作（上限15分）
根据申请人个人在班级、学生组织等团体所承担社会工作的情况、志愿者工作的参与情况、对学院或班级管理建设做出的贡献情况进行考察。
a.申请者担任主要学生干部（班长、团支书、研究生会主席、党群服务队副队长、党支部学生第一负责人等）加6分，其他学生干部（部长、副部长、党支部其他支委成员等）加4分，干事加2分。每人最多加6分。参评学年担任以上职务均需满六个月。
b.参加学院组织的重要活动给予一定加分。活动列表由学院统一提供，加分标准见附件6。
（2）学院评价（上限5分）
如学生有特殊经历或贡献，由学院奖学金评审委员会根据实际情况经集体讨论后予以评分。若最终存在两人以上综合分数相同，则参考其未被认定的科研成果进行评定；如未被认定的科研成果一致，则由学院奖学金评审委员会结合学生思想、学习、生活等综合表现情况，对相关学生予以综合评价，对推荐获奖名单认定和解释并做最终评定。
五、评选步骤
（一）9月16日：学生部公布研究生学业奖学金评选工作通知，下达获奖名额。
（二）9月18日—9月22日：学院评审委员会在学校参评条件、申请等级及相关规定条件的基础上，结合学院的实际情况，制定并公布评选细则，开展初步评审等工作。学院评审委员会名单及评选细则在学校公文通上予以公布。
（三）9月23日—9月30日：
1.所有符合参评条件并有意愿申请研究生学业奖学金的学生（包括认定名单中的学生，学制内博士和延期博士）登录网上办事服务大厅http://ehall.szu.edu.cn/new/index.html，在“学业奖学金”板块在线填写申请表、上传相关佐证材料，提交后打印申请表、本人签名，附相关成果复印件，送交学院评审委员会联络人李老师处。（学业奖学金申请系统开放时间为：9月23日8:00—9月30日23:00）
2.请各位硕士生同学填写研究生奖学金评定成果汇总表（在线表），后续会发至年级群。请各位同学对在线表所填信息真实性负责。
3.请各班班长收集齐本班同学纸质材料于2026年9月30日17:30前交至学院405办公室。材料清单如下（请各位同学按以下顺序放置）：
（1）学业奖学金申请表（系统导出、双面打印）；
（2）成绩单复印件；
（3）论文相关佐证材料（图书馆检索报告、论文无附加条件的录用通知）；
（4）专利相关佐证材料（专利受理通知书、专利证书复印件等）；
（5）承担科研项目、获奖证书复印件及其他相关证明材料。
（四）10月8日—10月21日：学院组织评审会，对申请研究生学业奖学金的学生进行初步评审。确定学院推荐名单后，在全校范围内进行公示（不少于5个工作日），并在“学业奖学金管理”系统中完成线上审核。
（五）10月21日后：学生部审核、公示获奖名单，报校领导审批。
（六）校级公示结束后，获奖学生可在校内自助打印机上打印学业奖学金证明。
六、有关说明及注意事项
（一）参评研究生学业奖学金所涉及的科研成果、奖励等认定截止时间为2026年8月31日，毕业年级延长至奖学金申请截止前即2026年9月30日23:00前。
（二）评选材料中有关学术论文、科研成果等，深圳大学须为第一完成单位；且同一科研成果、奖励等不得重复使用。
（三）硕士研究生（包括特等和一等认定的研究生）、学制内博士及延毕博士均需网上申报，佐证材料须上传成绩单，其他按需上传。
（四）对认定或评审结果有异议的学生，可在各学院（部）公示阶段向所在学院（部）评审委员会提出申诉，学院（部）评审委员会应及时研究并予以答复。如学生对学院（部）评审委员会作出的答复仍存在异议，可在学校公示阶段提请校评审领导小组复核。
（五）研究生学业奖学金的评审工作坚持公正、公平、公开、择优的原则，严格执行国家有关教育法规，杜绝弄虚作假。
（六）获得学业奖学金奖励的研究生，可以同时获得研究生国家奖学金、研究生国家助学金等其他研究生国家奖助政策,以及校内其他研究生奖助政策资助。
（七）本细则由材料学院研究生学业奖学金评审委员会负责解释与执行。

## 附件：材料学院科研成果评定计分方法

材料学院科研成果评定计分方法

有效成果认定

所有成果均需符合《深圳大学材料学院关于研究生科研成果的认定办法（修订）》。

二、科研成果分数计算

1.SCI论文加分

A+影响因子（以深圳大学图书馆能查询到的最新影响因子为准）

备注：A为文章大类分区加分（一区8分；二区5分；三区3分；四区2分）。

2.中文期刊论文加分

中文核心期刊论文2分；

中文非核心期刊论文1分。

3.会议论文：1分；

优秀论文、优秀墙报在会议论文基础上加0.5分；

4.专利加分

国际专利5分；

中国发明专利4分（PCT则另加1分）；

实用新型专利2分；

外观设计专利2分。

以上加分均要求取得授权，如进入实质审核阶段，则分值×50%。

5.学科竞赛加分

国家级：一等奖8分；二等奖7分；三等奖6分；优胜奖5分；

省级：一等奖6分；二等奖5分；三等奖4分；优胜奖3分；

市级：一等奖4分；二等奖3.5分；三等奖3分；优胜奖2.5分；

校级：一等奖3分；二等奖2.5分；三等奖2分；优胜奖1.5分；

院级：一等奖2分；二等奖1.5分；三等奖1分；优胜奖0.5分；

此项中竞赛加分均为总决赛，分赛区原则上采取降级处理，具体加分视赛事情况而定。

6.科研项目：

国家级、省级8分；

市级6分；

校级3分。

例：某同学有一篇影响因子6的一区SCI论文，科研成果加分方法如下：

8（文章大类分区加分）+6（文章影响因子）=14分

本方法由材料学院研究生学业奖学金评审委员会负责解释与执行。
