# 人工智能与数字经济广东省实验室（深圳） 2025-2026学年研究生国家奖学金和优秀研究生干部评选细则

根据《学生资助资金管理办法》（财教〔2021〕310 号）《深圳大学研究生国家奖学金评审办法（修订）》（深大校发〔2025〕226 号）《深圳大学优秀研究生、优秀研究生干部评选办法》（深大校发〔2026〕131 号）和我校相关社会奖学金设置协议等文件要求，为促进我实验室研究生培养机制改革，提高研究生培养质量，更好地发挥奖学金的激励和导向作用，确保我实验室2026年研究生奖学金评审工作公开、公平、有序进行，现将研究生国家奖学金和优秀研究生干部评选工作有关事宜通知如下：
一、研究生国家奖学金
（一）评选对象
攻读硕士、博士学位的具有中华人民共和国国籍的全日制研究生（延期毕业的研究生除外）。
（二）奖励标准
研究生国家奖学金由中央财政出资设立，博士研究生国家奖学金奖励标准为每生每年30000元；硕士研究生国家奖学金奖励标准为每生每年20000元。
（三）名额分配
名额分配方案详见附件1《深圳大学2025-2026学年研究生奖学金名额分配表》，我实验室硕士研究生国家奖学金有4个名额。
（四）参评条件
1.热爱社会主义祖国，拥护中国共产党领导；
2.遵守国家法律法规，遵守学校规章制度；
3.践行社会主义核心价值观，道德品质优秀；
4.学习成绩优异，科研能力显著，发展潜力突出。
5.科研成果要求：在本专业核心期刊上公开发表学术论文；获得省级以上奖励或申请国家发明专利（实质审查）；或其它有特殊贡献或者突出贡献者（需评审委员会讨论认定）。
（五）评选要求
1.各学院（部）研究生国家奖学金评审委员会根据学校参评条件制定本学院（部）评选细则，并在全校范围内公开。
2.各学院（部）制定评选细则时应综合考虑参评学生的科研能力、科研成果、学业成绩、其他突出贡献等因素。
二、优秀研究生干部
（一）参评对象
优秀研究生干部的参评对象为经我校正式录取并注册报到的全日制在校学习的研究生（延期毕业的硕士研究生除外）。
（二）奖励标准
每生每年2000元。
（三）奖励名额
根据《深圳大学2025-2026学年研究生奖学金名额分配表》（附件1），我实验室优秀研究生干部有4个名额。申请人数超出下达名额的，同等条件下优先推荐成果突出的参评者，符合评奖条件的申请人数达不到下达名额的，奖项名额自动空缺。
（四）参评条件
申请人参评优秀研究生干部时应同时满足下列条件：
1.热爱社会主义祖国，拥护中国共产党领导；
2.遵守国家法律法规和校规校纪；
3.践行社会主义核心价值观，道德品质优秀；
4.学习态度端正，所有必修课程全部通过；
5.参评学年担任校、院（部）级研究生干部、学校社团组织骨干不少于六个月；
6.任职期间有突出工作表现，能提供典型材料及例证。
上述研究生奖学金的评选安排如下：
一、评选程序
（一）9月11-16日，各学院（部）成立研究生奖学金评审委员会（以下简称院评审委员会），负责制定本学院（部）的评选细则、开展初步评审等工作。评选细则需在学校的总体要求下，按学院的实际情况进一步制定。院评审委员会名单（附件2）及评选细则需在学校公文通上予以公示。公示无异议，9月16日前将评选细则及评审委员会名单电子版（可编辑Word文件及签字盖章后PDF扫描件）通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交。
（二）9月14-17日，所有符合参评条件并有意愿申请研究生奖学金的学生登录深圳大学网上办事服务大厅http://ehall.webvpn.szu.edu.cn/new/index.html，进入“奖学金申请”模块，在线填写相关奖学金的申请审批表，其中国家奖学金还需上传《研究生国家奖学金申请人学术论文、科研成果、获奖情况汇总表》（见附件4，可下载系统生成的文档）至系统，按照所在学院（部）要求送交院评审委员会联络人李曼虹老师处。申报各类奖项时，相关佐证材料均需上传至系统附件。
其中国奖申请理由需填写至少半页以上，否则无效。
*纸质版申请材料提交截止时间：9月17日中午12:00。地点：光明区科润大厦B栋1015李曼虹老师处。逾期不予采纳。

（三）9月18-30日，实验室组织评审会，对申请研究生奖学金的学生进行初步评审。确定学院推荐名单后，应在全校范围内进行公示，并在“奖学金管理”系统中完成线上审核。公示无异议，9月30日前将以下材料电子版通过【“一网通办”平台-学生部-深圳大学奖学金材料审批上报】进行提交：
1.XX学院（部）2025-2026学年度研究生奖学金评选情况总结（附件6）的可编辑Word文件及签字盖章后PDF扫描件；
2.学院（部）推荐名单汇总表（附件4、5）的可编辑Excel文件及签字盖章后PDF扫描件；
3.国家奖学金推荐学生个人申请审批表的签字盖章后PDF扫描件。
（四）10月8-14日，学生部复核各学院（部）推荐名单，并将校级推荐名单在全校范围内进行公示。
（五）对评审结果有异议的学生，可在各学院（部）公示阶段向所在院评审委员会提出申诉，院评审委员会应及时研究并予以答复。如学生对院评审委员会作出的答复仍存在异议，可在学校公示阶段向学生部提出申诉。
（六）经上级主管部门核准后，学校将当年研究生奖学金一次性发放给获奖学生，并颁发荣誉证书，宣传优秀学子先进事迹。社会奖学金证书及奖金发放时间以教育发展基金会联系结果为准。

（一）个人申报材料除申请表以外，科研成果复印件（承担科研项目及获奖证书复印件、发表论文期刊封面、目录、论文首页复印件、专利证书复印件）、获奖证书复印件及其他可证明本人优异表现的佐证材料。同时提交《光明实验室研究生奖学金评审表_2026》
（二）有关论文证明材料无需图书馆开具检索证明，可自行在相关数据库中检索截图上传。检索指引见附件3，图书馆咨询电话26537002。
（三）奖学金评定工作涉及学生切身利益，请各学院（部）务必按照要求认真对待每一个工作环节，确保奖学金评定工作的公平、公正、公开、高效、无误，并注意保存奖学金评定环节中的过程性资料。
（四）有关国家奖学金的评选，本通知未尽事宜，详见财政部、教育部《研究生国家奖学金实施细则》及《普通高等学校研究生国家奖学金评审办法》相关规定。
（五）优秀研究生干部评奖细则详见《深圳大学优秀研究生、优秀研究生干部评选办法》。在职学习的专业学位研究生根据《深圳大学在职学习专业学位研究生评奖办法》评奖，具体事宜由所在学院通知。
（六）获奖学生须积极参加实验室及学校对优秀学子的宣传工作，积极担任先进典型宣传大使。
